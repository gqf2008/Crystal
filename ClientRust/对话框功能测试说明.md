#### 3. 测试步骤

**测试新建账号对话框:**
1. 启动程序 (cargo run --bin mir2_bevy)
2. 在登录界面点击 "New Account" 按钮 (位置: 60, 163)
3. 应该看到新建账号对话框弹出并居中显示
4. 对话框背景应该完整显示 (Prguse 库索引 63)
5. 鼠标悬停在 OK/Cancel 按钮上应该看到纹理变化
6. 点击按钮应该有 pressed 状态纹理
7. 点击 Cancel 或 OK 应该关闭对话框

**测试修改密码对话框:**
1. 在登录界面点击 "Password Change" 按钮 (位置: 166, 163)
2. 应该看到修改密码对话框弹出并居中显示
3. 对话框背景应该完整显示 (Prguse 库索引 64)
4. 按钮功能测试同上

### 🐛 已知问题

1. **纹理索引 63/64 是否存在?**
   - 如果对话框背景不显示,检查 Prguse 库是否包含这些索引
   - 查看控制台日志中的 "Failed to load" 警告

2. **对话框按钮位置可能需要微调**
   - C# 原版使用的坐标可能需要根据实际纹理大小调整

3. **ZIndex 可能不生效**
   - 如果对话框被其他元素遮挡,需要检查渲染顺序
