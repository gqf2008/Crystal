## 🔧 故障排除

### 问题 1: "Blocking waiting for file lock on build directory"

**原因**: 另一个 cargo 进程仍在运行

**解决方案**:
```powershell
# 杀掉所有 cargo 进程
Get-Process cargo -ErrorAction SilentlyContinue | Stop-Process -Force

# 等待一秒
Start-Sleep -Seconds 1

# 重新运行
cargo run --bin mir2_bevy
```

### 问题 2: 编译错误

**解决方案**:
```powershell
# 清理构建缓存
cargo clean

# 重新编译
cargo build --bin mir2_bevy
```

### 问题 3: 游戏无法启动

**检查项**:
1. 确认编译成功（无红色错误）
2. 检查是否有必要的资源文件
3. 查看控制台输出的错误信息

## 📝 开发要点

### 系统运行顺序

1. **Startup** - 一次性初始化
   - setup_player_system
   - setup_game_loop_system
   - 等其他初始化系统

2. **OnEnter(Game)** - 进入游戏状态
   - 初始化所有游戏系统

3. **Update(GameState::Game)** - 主游戏循环
   - 53 个系统分组并行运行
   - 网络系统、更新系统、渲染系统等

### 消息系统

项目使用 Bevy 的事件系统处理消息：
- **34 个消息类型** 注册在 app 中
- **事件驱动架构** 处理异步交互
- **系统优先级** 控制执行顺序

### 数据流向

```
玩家输入

消息系统 (34 种消息)
   ↓
系统处理 (53 个系统)
   ↓

   ↓
```
