# 地图渲染问题修复报告

## 问题描述

用户反馈：**有黑块，看不到建筑物、树木、山等对象**

## 问题分析

### 初步调查
运行日志显示：
```
Middle 层绘制数量: 0
```

**Middle层完全没有渲染！**这是建筑物、树木、山石等对象的渲染层。

### 根本原因

#### 1. Type 100地图格式解析错误

**错误的实现**（之前）：
```rust
// offset 从16开始读取宽高
offset = 16;
self.width = i16::from_le_bytes([...]) as i32;
self.height = i16::from_le_bytes([...]) as i32;

// offset从8开始读取数据（错误！）
offset = 8;
```

**正确的实现**（C#参考）：
```csharp
int offset = 16;
Width = BitConverter.ToInt16(Bytes, offset); // 16
offset += 2;
Height = BitConverter.ToInt16(Bytes, offset); // 18
MapCells = new CellInfo[Width, Height];
offset = 40; // 数据从40开始！
```

#### 2. Type 100数据结构错误

**错误**：
- BackIndex/MiddleIndex/FrontIndex 读取为2字节
- 没有+1处理Image值

**正确**：
- Index字段是**1字节**（255表示-1，否则+300）
- Image字段是**2字节+1**

#### 3. 地图类型判断顺序错误

**错误的顺序**：
```rust
// Type 100判断在前
if bytes[2] == 0x43 && bytes[3] == 0x23 {
    return self.load_map_type_100();
}
// Type 5判断在后
if bytes[0] == 0 {
    return self.load_map_type_5();
}
```

问题：`01 00 43 23`会被误判为Type 100，但如果bytes[0]=0则应该是Type 5。

**修复后的顺序**：
```rust
// 先检查Type 5
if bytes[0] == 0 {
    return self.load_map_type_5();
}
// 再检查Type 100（必须bytes[0]=1）
if bytes[0] == 1 && bytes[2] == 0x43 && bytes[3] == 0x23 {
    return self.load_map_type_100();
}
```

## 修复内容

### 文件：`src/objects/map_code.rs`

#### 修复1：Type 100格式加载逻辑

```rust
// 读取宽度和高度 (offset 16-19)
let mut offset = 16;
self.width = i16::from_le_bytes([...]) as i32;
offset += 2;
self.height = i16::from_le_bytes([...]) as i32;
offset += 2;

// 初始化地图格子数组
self.map_cells = vec![vec![CellInfo::new(); self.height as usize]; self.width as usize];

// offset 从40开始读取格子数据
offset = 40;

for x in 0..self.width {
    for y in 0..self.height {
        let cell = &mut self.map_cells[x as usize][y as usize];
        
        // flag (1字节)
        let flag = self.bytes[offset];
        offset += 1;
        
        // BackIndex (1字节): 255表示-1，否则+300
        let back_idx_byte = self.bytes[offset];
        cell.back_index = if back_idx_byte != 255 {
            (back_idx_byte as i16) + 300
        } else {
            -1
        };
        offset += 1;
        
        // MiddleIndex (1字节): 255表示-1，否则+300
        let middle_idx_byte = self.bytes[offset];
        cell.middle_index = if middle_idx_byte != 255 {
            (middle_idx_byte as i16) + 300
        } else {
            -1
        };
        offset += 1;
        
        // FrontIndex (1字节): 255表示-1，否则+300
        let front_idx_byte = self.bytes[offset];
        cell.front_index = if front_idx_byte != 255 {
            (front_idx_byte as i16) + 300
        } else {
            -1
        };
        offset += 1;
        
        // BackImage (2字节) + 1
        cell.back_image = (i16::from_le_bytes([
            self.bytes[offset],
            self.bytes[offset + 1],
        ]) as i32) + 1;
        offset += 2;
        
        // MiddleImage (2字节) + 1
        cell.middle_image = (i16::from_le_bytes([
            self.bytes[offset],
            self.bytes[offset + 1],
        ]) as i32) + 1;
        offset += 2;
        
        // FrontImage (2字节) + 1
        cell.front_image = (i16::from_le_bytes([
            self.bytes[offset],
            self.bytes[offset + 1],
        ]) as i32) + 1;
        offset += 2;
        
        // ... 其他字段
    }
}
```
