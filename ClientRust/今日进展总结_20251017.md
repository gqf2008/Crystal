```rust
// 旧版 (Bevy 0.14)

event_reader.read()

// 新版 (Bevy 0.17)
#[derive(Message)]
message_writer.write(MyMessage);

```

**Query API** (方法名变化):
```rust
// 旧版

// 新版
query.iter().next() -> Option<T>
```

**WindowResolution** (类型变化):
```rust

// 新版

```

## 📚 技术要点总结

### Bevy 0.17.2 关键API

**1. Message 系统 (完全替代 Event)**
```rust
// 定义
#[derive(Message)]
struct MyMessage {
    data: String,
}

// 发送
fn sender_system(mut writer: MessageWriter<MyMessage>) {
    writer.write(MyMessage { data: "hello".into() });
}

// 接收
fn receiver_system(mut reader: MessageReader<MyMessage>) {
    for msg in reader.read() {
        println!("{}", msg.data);
    }
}

// 注册 (自动,无需 app.init_message())
```

**2. Query 迭代器 API**
```rust
// 单一结果
if let Some(player) = query.iter().next() {

}

// 多个结果
for entity in query.iter() {
    // 处理
}

// 可变引用
for mut component in query.iter_mut() {
    // 修改
}
```

**3. 窗口配置**

### MLibrary 集成要点

**1. 全局库系统**
```rust

// 加载核心库
libraries::load_core_libraries()?;
```

**2. 纹理缓存**
```rust
#[derive(Resource)]
struct MLibraryAssets {
    textures: HashMap<String, Handle<Image>>,
}

// 获取或创建纹理
fn get_texture(&mut self, lib: &str, index: i32, images: &mut Assets<Image>)
    -> Option<Handle<Image>>
{
    let key = format!("{}:{}", lib, index);
    if let Some(handle) = self.textures.get(&key) {
        return Some(handle.clone());
    }
    
    // 加载并缓存
    let texture = load_from_mlibrary(lib, index);
    let handle = images.add(texture);
    self.textures.insert(key, handle.clone());
    Some(handle)
}
```

**3. BGRA8 转换**
```rust
fn bgra_to_image(data: &[u8], width: u32, height: u32) -> Image {
    Image::new(
        Extent3d { width, height, depth_or_array_layers: 1 },
        TextureDimension::D2,
        data.to_vec(),
        TextureFormat::Bgra8UnormSrgb,
        RenderAssetUsages::RENDER_WORLD,
    )
}
```
