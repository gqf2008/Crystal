## 任务 1: 实现 draw_tile 的实际纹理绘制

### 实现位置
`src/scenes/game_scene/map_control.rs::draw_tile()`

### 实现细节

**方法签名**:
```rust
fn draw_tile(&self, ctx: &mut Context, canvas: &mut Canvas, lib_index: i32, image_index: usize, x: f32, y: f32) -> GameResult<()>
```

**实现流程**:
1. 从 `MapLibs[lib_index]` 获取库
2. 调用 `lib.load_rgba_data(image_index)` 加载RGBA数据
3. 使用 `Image::from_pixels()` 创建ggez纹理
4. 计算绘制位置(考虑图像偏移 `info.x`, `info.y`)
5. 调用 `canvas.draw()` 绘制到屏幕

**代码实现**:
```rust
fn draw_tile(&self, ctx: &mut Context, canvas: &mut Canvas, lib_index: i32, image_index: usize, x: f32, y: f32) -> GameResult<()> {
    use ggez::graphics::{Image, DrawParam};
    
    // 获取 MapLibrary
    if let Some(map_lib) = get_map_library(lib_index) {
        let mut lib = map_lib.lock().unwrap();
        
        // 加载图像数据
        if let Ok((info, rgba_data)) = lib.load_rgba_data(image_index) {
            // 创建 ggez Image
            let img = Image::from_pixels(
                ctx,
                &rgba_data,
                ggez::graphics::ImageFormat::Rgba8UnormSrgb,
                info.width as u32,
                info.height as u32,
            );
            
            // 计算绘制位置(考虑图像偏移)
            let draw_x = x + info.x as f32;
            let draw_y = y + info.y as f32;
            
            // 绘制到 canvas
            canvas.draw(&img, DrawParam::default().dest([draw_x, draw_y]));
        }
    }
    
    Ok(())
}
```

### 关键发现

1. **ggez API**: `Image::from_pixels()` 直接返回 `Image`,不是 `Result<Image, _>`
2. **字段名称**: `ImageInfo` 使用 `x`/`y` 而不是 `offset_x`/`offset_y`
3. **绘制方法**: `canvas.draw()` 需要引用 `&Image`,返回类型是 unit

### 调用更新

所有调用 `draw_tile` 的地方都添加了 `ctx` 参数:
- `draw_floor()` 中的 Back 层渲染
- `draw_objects()` 中的 3 种动画层渲染

## 任务 2: 实现 UserObject 获取真实位置

### 实现位置
`src/scenes/game_scene.rs::draw()`

### 实现细节

**UserPosition 数据流**:
```
UserObject.player.map_object.current_location (Point)
    └─> UserPosition { x, y }

UserObject.player.map_object.offset_move (Point)
    └─> UserPosition { offset_x, offset_y }
```

**代码实现**:
```rust
pub fn draw(&mut self, ctx: &mut ggez::Context, canvas: &mut Canvas) -> GameResult<()> {
    if let Some(map_control) = &mut self.map_control {
        // 从 user 对象获取实际位置
        let user_pos = if let Some(user) = &self.user {
            map_control::UserPosition {
                x: user.player.map_object.current_location.x,
                y: user.player.map_object.current_location.y,
                offset_x: user.player.map_object.offset_move.x,
                offset_y: user.player.map_object.offset_move.y,
            }
        } else {
            // 如果没有 user 对象,使用默认中心位置
            map_control::UserPosition {
                x: map_control.width / 2,
                y: map_control.height / 2,
                offset_x: 0,
                offset_y: 0,
            }
        };
        
        map_control.draw(ctx, canvas, &user_pos)?;
    }
    // ...
}
```

### UserObject 结构分析

**类型层次**:
```
UserObject
    ├─ player: PlayerObject
    │   └─ map_object: MapObject
    │       ├─ current_location: Point  (地图坐标)
    │       └─ offset_move: Point       (移动偏移,用于平滑动画)
    └─ (其他用户特定字段: hp, mp, inventory, etc.)
```

**C# 对应关系**:
- C#: `User.Movement.X/Y` → Rust: `user.player.map_object.current_location`
- C#: `User.OffSetMove.X/Y` → Rust: `user.player.map_object.offset_move`

### 降级策略

如果 `self.user` 为 `None`,使用地图中心作为默认视角:
```rust
x: map_control.width / 2,
y: map_control.height / 2,
```

这确保即使没有玩家对象,地图仍能正常渲染。

- 错误处理和转换

**代码实现**:
```rust
pub fn load_map(&mut self, map_path: &str) -> GameResult<()> {
    use crate::objects::MapReader;
    
    tracing::info!("🗺️  Loading map: {}", map_path);
    
    // 加载地图数据
    match MapReader::new(map_path) {
        Ok(reader) => {
            // 创建 MapControl
            let map_control = MapControl::from_map_reader(reader);
            
            tracing::info!("✅ Map loaded: {} ({}x{})", 
                map_control.filename, 
                map_control.width, 
                map_control.height
            );
            
            self.map_control = Some(map_control);
            Ok(())
        }
        Err(e) => {
            tracing::error!("❌ Failed to load map: {}", e);
            Err(ggez::GameError::CustomError(format!("Failed to load map: {}", e)))
        }
    }
}
```

**支持的地图格式**:
- C# 自定义格式 (Type 100)
- Wemade Mir3 格式 (Type 5)
- Shanda Mir3 格式 (Type 6)
- Wemade AntiHack 格式 (Type 4)

## 性能考虑

### 当前实现

**问题**: 每帧为每个瓦片调用 `Image::from_pixels()`
- 创建大量临时纹理
- GPU 上传开销巨大
- 无缓存机制

**性能影响**:
- 估计: 100-200 瓦片/帧 × 30-60 FPS = 3000-12000 纹理创建/秒
- 每个纹理: 48×32 × 4字节 = 6144字节
- 总带宽: 18-73 MB/秒上传到 GPU

### 优化方向

#### 1. 纹理缓存 (P0 - 关键)

```rust
// MLibrary 中添加缓存
struct MLibrary {
    texture_cache: HashMap<usize, Image>,  // image_index -> 缓存的 Image
}

fn get_or_create_texture(&mut self, ctx: &mut Context, index: usize) -> Option<&Image> {
    if !self.texture_cache.contains_key(&index) {
        let (info, rgba_data) = self.load_rgba_data(index).ok()?;
        let img = Image::from_pixels(ctx, &rgba_data, ...);
        self.texture_cache.insert(index, img);
    }
    self.texture_cache.get(&index)
}
```

**预期提升**: 100-1000倍(首帧慢,后续帧只查找缓存)

#### 2. 纹理图集 (P1)

将多个小纹理合并到大纹理:
```rust
struct TextureAtlas {
    image: Image,
    regions: HashMap<(i32, usize), Rect>,  // (lib_index, image_index) -> UV坐标
}
```

**预期提升**: 减少draw call,提升10-50倍

#### 3. 批量渲染 (P2)

使用 ggez InstanceArray 或 SpriteBatch:
```rust
let mut batch = SpriteBatch::new(atlas_image);
for tile in visible_tiles {
    batch.add(DrawParam::new()...);
}
canvas.draw(&batch, DrawParam::default());
```

**预期提升**: 减少CPU开销,提升2-5倍
