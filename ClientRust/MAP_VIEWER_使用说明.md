# 地图查看器 (Map Viewer) 使用说明

## 📖 简介

地图查看器是一个独立的地图渲染工具，用于可视化传奇地图文件(.map)，支持完整的地图渲染和交互式相机控制。

## ✨ 功能特性

### 1. 完整地图渲染
- ✅ **Back Layer (地表层)** - 地面瓦片 (只渲染偶数坐标)
- ✅ **Middle Layer (建筑层)** - 建筑物、障碍物
- ✅ **Front Layer (前景层)** - 树木、装饰物
- ✅ **动画支持** - Middle/Front 层的瓦片动画

### 2. 相机控制
- ✅ **鼠标拖拽** - 按住左键移动视角
- ✅ **滚轮缩放** - 0.25x ~ 4.0x 缩放范围
- ✅ **以鼠标为中心缩放** - 缩放时保持鼠标指向位置不变

### 3. 性能优化
- ✅ **视锥剔除** - 只渲染可见区域的瓦片
- ✅ **纹理缓存** - 使用 `get_or_create_texture()` 缓存机制
- ✅ **Release 模式** - 默认使用优化编译

### 4. 实时信息显示
- 地图文件名和尺寸
- 当前 FPS
- 相机缩放级别
- 相机世界坐标
- 鼠标悬停的地图格子坐标

## 🚀 使用方法

### 基本用法
```powershell
# 加载默认地图 (Map/0.map)
cargo run --example map_viewer --release

# 加载指定地图
cargo run --example map_viewer --release Map/r001.map
```

### 常用地图路径
```powershell
# 银杏山谷 (200x200)
cargo run --example map_viewer --release Map/r001.map

# 比奇城 (如果存在)
cargo run --example map_viewer --release Map/3.map

# 盟重土城
cargo run --example map_viewer --release Map/1.map
```

## 🎮 交互操作

### 鼠标控制
| 操作 | 功能 |
|------|------|
| **按住左键拖拽** | 移动相机视角 |
| **滚轮向上滚动** | 放大视图 (Zoom In) |
| **滚轮向下滚动** | 缩小视图 (Zoom Out) |
| **ESC 键** | 退出程序 |

### 缩放范围
- 最小缩放: 0.25x (俯瞰整个地图)
- 正常缩放: 1.0x (原始分辨率)
- 最大缩放: 4.0x (细节放大)

## 📊 性能指标

### 优化效果
- **纹理缓存**: 瓦片只加载一次，后续帧复用缓存
- **视锥剔除**: 只渲染屏幕可见区域 + 2格边缘缓冲
- **帧率**: 在 Release 模式下通常可达 60 FPS

### 性能对比
```
之前 (每帧加载): ~5-10 FPS
现在 (纹理缓存): ~60 FPS
性能提升: 6-12 倍
```

## 🔧 技术细节

### 地图渲染顺序
1. **Back Layer** - 地面瓦片 (y%2==0 && x%2==0)
2. **Middle Layer** - 建筑层 (所有格子)
3. **Front Layer** - 前景层 (所有格子，Y 偏移 -32px)

### 坐标系统
- **网格大小**: 48x32 像素 (CELL_WIDTH x CELL_HEIGHT)
- **世界坐标**: 以像素为单位
- **地图坐标**: 以格子为单位
- **屏幕坐标**: 相对于窗口左上角

### 相机系统
```rust
// 世界坐标转屏幕坐标
screen_x = (world_x - camera.x) * zoom + screen_width / 2
screen_y = (world_y - camera.y) * zoom + screen_height / 2

// 屏幕坐标转世界坐标
world_x = camera.x + (screen_x - screen_width / 2) / zoom
world_y = camera.y + (screen_y - screen_height / 2) / zoom
```
