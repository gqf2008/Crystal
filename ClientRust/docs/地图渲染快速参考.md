## 碰撞层偏移修正

**问题**: 碰撞层显示位置错误

**修复**: 碰撞层向下偏移一个格子（32px）

**位置**: `src/ecs/systems/render/debug_system.rs`

**修改**:
```rust
// 修改前（错误）
let world_y = ((grid_y - 1) * CELL_HEIGHT) as f32;  // 向上偏移

// 修改后（正确）
let world_y = ((grid_y + 1) * CELL_HEIGHT) as f32;  // 向下偏移
```

**原因**: 碰撞判定基于角色脚底位置，位于格子下方

## 关键代码注释总结

### 1. 坐标系统

```rust
// 格子坐标 → 世界坐标
let world_x = (grid_x * CELL_WIDTH) as f32;   // * 48
let world_y = (grid_y * CELL_HEIGHT) as f32;  // * 32

// 世界坐标 → 屏幕坐标
let screen_x = (world_x - camera_pos.x) * camera.zoom + screen_width/2;
let screen_y = (world_y - camera_pos.y) * camera.zoom + screen_height/2;
```

### 2. Y轴偏移规则

```rust
// Back层：永远不偏移
adjusted_y = world_y

// Middle/Front层标准尺寸（48x32或96x64）：不偏移
adjusted_y = world_y

// Middle/Front层非标准尺寸：底部对齐
adjusted_y = world_y + CELL_HEIGHT - tile_h

// Front层混合特殊库（14/27/100-199）：额外向上2格
adjusted_y = world_y - 2*CELL_HEIGHT
```

### 3. 图像内部偏移

```rust
// 仅在以下情况应用 info.x/info.y:
// 1. Front层 + Blend + 库14/27/100-199
// 2. Front层 + Blend + 索引2723-2732
// 3. 库28 + 非空偏移

// Back/Middle层：永远不应用
// 其他Front层：永远不应用
```

### 4. 混合模式

```rust
// use_blend == true → ADD混合（发光效果）
canvas.set_blend_mode(ggez::graphics::BlendMode::ADD);

// use_blend == false → Normal混合（默认）
canvas.set_blend_mode(ggez::graphics::BlendMode::ALPHA);
```

### 5. 视口裁剪

```rust
// Front层底部扩展800px（高大建筑）
let bottom_extra = if matches!(layer, TileLayer::Front) {
    800.0
} else {
    200.0  // Back/Middle层200px
};

// 裁剪判断
if world_x > view_right + 200.0
    || world_x < view_left - 200.0
    || world_y > view_bottom + bottom_extra
    || world_y < view_top - 200.0
{
    continue;  // 跳过不可见瓦片
}
```

## 常见问题排查

### Back层瓦片错位
**原因**: 错误应用了图像内部偏移（info.x/info.y）  
**检查**: `should_apply_offset` 逻辑，确保Back层返回`false`

### 光效（火把）偏移过多或过少
**原因**: Y轴偏移计算错误  
**检查**: 特殊库判断（14/27/100-199），应该使用`world_y - 2*CELL_HEIGHT`

### 建筑物悬空
**原因**: 非标准尺寸偏移计算错误  
**检查**: `world_y + CELL_HEIGHT - tile_h` 公式是否正确

### 碰撞层显示错位
**原因**: 偏移方向错误  
**检查**: 应该是`(grid_y + 1) * CELL_HEIGHT`，向下偏移
