### ✅ 1.2 GameState 事件收集机制

**位置**: `src/ecs/game_app.rs`

**核心流程**:
```rust
impl EventHandler for GameState {
    fn update(&mut self, ctx: &mut Context) -> GameResult {
        self.collect_network_events();    // 1. 收集网络事件
        
        // 2. Scene 处理事件（从 GlobalEvents 读取）
        if let Some(next_scene) = self.current_scene.update(ctx, &mut self.world)? {
            self.switch_scene(ctx, next_scene)?;
        }
        
        self.clear_global_events();       // 3. 清理事件
        Ok(())
    }
}
```

**输入事件收集**（通过 ggez 事件回调）:
```rust
fn mouse_button_down_event(&mut self, button, x, y) {
    self.world.global_events_mut().input_events.push(
        InputEvent::MouseDown { button, x, y }
    );
}
```

**优点**:
- ✅ **清晰的生命周期**: 收集 → 处理 → 清理
- ✅ **避免事件污染**: 每帧结束自动清理
- ✅ **场景切换安全**: 切换时额外清理，防止旧场景事件泄露

```rust
pub struct EventLog {
    events: Vec<(Instant, GameEvent)>,
    max_capacity: usize,
}

impl EventLog {
    pub fn record(&mut self, event: GameEvent) {
        self.events.push((Instant::now(), event));
        if self.events.len() > self.max_capacity {
            self.events.remove(0);
        }
    }
    
    pub fn replay(&self, from: Instant) -> impl Iterator<Item = &GameEvent> {
        self.events.iter()
            .filter(move |(time, _)| *time >= from)
            .map(|(_, event)| event)
    }
}
```

```rust
    where F: FnOnce() {
```
