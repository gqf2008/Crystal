## 概述

瓦片动画系统负责更新地图上所有动画瓦片的帧索引，实现火把、蜡烛、水流、旗帜等动态效果。

### 特性

✅ **已实现**：
- 基于全局计数器的帧更新算法（模拟 C# 原版逻辑）
- 支持不同帧数和帧间隔的动画
- 可通过 `A` 键全局启用/禁用动画
- 支持独立控制动画瓦片显示（`D` 键）
- 60 FPS 基准时钟

🚀 **未来优化**：
- 视口裁剪优化（只更新可见动画瓦片）
- 批量更新优化
- 动画分组管理

## 核心概念

### 1. AnimatedTile 组件

```rust
pub struct AnimatedTile {
    pub frame_count: u8,       // 总帧数（例如：火把有4帧）
    pub frame_interval: u8,    // 帧间隔（控制播放速度）
    pub base_image_index: i32, // 基础图像索引（第一帧）
}
```

**示例**：
- 火把：`frame_count=4, frame_interval=1, base_image_index=2723`
- 蜡烛：`frame_count=6, frame_interval=1, base_image_index=2100`

### 2. MapTile 组件

```rust
pub struct MapTile {
    pub grid_x: i32,
    pub grid_y: i32,
    pub layer: TileLayer,
    pub library_index: i16,
    pub image_index: i32,  // ← 动画系统会更新这个字段
    pub use_blend: bool,
    pub brightness: f32,
    pub z_order: i32,
}
```

**关键点**：
- 同一个实体同时拥有 `MapTile` 和 `AnimatedTile` 组件
- `image_index` 会在每帧更新为：`base_image_index + frame_offset`

### 3. 全局动画计数器

```rust
pub struct TileAnimationSystem {
    animation_counter: u32,      // 全局计数器（模拟 C# 的 AnimationCount）
    accumulated_time: f32,       // 累积时间（秒）
    counter_interval: f32,       // 计数器递增间隔（1/60 秒）
}
```

## 实现细节

### 1. 帧偏移计算算法

**C# 原版逻辑**：
```csharp
// C# GameScene.cs
index += (AnimationCount % (animation + (animation * animationTick))) / (1 + animationTick);
```

**Rust 实现**：
```rust
fn calculate_frame_offset(&self, frame_count: u8, frame_interval: u8) -> i32 {
    if frame_count == 0 {
        return 0;
    }

    // total_ticks = animation + (animation * animationTick)
    let total_ticks = (frame_count as u32 + frame_count as u32 * frame_interval as u32);
    
    // divisor = 1 + animationTick
    let divisor = 1 + frame_interval as u32;
    
    // frame_offset = (counter % total_ticks) / divisor
    ((self.animation_counter % total_ticks) / divisor) as i32
}
```

**算法解析**：

假设火把动画（4帧，间隔1）：
```
frame_count = 4
frame_interval = 1

total_ticks = 4 + (4 * 1) = 8
divisor = 1 + 1 = 2

计数器范围: 0 ~ 7 (循环)
帧偏移计算:
  counter=0 → offset=0 → 显示第1帧
  counter=1 → offset=0 → 显示第1帧
  counter=2 → offset=1 → 显示第2帧
  counter=3 → offset=1 → 显示第2帧
  counter=4 → offset=2 → 显示第3帧
  counter=5 → offset=2 → 显示第3帧
  counter=6 → offset=3 → 显示第4帧
  counter=7 → offset=3 → 显示第4帧
  counter=8 → offset=0 → 循环到第1帧
```

**效果**：每帧显示 2 个游戏循环 (1/30 秒 @ 60 FPS)

### 2. 时间管理

```rust
// 累积 delta_time
self.accumulated_time += delta_time;

// 每 1/60 秒递增计数器
while self.accumulated_time >= self.counter_interval {
    self.animation_counter = self.animation_counter.wrapping_add(1);
    self.accumulated_time -= self.counter_interval;
}
```

**特点**：
- 使用 `wrapping_add` 避免溢出 panic
- 累积时间确保在不同帧率下动画速度一致
- 计数器循环到 `u32::MAX` 后自动归零

### 3. 批量更新

```rust
// 查询所有拥有 MapTile 和 AnimatedTile 的实体
for (_, (tile, anim)) in world.query_mut::<(&mut MapTile, &AnimatedTile)>() {
    let frame_offset = self.calculate_frame_offset(anim.frame_count, anim.frame_interval);
    tile.image_index = anim.base_image_index + frame_offset;
}
```

**性能**：
- 单次遍历所有动画瓦片
- 时间复杂度：O(n)，n 为动画瓦片数量
- 典型地图：约 100-500 个动画瓦片

## 性能优化

### 当前性能

**测试场景**：
- 地图尺寸：200x200
- 动画瓦片数量：约 300 个
- 更新耗时：<0.1ms @ 60 FPS

### 优化方向

#### 1. 视口裁剪优化 🎯 **推荐**

**问题**：当前会更新所有动画瓦片，包括不可见的

**解决方案**：
```rust
// 伪代码
fn update(&mut self, world: &mut World, delta_time: f32) -> GameResult {
    // 获取相机视口范围
    let viewport = world.get_camera_viewport();
    
    // 只更新可见范围内的动画瓦片
    for (_, (tile, anim)) in world.query_mut::<(&mut MapTile, &AnimatedTile)>() {
        if !viewport.contains(tile.grid_x, tile.grid_y) {
            continue; // 跳过不可见瓦片
        }
        
        let frame_offset = self.calculate_frame_offset(...);
        tile.image_index = anim.base_image_index + frame_offset;
    }
}
```

**预期收益**：
- 大地图场景下性能提升 50-80%
- 小地图无明显差异

#### 2. 批量更新优化

**问题**：每个瓦片都单独计算帧偏移

**解决方案**：
```rust
// 按 (frame_count, frame_interval) 分组
let mut groups: HashMap<(u8, u8), Vec<Entity>> = HashMap::new();

// 分组收集
for (entity, anim) in world.query::<&AnimatedTile>().iter() {
    groups.entry((anim.frame_count, anim.frame_interval))
        .or_default()
        .push(entity);
}

// 批量更新（每组只计算一次帧偏移）
for ((frame_count, frame_interval), entities) in groups {
    let offset = self.calculate_frame_offset(frame_count, frame_interval);
    
    for entity in entities {
        let mut tile = world.get::<&mut MapTile>(entity).unwrap();
        let anim = world.get::<&AnimatedTile>(entity).unwrap();
        tile.image_index = anim.base_image_index + offset;
    }
}
```

**预期收益**：
- 减少重复计算
- 提升 10-20%

#### 3. 固定时间步长

**问题**：变化的 `delta_time` 可能导致动画速度不稳定

**当前实现**：已使用固定 1/60 秒计数器间隔 ✅

## 常见问题

### Q1: 为什么动画看起来很卡顿？

**可能原因**：
1. ✅ 检查 `RenderConfig.show_animations` 是否为 `true`
2. ✅ 检查 `RenderConfig.max_fps` 设置（建议 60）
3. ✅ 检查是否启用了 VSync（`WindowSetup::vsync(true)`）

### Q2: 动画速度与 C# 版本不同？

**解决方案**：
- 调整 `counter_interval`（当前 1/60 秒）
- 检查 `frame_interval` 是否与 C# 一致

### Q3: 如何添加新的动画瓦片？

**步骤**：
1. 在地图加载时创建 `MapTile` + `AnimatedTile` 实体
2. 确保 `base_image_index` 指向第一帧
3. 设置正确的 `frame_count` 和 `frame_interval`

示例见 `map_loader.rs:106-115`。

### Q4: 如何暂停特定瓦片的动画？

**方法1**：删除 `AnimatedTile` 组件
```rust
world.remove_one::<AnimatedTile>(entity);
```

**方法2**：设置 `frame_count = 1`
```rust
let mut anim = world.get::<&mut AnimatedTile>(entity).unwrap();
anim.frame_count = 1; // 只有一帧，不会播放动画
```
