## ✅ 正确的事件清理机制

### 1. 清理位置

**文件**: `src/ecs/game_app.rs`

```rust
impl EventHandler for GameState {
    fn update(&mut self, ctx: &mut Context) -> GameResult {
        // 1. 收集网络事件
        self.collect_network_events();
        
        // 2. 场景处理（从 GlobalEvents 读取事件）
        if let Some(next_scene) = self.current_scene.update(ctx, &mut self.world)? {
            self.switch_scene(ctx, next_scene)?;
        }
        
        // 3. ✅ 清理所有事件（统一处理）
        self.clear_global_events();
        
        Ok(())
    }
}

fn clear_global_events(&mut self) {
    self.world.global_events_mut().clear_frame_events();
}
```

### 2. 清理时机

```
每帧循环:
┌─────────────────────────────────────┐
│ 1. collect_network_events()         │  收集网络事件
├─────────────────────────────────────┤
│ 2. Scene::update(world)             │  场景/系统处理
│    └─> 读取 world.global_events()  │  所有事件
├─────────────────────────────────────┤
│ 3. clear_global_events() ✅         │  清理所有事件
│    └─> clear_frame_events()         │
└─────────────────────────────────────┘
```

### 3. 清理内容

**文件**: `src/ecs/components/events.rs`

```rust
impl GlobalEvents {
    pub fn clear_frame_events(&mut self) {
        if self.has_events() {
            self.input_events.clear();      // 清理输入事件
            self.net_events.clear();        // 清理网络事件
        }
        
        if self.enable_logging && self.frame_event_count > 0 {
            tracing::debug!("🧹 清理事件: {} 个", self.frame_event_count);
        }
        self.frame_event_count = 0;
    }
}
```

## 🎯 关键要点

1. ✅ **没有独立的清理系统**: 事件清理不是 ECS System
2. ✅ **GameState 统一管理**: 在 update() 末尾清理
3. ✅ **每帧自动清理**: 防止事件污染和重放
4. ✅ **场景切换也清理**: `switch_scene()` 时额外清理
5. ✅ **简单可靠**: 不需要优先级调度，直接在主循环中处理
