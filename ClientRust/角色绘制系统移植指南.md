# PlayerObject 角色绘制系统分析

## 问题诊断

**当前问题**:
1. ✅ 使用了 **ChrSel** 库 (角色选择界面的静态预览图)
2. ❌ 应该使用 **CArmours/AArmours/ARArmours** 库 (实际游戏中的角色装备纹理)
3. ❌ 没有动画系统 (FrameSet, Frame, FrameIndex)
4. ❌ 没有根据动作计算帧索引 (DrawFrame)

## C# 原版角色系统架构

### 1. 核心图库系统

**关键库命名规则**:
- `CArmours` = Common Armours (通用装备库,所有非特殊职业)
- `AArmours` = Assassin Armours (刺客装备库)
- `ARArmours` = Archer Armours (弓箭手装备库)
- `CHair` = Common Hair (通用发型)
- `CWeapons` = Common Weapons (通用武器)
- `CHumEffect` = Common Human Effects (人物特效,如翅膀)

### 2. 动画系统 (FrameSet)

```csharp
// 帧集合 - 存储所有动作的帧数据
public FrameSet Frames;

// 当前帧
public Frame Frame;

// 帧索引 (自动递增)
public int FrameIndex;       // 当前动画帧索引 (0,1,2...)
public int FrameInterval;    // 帧间隔 (毫秒)

// 绘制帧 = 动作基础帧 + 方向偏移 + 当前帧索引
public int DrawFrame
{
    get
    {
        if (Frame == null) return 0;
        return Frame.Start + (int)Direction * Frame.Count + FrameIndex;
    }
}
```

**Frame 结构**:
```csharp

    public int EffectCount;  // 特效帧数
```

### 3. 绘制流程

```csharp
// PlayerObject.cs line 5001
public override void Draw()
{
    DrawBehindEffects(Settings.Effect);  // 后置特效
    
    float oldOpacity = DXManager.Opacity;
    if (Hidden && !DXManager.Blending) 
        DXManager.SetOpacity(0.5F);      // 隐身半透明
    
    DrawMount();  // 坐骑
    
    // 左侧/上侧方向: 先画武器
    if (Direction == MirDirection.Left || Direction == MirDirection.Up || 
        Direction == MirDirection.UpLeft || Direction == MirDirection.DownLeft)
        DrawWeapon();
    else
        DrawWeapon2();
    
    DrawBody();  // ← 关键! 绘制身体
    
    // 上半部分方向: 先画头发再画翅膀
    if (Direction == MirDirection.Up || Direction == MirDirection.UpLeft || 
        Direction == MirDirection.UpRight || Direction == MirDirection.Right || 
        Direction == MirDirection.Left)
    {
        DrawHead();
        if (this != User) DrawWings();
    }
    else
    {
        if (this != User) DrawWings();
        DrawHead();
    }
    
    // 右侧/下侧方向: 后画武器
    if (Direction == MirDirection.UpRight || Direction == MirDirection.Right || 
        Direction == MirDirection.DownRight || Direction == MirDirection.Down)
        DrawWeapon();
    else
        DrawWeapon2();
    
    DXManager.SetOpacity(oldOpacity);
}
```

```csharp
public void DrawBody()
{
    bool oldGrayScale = DXManager.GrayScale;
    Color drawColour = ApplyDrawColour();
    
    // 关键: BodyLibrary.Draw(DrawFrame + ArmourOffSet, DrawLocation, ...)
    if (BodyLibrary != null)

            DrawLocation,              // ← 屏幕位置

        );
    
    DXManager.SetGrayscale(oldGrayScale);
}
```

### 5. 帧索引计算详解

```
最终绘制帧 = DrawFrame + ArmourOffSet

DrawFrame = Frame.Start + Direction * Frame.Count + FrameIndex

例子: 男战士站立朝南 (Direction=4)
- Frame.Start = 0
- Direction = 4 (Down)
- Frame.Count = 4 (每方向4帧)
- FrameIndex = 0,1,2,3 (循环)
- DrawFrame = 0 + 4*4 + 0~3 = 16~19

如果是女战士:
- ArmourOffSet = 808
- 最终帧 = 16~19 + 808 = 824~827
```

**帧布局图** (CArmours 库):
```
帧索引    方向         性别      动作
0-31      全8方向 * 4  男战士    站立
32-79     全8方向 * 6  男战士    行走
80-127    全8方向 * 6  男战士    跑步
128-175   全8方向 * 6  男战士    攻击1
...
808-839   全8方向 * 4  女战士    站立
840-887   全8方向 * 6  女战士    行走
...
```

### 阶段1: 最小可行版 (MVP)

**目标**: 显示静态站立的战士角色

```rust
// 1. 修改 PlayerObject 结构
pub struct PlayerObject {
    // 基础属性
    pub gender: MirGender,
    pub class: MirClass,
    pub armour: i32,      // 装备ID
    pub hair: u8,         // 发型ID
    pub weapon: i32,      // 武器ID
    
    // 动画状态
    pub current_action: MirAction,
    pub frame_index: usize,      // 当前帧索引
    pub frame_interval: u64,     // 帧间隔 (ms)
    pub last_frame_time: Instant,
    
    // 帧数据 (简化版)
    pub frame_start: usize,      // 当前动作起始帧
    pub frame_count: usize,      // 每方向帧数
}

// 2. 计算 DrawFrame
impl PlayerObject {
    fn get_draw_frame(&self) -> usize {
        let direction_offset = (self.direction as usize) * self.frame_count;
        self.frame_start + direction_offset + self.frame_index
    }
    
    fn get_armour_offset(&self) -> usize {
        match self.gender {
            MirGender::Male => 0,
            MirGender::Female => 808,
        }
    }
    
    fn get_final_frame(&self) -> usize {
        self.get_draw_frame() + self.get_armour_offset()
    }
}

// 3. 绘制函数
fn draw_player_with_camera(
    ctx: &mut Context,
    canvas: &mut Canvas,
    player: &PlayerObject,
    camera: &Camera,
) -> GameResult {
    use crate::graphics::libraries::{get_library, LibraryName};
    
    // 获取正确的装备库
    let library_name = match player.class {
        MirClass::Warrior | MirClass::Wizard | MirClass::Taoist => {
            // 通用库
            LibraryName::CArmours(player.armour as usize)
        }
        MirClass::Assassin => {
            LibraryName::AArmours(player.armour as usize)
        }
        MirClass::Archer => {
            // 简化: 先用通用库
            LibraryName::CArmours(player.armour as usize)
        }
    };
    
    if let Some(lib_arc) = get_library(library_name) {
        if let Ok(mut lib) = lib_arc.try_lock() {
            let final_frame = player.get_final_frame();
            let (screen_x, screen_y) = camera.world_to_screen(
                player.world_x,
                player.world_y,
            );
            
            lib.draw_with_color(
                ctx,
                canvas,
                final_frame,
                screen_x,
                screen_y,
                Color::WHITE,
                true, // use_offset
            )?;
        }
    }
    
    Ok(())
}
```

### 阶段2: 添加动画更新

```rust
impl PlayerObject {
    pub fn update(&mut self, delta_time: f32) {
        let now = Instant::now();
        let elapsed = now.duration_since(self.last_frame_time).as_millis() as u64;
        
        if elapsed >= self.frame_interval {
            self.frame_index = (self.frame_index + 1) % self.frame_count;
            self.last_frame_time = now;
        }
    }
    
    pub fn set_action(&mut self, action: MirAction) {
        if self.current_action == action {
            return;
        }
        
        self.current_action = action;
        self.frame_index = 0;
        
        // 根据动作设置帧数据
        match action {
            MirAction::Standing => {
                self.frame_start = 0;
                self.frame_count = 4;
                self.frame_interval = 500;
            }
            MirAction::Walking => {
                self.frame_start = 32;
                self.frame_count = 6;
                self.frame_interval = 100;
            }
            MirAction::Running => {
                self.frame_start = 80;
                self.frame_count = 6;
                self.frame_interval = 80;
            }
            MirAction::Attack1 => {
                self.frame_start = 128;
                self.frame_count = 6;
                self.frame_interval = 100;
            }
            _ => {
                self.frame_start = 0;
                self.frame_count = 1;
                self.frame_interval = 100;
            }
        }
    }
}
```

## 关键差异总结

| 方面 | 当前Rust版 | C#原版 | 需要修改 |
|------|-----------|--------|---------|
| 图库 | ❌ ChrSel (静态预览) | ✅ CArmours (动画装备) | 替换库 |
| 帧计算 | ❌ 简单索引 | ✅ DrawFrame + Offset | 添加计算 |
| 动画 | ❌ 无 | ✅ FrameIndex 自动递增 | 添加 update() |
| 动作 | ❌ 固定站立 | ✅ MirAction 切换 | 添加 set_action() |
| 偏移 | ❌ 无 | ✅ ArmourOffSet (性别) | 添加计算 |
| 方向 | ✅ 有 | ✅ 有 | 已实现 |
