# 项目架构说明 - Mir2 Rust 客户端

## 📁 项目结构

```
ClientRust/
├── src/
│   ├── bin/
│   │   ├── map_viewer_ecs.rs   # 🗺️  地图查看器 (单机工具)
│   │   └── mir2x.rs            # 🎮 完整客户端 (联网游戏)
│   ├── ecs/                    # ♻️  ECS 架构 (共享)
│   │   ├── components.rs       # 组件定义
│   │   ├── systems/            # 系统实现
│   │   │   ├── camera.rs       # 摄像机系统
│   │   │   ├── player.rs       # 角色系统
│   │   │   ├── render.rs       # 渲染系统
│   │   │   ├── animation.rs    # 动画系统
│   │   │   └── network.rs      # 网络系统 (仅 mir2x)
│   │   └── mod.rs
│   ├── scenes/                 # 🎬 场景系统
│   ├── network/                # 🌐 网络通信
│   ├── graphics/               # 🎨 图形资源
│   └── lib.rs
└── Cargo.toml
```

## 🎯 两个入口点

### 1. map_viewer_ecs.rs - 地图查看器

**定位:** 单机工具,用于预览和调试地图

**功能:**
- ✅ 地图加载与渲染
- ✅ 鼠标交互 (拖拽、缩放、寻路)
- ✅ 角色动画演示
- ✅ 边缘滚屏
- ✅ 调试工具 (网格、障碍物、路径可视化)

**运行:**
```bash
cargo run --bin map_viewer_ecs --release
```

**特点:**
- 不需要服务器
- 快速启动
- 专注于地图编辑和调试

---

### 2. mir2x.rs - 完整客户端

**定位:** 联网游戏客户端

**功能计划:**
- 🚧 网络连接
- 🚧 登录系统
- 🚧 角色选择
- 🚧 游戏场景
- 🚧 多人在线同步
- 🚧 战斗系统
- 🚧 UI 系统

**运行:**
```bash
cargo run --bin mir2x --release
```

**特点:**
- 连接到服务器
- 完整游戏功能
- 多人在线

---

## ♻️ ECS 架构 (共享代码)

### 组件 (Components)

**核心组件:**
- `Position` - 位置
- `Camera` - 摄像机
- `Player` - 角色
- `MapTile` - 地图瓦片
- `AnimatedTile` - 动画瓦片
- `Door` - 门

**网络组件 (仅 mir2x):**
- `NetworkComponent` - 网络状态
- `OtherPlayer` - 其他玩家
- `Monster` - 怪物
- `NPC` - NPC

### 系统 (Systems)

**共享系统:**
- `CameraSystem` - 摄像机控制 + 边缘滚屏
- `PlayerSystem` - 角色移动 + 寻路
- `RenderSystem` - 地图渲染
- `AnimationSystem` - 动画更新
- `DoorSystem` - 门动画

**网络系统 (仅 mir2x):**
- `NetworkSystem` - 网络包处理 + 状态同步

## 🛠️ 开发流程

### 地图查看器开发
```bash
# 编辑代码
code src/bin/map_viewer_ecs.rs

# 编译运行
cargo run --bin map_viewer_ecs
```

### 完整客户端开发
```bash
# 编辑代码
code src/bin/mir2x.rs
code src/ecs/systems/network.rs

# 编译运行
cargo run --bin mir2x
```

### 共享系统开发
```bash
# 编辑共享系统
code src/ecs/systems/camera.rs

# 两个入口都会受益
cargo run --bin map_viewer_ecs  # 测试地图查看器
cargo run --bin mir2x           # 测试完整客户端
```

## 🎓 设计理念

1. **分离关注点**
   - 地图查看器 = 单机调试工具
   - 完整客户端 = 联网游戏

2. **代码复用**
   - ECS 系统在两者间共享
   - 减少重复代码

3. **渐进式开发**
   - 先完善地图查看器
   - 再构建完整客户端
   - 每步都可测试

4. **清晰架构**
   - 每个系统独立文件
   - 模块化设计
   - 易于维护和扩展
