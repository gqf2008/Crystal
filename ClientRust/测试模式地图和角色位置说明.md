# 🎮 测试模式 - 地图和角色位置说明

## 问题
**Q: 不接入服务器网络，是怎么确定用哪张地图和角色在什么位置的？**

## 答案总结

当前测试模式使用了**硬编码的默认值**，分为三个部分：

### 1️⃣ 地图选择
📍 **位置**: `src/bevy/scenes/game_scene/rendering/init.rs`

```rust
pub fn setup_game_rendering(
    mut commands: Commands,
    mut load_request: ResMut<MapLoadRequest>,
) {
    // ...
    // ⚠️ 硬编码: 始终加载地图 "0"
    load_request.request("0".to_string());
    info!("🗺️ 已请求加载地图: 0");
}
```

**结果**: 测试模式总是加载 `Map/0.map` 文件 (700×700 的比奇城)

### 3️⃣ 测试地图数据
📍 **位置**: `src/bevy/scenes/game_scene/map_systems.rs`

```rust
pub fn load_map_system(
    mut map_data: ResMut<MapData>,
    mut game_state: ResMut<GameSceneState>,
) {
    // ⚠️ 硬编码: 创建一个 100×100 的测试地图
    *map_data = MapData::new(
        1,                         // 地图 ID = 1
        "Mirror World".to_string(), // 地图名
        100,                        // 宽度 = 100
        100,                        // 高度 = 100
    );
    
    // 初始化地面瓦片
    for y in 0..100 {
        for x in 0..100 {
            let mut tile = MapTile {
                tile_x: x,
                tile_y: y,
                layer: 0,
                tile_id: 1,  // 地面瓦片
                walkable: true,
            };
            
            // ⚠️ 硬编码: 边界不可行走
            if (x < 5) || (x > 95) || (y < 5) || (y > 95) {
                tile.walkable = false;
                tile.tile_id = 2;
            }
            
            map_data.set_tile(x, y, 0, tile);
        }
    }
    
    // ⚠️ 硬编码: 添加测试 NPC
    let npc = MapObject {
        object_id: 1,
        object_type: 1,
        x: 50,
        y: 50,
        name: "村长".to_string(),
        // ...
    };
    map_data.add_object(npc);
    
    // ⚠️ 硬编码: 添加传送点
    let teleport = MapObject {
        object_id: 2,
        object_type: 3,
        x: 25,
        y: 25,
        name: "传送点".to_string(),
        // ...
    };
    map_data.add_object(teleport);
}
```

**结果**: 
- 测试地图大小: 100×100
- 边界 5 格不可行走
- NPC "村长" 在 (50, 50)
- 传送点在 (25, 25)

## 完整流程

### 启动流程
```
1. 用户按 F2 → 角色选择界面
2. 点击角色 → 点击"开始游戏"
3. 检测 NetworkManager 不存在
   ↓
4. 进入测试模式
   ↓
5. GameState::Game 状态激活
   ↓
6. OnEnter(GameState::Game) 触发:
   a. setup_game_scene
   b. setup_game_rendering
      └─→ load_request.request("0")  // 请求地图 0
   c. load_map_system
      └─→ 创建 100×100 测试地图
   d. spawn_test_player
      └─→ 玩家出生在 (5, 5)
   e. load_map_system_new
      └─→ 从文件加载 Map/0.map (700×700)
```

### 地图加载冲突 ⚠️

**注意**: 当前有**两个地图系统**同时运行：

| 系统 | 地图大小 | 数据来源 | 用途 |
|------|---------|---------|------|
| `load_map_system` (旧) | 100×100 | 硬编码测试数据 | MapData 资源 |
| `load_map_system_new` (新) | 700×700 | 读取 Map/0.map 文件 | MapRenderData 渲染 |

**结果**: 
- 渲染使用真实的 700×700 地图
- 碰撞检测使用 100×100 测试地图 ❌ (可能有问题)

## 总结

✅ **当前测试模式**:
- 地图: 硬编码 "0" (Map/0.map)
- 位置: 硬编码 (5, 5)
- 数据: 部分硬编码 (100×100) + 部分从文件加载 (700×700)

⚠️ **存在问题**:
- 两个地图系统冲突 (MapData vs MapRenderData)
- 碰撞检测可能不准确 (使用 100×100 而非 700×700)
- 无法灵活切换地图和位置

🎯 **建议**:
1. 统一地图系统，删除旧的测试地图代码
2. 添加配置文件支持测试模式
3. 接入真实服务器时，从 ObjectPlayer 包获取地图和位置
