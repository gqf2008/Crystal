## 🏗️ 系统架构

### 7 个系统组

```
Startup Phase
└─ setup_player_system
   setup_game_loop_system
   setup_network_sync_system
   ...

OnEnter(Game) Phase
└─ All Startup systems re-run

Update(GameState::Game) Phase
└─ Group 1: Player Systems (3)
   Group 2: Map Systems (5)
   Group 3: NPC/Dialogue Systems (6)
   Group 4: Chat Systems (8)
   Group 5: Network Systems (14)
   Group 6: Game Loop Systems (17)
   Group 7: Message Handlers
```

### 并行执行策略

```
Frame N:
├─ Player Systems (update position/stats)
├─ Map Systems (collision detection)
├─ NPC Systems (dialogue state)
├─ Chat Systems (message processing)
├─ Network Systems (send/receive sync)
├─ Loop Systems (FPS calculation, health check)
└─ Render Phase (parallel)
↓
Frame N+1 (dependent on N results)
```
