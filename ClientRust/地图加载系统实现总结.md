# 地图加载系统实现总结

## 📅 实现日期
2024年 (Bevy 0.17.2)

## 🎯 实现目标

实现一个完整的地图加载系统,能够从 `.map` 文件加载地图数据,填充到渲染系统,并自动设置摄像机边界。

## 📦 核心组件

### 1. MapLoadRequest 资源

**位置**: `src/bevy/scenes/game_scene/rendering/map_loader.rs`

```rust
#[derive(Resource, Default)]
pub struct MapLoadRequest {
    pub map_name: Option<String>,
    pub is_loading: bool,
}

impl MapLoadRequest {
    pub fn request(&mut self, map_name: String) {
        self.map_name = Some(map_name);
        self.is_loading = false;
    }
    
    pub fn is_requested(&self) -> bool {
        self.map_name.is_some() && !self.is_loading
    }
    
    pub fn start_loading(&mut self) {
        self.is_loading = true;
    }
    
    pub fn finish_loading(&mut self) {
        self.map_name = None;
        self.is_loading = false;
    }
}
```

**设计说明**:
- 使用 **Resource 模式** 而不是 Event 系统
- 简化了 API 兼容性问题 (避免 Bevy 0.17 的 `add_message` 复杂性)
- 状态管理清晰: 请求 → 加载中 → 完成

### 2. load_map_system 系统

**位置**: `src/bevy/scenes/game_scene/rendering/map_loader.rs`

```rust
pub fn load_map_system(
    mut load_request: ResMut<MapLoadRequest>,
    mut map_data: ResMut<MapRenderData>,
    mut camera_query: Query<&mut GameCamera>,
) {
    // 检查是否有加载请求
    if !load_request.is_requested() {
        return;
    }
    
    let map_name = load_request.map_name.as_ref().unwrap().clone();
    load_request.start_loading();
    
    info!("🗺️ 开始加载地图: {}", map_name);
    
    match load_map_file(&map_name) {
        Ok((cells, width, height)) => {
            info!("✅ 地图加载成功: {}x{}", width, height);
            
            // 填充地图数据
            map_data.cells = cells;
            map_data.width = width;
            map_data.height = height;
            map_data.doors.clear();
            
            // 提取门信息
            extract_doors(&mut map_data);
            
            // 设置摄像机边界
            if let Ok(mut camera) = camera_query.single_mut() {
                let map_width_px = width as f32 * 48.0;
                let map_height_px = height as f32 * 32.0;
                camera.set_map_bounds(map_width_px, map_height_px);
                info!("📷 摄像机边界已设置: {}x{}", map_width_px, map_height_px);
            }
            
            load_request.finish_loading();
        }
        Err(e) => {
            error!("❌ 加载地图失败: {}", e);
            load_request.finish_loading();
        }
    }
}
```

**功能流程**:
1. 检查是否有加载请求
2. 标记为"加载中"
3. 调用 `load_map_file()` 加载地图数据
4. 成功后:
   - 填充 `MapRenderData`
   - 提取门信息 (`extract_doors`)
   - 设置摄像机边界
5. 完成后清理请求状态

### 3. load_map_file 函数

**位置**: `src/bevy/scenes/game_scene/rendering/map_loader.rs`

```rust
fn load_map_file(map_name: &str) -> io::Result<(Vec<Vec<CellInfo>>, i32, i32)> {
    use std::path::PathBuf;
    use crate::objects::MapReader;
    
    // 尝试多个可能的路径
    let paths = [
        PathBuf::from(format!("Map/{}.map", map_name)),
        PathBuf::from(format!("./Map/{}.map", map_name)),
        PathBuf::from(format!("Data/Map/{}.map", map_name)),
        PathBuf::from(format!("./Data/Map/{}.map", map_name)),
        PathBuf::from(format!("../Map/{}.map", map_name)),
        PathBuf::from(format!("../Data/Map/{}.map", map_name)),
    ];
    
    for path in &paths {
        if path.exists() {
            info!("📂 找到地图文件: {:?}", path);
            let reader = MapReader::new(path.to_str().unwrap())?;
            return Ok((reader.map_cells, reader.width, reader.height));
        }
    }
    
    error!("❌ 地图文件未找到: {}", map_name);
    Err(io::Error::new(NotFound, format!("地图文件未找到: {}", map_name)))
}
```

**设计亮点**:
- **100% 复用** `objects::MapReader` (已存在的地图读取器)
- 尝试多个路径,适应不同的工作目录
- 清晰的日志输出,方便调试

### 4. extract_doors 函数

**位置**: `src/bevy/scenes/game_scene/rendering/map_loader.rs`

```rust
fn extract_doors(map_data: &mut MapRenderData) {
    let mut door_id = 1u8;
    
    for y in 0..map_data.height {
        for x in 0..map_data.width {
            if let Some(cell) = map_data.get_cell(x, y) {
                if cell.door_offset > 0 {
                    map_data.doors.push(DoorInfo {
                        id: door_id,
                        x,
                        y,
                        image: cell.door_index,
                        offset: cell.door_offset,
                        opened: false,
                    });
                    door_id += 1;
                }
            }
        }
    }
    
    info!("🚪 提取到 {} 个门", map_data.doors.len());
}
```

**功能说明**:
- 遍历所有地图格子
- 检查 `door_offset > 0` (标识门)
- 创建 `DoorInfo` 并添加到列表
- 自动分配门ID

## 📊 API 设计对比

### 初始设计 (Event 模式) ❌

```rust
// 定义事件
#[derive(Event, Clone)]
pub struct LoadMapRequest { pub map_name: String }

#[derive(Event, Clone)]
pub struct MapLoadedEvent { /* ... */ }

// 系统
pub fn load_map_system(
    mut events: EventReader<LoadMapRequest>,
    mut loaded_events: EventWriter<MapLoadedEvent>,
) { ... }

// 注册
app.add_event::<LoadMapRequest>();  // Bevy 0.17 不兼容!
app.add_event::<MapLoadedEvent>();
```

**问题**:
- Bevy 0.17 使用 `add_message` 而不是 `add_event`
- 编译错误: `LoadMapRequest is not a Message`
- API 复杂,需要多次注册

### 最终设计 (Resource 模式) ✅

```rust
// 定义资源
#[derive(Resource, Default)]
pub struct MapLoadRequest {
    pub map_name: Option<String>,
    pub is_loading: bool,
}

// 系统
pub fn load_map_system(
    mut load_request: ResMut<MapLoadRequest>,
    mut map_data: ResMut<MapRenderData>,
) { ... }

// 注册
app.insert_resource(MapLoadRequest::default());
```

**优势**:
- API 简单,只需一次注册
- 状态管理清晰
- 避免事件系统的兼容性问题
- 符合 Bevy 最佳实践

## 💡 设计经验

### 1. Resource vs Event

**选择 Resource 的场景**:
- 需要持久化状态
- 单一请求者
- 简单的请求-响应模式

**选择 Event 的场景**:
- 多个监听者
- 瞬时通知
- 复杂的事件链

### 2. 100% 复用策略

本次实现完全复用了 `objects::MapReader`,证明了复用策略的价值:
- 减少代码重复
- 保持一致性
- 降低维护成本

### 3. 渐进式实现

地图加载系统建立在之前的基础上:
- Phase 3: 地图渲染
- Phase 4: 摄像机系统
- Phase 5: 地图加载 (本次)

每个阶段都是可编译、可测试的,降低了开发风险。
