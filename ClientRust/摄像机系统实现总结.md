### 1. GameCamera 组件

**文件**: `src/bevy/scenes/game_scene/rendering/camera.rs`

```rust
#[derive(Component, Debug)]
pub struct GameCamera {
    /// 目标位置 (世界坐标,像素)
    pub target: Vec2,
    /// 平滑跟随速度 (0-1, 默认 0.2)
    pub smoothness: f32,
```

**设计说明**:
- `target`: 跟随目标的位置 (通常是玩家)
- `smoothness`: 控制跟随的流畅度 (0.2 = 每帧移动 20%)
- `zoom`: 缩放级别 (预留功能)
- `map_bounds`: 地图边界,用于限制摄像机位置

#### 边界限制

```rust
/// 计算限制后的目标位置 (带地图边界)
pub fn clamp_target(&self, screen_width: f32, screen_height: f32) -> Vec2 {
    let Some(map_bounds) = self.map_bounds else {
        return self.target;
    };

    // 计算可视区域的半宽和半高
    let half_width = screen_width / (2.0 * self.zoom);
    let half_height = screen_height / (2.0 * self.zoom);

    // 限制摄像机位置，确保不超出地图边界
    let min_x = half_width.max(0.0);
    let max_x = (map_bounds.x - half_width).max(min_x);
    let min_y = half_height.max(0.0);
    let max_y = (map_bounds.y - half_height).max(min_y);

    Vec2::new(
        self.target.x.clamp(min_x, max_x),
        self.target.y.clamp(min_y, max_y),
    )
}
```

**边界计算逻辑**:
```
摄像机不能超出边界:
- 最小位置 = 半屏幕宽度 (防止显示地图外)
- 最大位置 = 地图宽度 - 半屏幕宽度

示例:
地图宽度 = 2400 像素
屏幕宽度 = 1024 像素
半屏幕宽度 = 512 像素

min_x = 512
max_x = 2400 - 512 = 1888

摄像机 X 位置范围: [512, 1888]
```

#### 坐标转换

```rust
/// 世界坐标转屏幕坐标
pub fn world_to_screen(&self, world_pos: Vec2, camera_pos: Vec2, screen_size: Vec2) -> Vec2 {
    (world_pos - camera_pos) * self.zoom + screen_size / 2.0
}

/// 屏幕坐标转世界坐标
pub fn screen_to_world(&self, screen_pos: Vec2, camera_pos: Vec2, screen_size: Vec2) -> Vec2 {
    camera_pos + (screen_pos - screen_size / 2.0) / self.zoom
}
```

**转换公式**:
```
世界 → 屏幕:
screen_x = (world_x - camera_x) * zoom + screen_width / 2
screen_y = (world_y - camera_y) * zoom + screen_height / 2

屏幕 → 世界:
world_x = camera_x + (screen_x - screen_width / 2) / zoom
world_y = camera_y + (screen_y - screen_height / 2) / zoom
```

#### 可见区域计算

```rust
/// 获取可见区域 (世界坐标)
pub fn get_visible_rect(&self, camera_pos: Vec2, screen_size: Vec2) -> (Vec2, Vec2) {
    let half_size = screen_size / (2.0 * self.zoom);
    let min = camera_pos - half_size;
    let max = camera_pos + half_size;
    (min, max)
}

/// 计算可见的地图格子范围
pub fn get_visible_tiles(&self, camera_pos: Vec2, screen_size: Vec2, map_width: i32, map_height: i32) -> (i32, i32, i32, i32) {
    let (min, max) = self.get_visible_rect(camera_pos, screen_size);

    let start_x = ((min.x / 48.0).floor() as i32 - 2).max(0);
    let end_x = ((max.x / 48.0).ceil() as i32 + 2).min(map_width - 1);
    let start_y = ((min.y / 32.0).floor() as i32 - 2).max(0);
    let end_y = ((max.y / 32.0).ceil() as i32 + 2).min(map_height - 1);

    (start_x, end_x, start_y, end_y)
}
```

**用途**:
- 为地图渲染系统提供可见格子范围
- 实现视锥剔除 (只渲染可见的瓦片)
- 额外添加 2 格边距 (防止边缘闪烁)

### 3. 平滑跟随系统

```rust
/// 摄像机平滑跟随系统
pub fn camera_follow_system(
    mut camera_query: Query<(&mut Transform, &GameCamera), With<Camera2d>>,
    window_query: Query<&Window, With<PrimaryWindow>>,
    time: Res<Time>,
) {
    let Ok(window) = window_query.single() else {
        return;
    };

    let screen_width = window.width();
    let screen_height = window.height();

    for (mut transform, camera) in camera_query.iter_mut() {
        // 1. 计算限制后的目标位置
        let clamped_target = camera.clamp_target(screen_width, screen_height);

        // 2. 平滑插值到目标位置 (lerp)
        let current = transform.translation.truncate();
        let lerp_factor = camera.smoothness * time.delta_secs() * 60.0;
        let lerp_factor = lerp_factor.min(1.0); // 防止超过目标

        let new_pos = current.lerp(clamped_target, lerp_factor);

        // 3. 更新 Transform (注意 Y 轴反转)
        transform.translation.x = new_pos.x;
        transform.translation.y = -new_pos.y; // Bevy Y轴向上,所以取负
    }
}
```

**平滑跟随算法**:
```rust
// 线性插值 (Linear Interpolation)
new_pos = current + (target - current) * lerp_factor

// lerp_factor 计算:
lerp_factor = smoothness * delta_time * 60.0

// smoothness = 0.2 意味着:
// - 每帧移动到目标位置的 20%
// - delta_time * 60.0 确保帧率独立
// - 60Hz 时: lerp_factor ≈ 0.2
```

**效果**:
- 避免摄像机抖动
- 平滑的跟随动画
- 帧率独立 (使用 delta_time)

## 📈 性能优化

### 视锥剔除

**原理**:
```
地图总格子数: 1000 x 1000 = 1,000,000
可见格子数: 30 x 20 = 600

渲染效率提升: 1,000,000 / 600 ≈ 1,666 倍
```

**实现**:
```rust
// 计算可见范围 (带 2 格边距)
let (start_x, end_x, start_y, end_y) = camera.get_visible_tiles(...);

// 只渲染可见格子
for y in start_y..=end_y {
    for x in start_x..=end_x {
        // 渲染瓦片
    }
}
```

### 平滑跟随优化

**帧率独立**:
```rust
let lerp_factor = smoothness * time.delta_secs() * 60.0;
```

- 60Hz: `lerp_factor = 0.2 * (1/60) * 60 = 0.2`
- 30Hz: `lerp_factor = 0.2 * (1/30) * 60 = 0.4`
- 120Hz: `lerp_factor = 0.2 * (1/120) * 60 = 0.1`

保证不同帧率下相同的视觉效果。
