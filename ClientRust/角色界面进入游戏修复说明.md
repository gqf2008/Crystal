# 角色界面进入游戏修复说明

## 📋 问题描述

**原始错误**:
```
Parameter `Res<MapData>` failed validation: Resource does not exist
```

当从角色选择界面点击"开始游戏"按钮进入游戏场景时，系统 `create_map_layers_system` 需要 `MapData` 资源，但该资源在进入游戏场景时尚未创建，导致程序 panic。

## ✅ 修复方案

### 1. 初始化 MapData 资源

在 `setup_game_scene` 系统中提前初始化 `MapData` 资源：

**文件**: `src/bevy/scenes/game_scene/mod.rs`

```rust
pub fn setup_game_scene(
    mut commands: Commands,
) {
    info!("🎮 设置游戏场景");
    
    // 创建游戏场景状态资源
    commands.insert_resource(GameSceneState::default());
    info!("✅ GameSceneState 已创建");
    
    // 初始化 MapData 资源 (空地图,等待加载)
    commands.insert_resource(MapData::default());  // ✅ 新增
    info!("✅ MapData 资源已初始化");
    
    // ... 其他初始化代码
}
```

### 2. 修改地图加载系统

修改 `load_map_system` 使用已存在的 `MapData` 资源而不是创建新的：

**文件**: `src/bevy/scenes/game_scene/map_systems.rs`

```rust
pub fn load_map_system(
    mut map_data: ResMut<MapData>,  // ✅ 改为 ResMut
    mut game_state: ResMut<GameSceneState>,
) {
    // 如果地图已经加载，跳过
    if map_data.is_loaded {
        return;
    }
    
    info!("🗺️ 开始加载地图...");
    
    // 初始化地图数据
    *map_data = MapData::new(  // ✅ 直接修改已存在的资源
        1,
        "Mirror World".to_string(),
        100,
        100,
    );
    
    // ... 加载瓦片和对象
    
    map_data.is_loaded = true;
    game_state.is_initialized = true;
    
    info!("🗺️ 地图加载完成 (100×100, 对象数: 2)");
}
```

### 3. 测试模式直接切换场景

修改角色选择界面的"开始游戏"按钮，在测试模式下直接切换到游戏场景：

**文件**: `src/bevy/scenes/select_scene/button_systems.rs`

```rust
pub fn handle_button_clicks(
    // ... 其他参数
    mut next_state: ResMut<NextState<crate::bevy::GameState>>,  // ✅ 新增
) {
    // ...
    
    BottomButtonType::StartGame => {
        if let Some(tx) = &state.command_tx {
            // 发送网络命令...
        } else {
            // 测试模式: NetworkManager 未初始化,直接切换到游戏场景
            warn!("⚠️ 网络命令通道未初始化 - 进入测试模式");
            info!("🎮 [测试模式] 直接进入游戏场景: {}", character.name);
            next_state.set(crate::bevy::GameState::Game);  // ✅ 直接切换
        }
    }
}
```

## 🎯 核心改进

| 项目 | 修复前 | 修复后 |
|------|--------|--------|
| **MapData 初始化** | 在 `load_map_system` 中创建 | 在 `setup_game_scene` 中提前创建 |
| **系统执行顺序** | 依赖系统执行顺序 | 资源提前存在,无依赖问题 |
| **测试模式** | 无法进入游戏场景 | 直接切换到 GameState::Game |
| **错误处理** | Panic: Resource does not exist | ✅ 正常运行 |

## 🔧 技术细节

### 资源生命周期

```
OnEnter(Game)
    ↓
setup_game_scene()         ← 创建 MapData (空)
    ↓
load_map_system()          ← 填充 MapData (地图数据)
    ↓
create_map_layers_system() ← 使用 MapData (创建图层) ✅
```

### 系统注册顺序

```rust
app.add_systems(OnEnter(GameState::Game), (
    setup_game_scene,          // 1. 初始化资源
    setup_game_rendering,      // 2. 初始化渲染
    load_map_system,           // 3. 加载地图
    create_map_layers_system,  // 4. 创建图层
    spawn_map_objects_system,  // 5. 生成对象
));
```
