# Front 层绘制范围修复报告

## 🐛 问题描述

用户反馈:"看上去Front层绘制不全"

## 🔍 根本原因

Front 层的绘制范围过小,导致高大物体(树木、建筑物、城墙等)的顶部或延伸部分被裁剪。

### 原始实现问题
```rust
// ❌ 旧代码 - 只向下扩展
let front_extra_cells = 20;
let front_start_y = start_y;                      // 不向上扩展
let front_end_y = (end_y + front_extra_cells)...  // 向下扩展20格
```

**问题**:
1. **没有向上扩展** - 高大物体的顶部在当前格子上方,需要向上扩展才能绘制
2. **向下扩展不够** - 20格对于某些高大建筑物不足
3. **没有水平扩展** - 宽大物体的左右边缘可能被裁剪

## ✅ 修复方案

### 新的实现
```rust
// ✅ 新代码 - 四个方向都扩展
let front_extra_left = 10;   // 向左扩展
let front_extra_right = 10;  // 向右扩展
let front_extra_top = 15;    // 向上扩展(物体顶部)
let front_extra_bottom = 30; // 向下扩展(物体延伸和阴影)

let front_start_x = (start_x - front_extra_left).max(0);
let front_end_x = (end_x + front_extra_right).min(self.width - 1);
let front_start_y = (start_y - front_extra_top).max(0);
let front_end_y = (end_y + front_extra_bottom).min(self.height - 1);
```

### 扩展参数说明

| 方向 | 扩展格子数 | 原因 |
|------|-----------|------|
| **↑ 上** | 15 格 | 高大物体的顶部(如树冠、塔顶)通常高出地面15格以上 |
| **↓ 下** | 30 格 | 物体底部阴影、建筑物延伸部分需要更多空间 |
| **← 左** | 10 格 | 宽大物体的左侧部分 |
| **→ 右** | 10 格 | 宽大物体的右侧部分 |

### 动态优化保护
```rust
let total_cells = visible_width * visible_height;
let (draw_middle, draw_front) = if total_cells > 50000 {
    (false, false)  // 格子过多时禁用 Middle 和 Front
} else if total_cells > 20000 {
    (false, true)   // 禁用 Middle,保留 Front
} else {
    (true, true)    // 全部绘制
};
```

当可见格子超过阈值时,自动减少绘制层数以保持性能。

## 🚀 后续优化建议

### 1. 动态扩展
根据地图类型调整扩展参数:
```rust
let (front_extra_top, front_extra_bottom) = match map_type {
    MapType::City => (20, 35),      // 城市:更多建筑物
    MapType::Forest => (15, 30),    // 森林:标准树木
    MapType::Cave => (10, 20),      // 洞穴:低矮物体

};
```

### 2. 基于物体高度的智能扩展
分析地图文件,找出最高物体,动态计算扩展范围:
```rust
let max_object_height = analyze_map_max_height();
let front_extra_top = (max_object_height / CELL_HEIGHT) + 5;
```

```toml
extend_top = 15
extend_bottom = 30
extend_left = 10
extend_right = 10
```
