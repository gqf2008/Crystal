## 📖 使用指南

### 打开对话框
1. 启动游戏并登录账号
2. 进入角色选择界面
3. 按 **C键** 或点击 **"新建角色"** 按钮

### 创建角色
1. **选择职业**: 点击 战士/法师/道士/刺客/弓箭手 按钮
2. **选择性别**: 点击 男/女 按钮
3. **输入名称**: 点击输入框,输入2-16个字符(支持中文)
4. **确认创建**: 点击 **"确认"** 按钮
5. **取消操作**: 点击 **"取消"** 按钮或按 **Escape键**

### 快捷键
- **C**: 打开对话框
- **Enter**: 提交创建
- **Escape**: 关闭对话框
- **Backspace**: 删除字符
- **←/→**: 移动光标

## 🐛 故障排除

### 问题1: 对话框不显示
- **原因**: 纹理未加载
- **解决**: 确保Data目录存在,包含所有.lib文件

### 问题2: 中文输入无效
- **原因**: IME未启用
- **解决**: 检查系统输入法设置

### 问题3: 确认按钮无法点击
- **原因**: 角色名称验证失败
- **解决**: 确保名称2-16字符,只包含中文/英文/数字
