# GameScene 渲染系统测试指南

## 🎮 快速开始

### 1. 编译项目

```powershell
# Debug 模式 (快速编译)
cargo build --bin mir2_bevy

# Release 模式 (优化性能)
cargo build --bin mir2_bevy --release
```

### 2. 运行程序

```powershell
# Debug 模式
cargo run --bin mir2_bevy

# Release 模式
cargo run --bin mir2_bevy --release
```

### 3. 测试地图渲染

**步骤**:
1. 程序启动后会进入登录场景
2. 按 **F3** 键跳转到游戏场景
3. 观察地图渲染效果

**预期结果**:
- ✅ 窗口显示游戏场景
- ✅ 顶部显示 HUD (玩家信息)
- ✅ 地图开始渲染 (如果找到 Map/0.map)
- ✅ 摄像机初始化完成

## ⌨️ 调试快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| **F1** | 跳转到登录场景 | 测试 LoginScene |
| **F2** | 跳转到选择场景 | 测试 SelectScene |
| **F3** | 跳转到游戏场景 | 测试 GameScene (地图渲染) |
| **F5** | 重新加载地图 | 仅在游戏场景有效 |
| **ESC** | 返回登录场景 | 从任何场景返回 |

## 📂 地图文件准备

### 需要的文件

```
ClientRust/
├── Map/
│   └── 0.map          ← 地图文件
└── Data/
    └── Map/
        └── 0.map      ← 备用路径
```

### 地图文件路径查找顺序

程序会按以下顺序查找地图文件:
1. `Map/0.map`
2. `./Map/0.map`
3. `Data/Map/0.map`
4. `./Data/Map/0.map`
5. `../Map/0.map`
6. `../Data/Map/0.map`

**建议**: 将 `0.map` 放在 `ClientRust/Map/` 目录下

## 🔍 观察要点

### 1. 启动日志

查找以下日志输出:

```

🎮 窗口大小: 1024x768
📦 插件: DefaultPlugins + 最近邻插值
🎮 进入登录状态
```

### 2. 切换到游戏场景 (按F3)

查找以下日志:

```
🎮 设置游戏场景
✅ GameSceneState 已创建
✅ 游戏场景根节点已创建
🎨 初始化游戏渲染系统
📷 游戏摄像机已生成
🗺️ 已请求加载地图: 0
```

### 3. 地图加载

查找以下日志:

```
🗺️ 开始加载地图: 0
📂 找到地图文件: "Map/0.map"
✅ 地图加载成功: 100x100
🚪 提取到 X 个门
📷 摄像机边界已设置: 4800.0x3200.0
```

### 4. 渲染循环

每帧应该调用:
- `update_animation_system` - 更新动画计数器
- `camera_follow_system` - 更新摄像机位置
- `render_map_system` - 渲染地图

## ❌ 常见问题

### 问题 1: 地图文件未找到

**现象**:
```
❌ 地图文件未找到: 0
❌ 加载地图失败: 地图文件未找到: 0
```

**解决**:
1. 确认 `Map/0.map` 文件存在
2. 检查文件路径是否正确
3. 尝试复制到 `Data/Map/0.map`

### 问题 2: 窗口全黑

**可能原因**:
1. 地图文件未加载
2. MLibrary 纹理未加载
3. 摄像机位置错误

**调试**:
1. 检查日志中的错误信息
2. 按 F5 重新加载地图
3. 查看是否有纹理加载日志

### 问题 3: 摄像机不动

**可能原因**:
1. 没有设置 camera.target
2. smoothness 为 0
3. 边界限制过严

**调试**:
- 查看 `GameCamera::new()` 的默认值
- 确认 `camera_follow_system` 正在运行

### 问题 4: 性能问题 (帧率低)

**优化建议**:
1. 使用 Release 模式编译
2. 检查可见区域计算是否正确
3. 确认视锥剔除生效
