## 🔍 详细版本信息

### Bevy 0.17.2 ✅

**特性配置**:
```toml
bevy = { version = "0.17.2", features = [
    "dynamic_linking",            # ⚡ 加快开发编译速度
    "experimental_bevy_feathers", # 🎨 UI 组件库 + 样式主题
    "bevy_ui_debug",              # 🐛 UI 调试工具
    "custom_cursor",              # 🖱️ 自定义光标
    "png",                        # 🖼️ PNG 图片支持
    "jpeg",                       # 📷 JPEG 图片支持
    "default_font",               # 🔤 默认字体 (ASCII)
] }
```

**用途**:
- ✅ 作为当前主客户端引擎
- ✅ 所有 UI 系统 (LoginScene, SelectScene, GameScene)
- ✅ 所有游戏逻辑系统
- ✅ 渲染和事件处理

**编译二进制**:
- 名称: `mir2_bevy`
- 入口: `src/bin/main_bevy.rs`
- 状态: 🚀 **完全可用**
