## 📞 技术支持

### 快速问题排查
- Q: 编译失败？ → 运行 `cargo clean && cargo check`
- Q: FPS低？ → 检查 FrameStats 资源，系统会自动优化
- Q: 网络异常？ → 检查 NetworkState 资源连接状态
- Q: 聊天不显示？ → 检查 ChatDisplaySettings 配置

### 常见配置
```rust
// 调整同步频率
network_state.sync_interval = 0.2;  // 更频繁

// 调整FPS上限
frame_stats.history_size = 120;  // 2秒历史

// 启用/禁用消息类型
chat_filter.show_whisper = false;  // 隐藏私聊
```
