# Simple Map Viewer 使用指南

## 🎮 功能说明

`simple_map_viewer` 是一个独立的地图渲染测试工具,用于验证 `GameScene` 的 `MapRenderer` 模块。

### 新增视觉辅助功能

#### 1. 🎯 十字准星
- **位置**: 屏幕正中心
- **颜色**: 红色十字 + 黄色中心点
- **用途**: 标记摄像机注视点,移动时观察地图相对移动

#### 2. 🔲 屏幕边框
- **位置**: 屏幕四周
- **颜色**: 青色
- **用途**: 显示可见区域的边界

#### 3. 📊 信息面板
- **位置**: 左上角
- **内容**:
  - 地图名称
  - 摄像机位置 (world coordinates)
  - 当前缩放倍数
  - 实时 FPS

### 调试输出

程序会每 60 帧(约 1 秒)打印一次调试信息:

```
🎥 MapRenderer::draw() - Camera: (16800.0, 11200.0), zoom: 1.00, screen: (1024x768)
   📐 可见区域: world(16288,10816 -> 17312,11584), tiles(337,336 -> 363,364)
```

**参数说明**:
- `Camera: (x, y)`: 摄像机世界坐标(像素)
- `zoom`: 缩放倍数(1.0 = 原始尺寸)
- `screen: (WxH)`: 窗口尺寸(像素)
- `world(...)`: 可见区域的世界坐标范围
- `tiles(...)`: 可见区域的瓦片索引范围

## ⌨️ 操作说明

### 移动控制
```
方向键:
  ↑ - 向上移动 (500 像素/次)
  ↓ - 向下移动
  ← - 向左移动
  → - 向右移动
```

### 缩放控制
```
+ 或 = - 放大 (1.1x 增量,最大 3.0x)
-      - 缩小 (0.9x 递减,最小 0.5x)
```

### 特殊功能
```
Home - 回到地图中心
ESC  - 退出程序
```

## 🧪 测试建议

### 测试 1: 基础移动
1. 启动程序: `cargo run --bin simple_map_viewer -- 0`
2. 观察屏幕中心的**黄色中心点**
3. 按方向键,观察:
   - 地图纹理相对十字准星移动
   - 控制台输出摄像机位置变化
   - 左上角 FPS 保持稳定

**预期结果**: 按 → 时,地图向左移动;按 ↑ 时,地图向下移动(摄像机相反方向移动)

### 测试 2: 缩放功能
1. 按 `+` 键多次(3-5次)
2. 观察:
   - 地图瓦片尺寸变大
   - 左上角显示 `缩放: 1.46x`, `1.61x` 等
   - 可见的瓦片数量减少
3. 按 `-` 键恢复

**预期结果**: 放大时看到更大的瓦片细节,缩小时看到更多地图区域

### 测试 3: 组合操作
1. 先放大到 2.0x (`zoom: 2.00`)
2. 然后移动摄像机
3. 观察移动速度视觉上是否变快(因为每像素占据更多屏幕空间)

### 测试 4: 边界测试
1. 按住 ← 键移动到地图左边缘
2. 继续按住,观察是否卡在边界
3. 检查控制台输出:
   ```
   tiles(0,336 -> 28,364)  // start_x 被限制在 0
   ```

### 测试 5: 窗口缩放
1. 拖动窗口边框改变大小,或按 F11 全屏
2. 观察:
   - 屏幕边框自动调整
   - 可见瓦片数量自动增加/减少
   - 控制台输出 `screen: (WxH)` 变化

## 🔍 问题诊断

### 问题 1: 看不到地图
**症状**: 黑屏,只有十字准星和边框
**原因**: 图形库未正确加载
**检查**:
```
✅ 图形库加载成功!  ← 应该看到这个
```

### 问题 2: 移动无反应
**症状**: 按方向键,控制台有输出但画面不变
**检查**:
1. 控制台是否显示 `摄像机向右: (x, y)`
2. 可见区域瓦片索引是否变化
3. 如果都变化了但看不出来 → 该区域纹理可能非常相似

**解决**: 使用缩放功能(`+`)放大后再移动

### 问题 3: 缩放无反应
**症状**: 按 +/- 键无效果
**检查**:
1. 键盘布局(是否使用小键盘的 +/-)
2. 控制台输出 `🔍 缩放: x.xxX`

### 问题 4: FPS 很低
**症状**: FPS < 30
**原因**: 窗口过大或地图过大
**检查**:
```
📐 可见区域: tiles(...) ← 格子数是否 > 10000
```
**解决**: 缩小窗口或降低缩放倍数

## 🎨 视觉识别技巧

### 如何确认地图在移动?

#### 方法 1: 观察独特地形
- 找到地图上的建筑物、树木、道路等明显标志
- 移动时这些标志应该相对十字准星移动

#### 方法 2: 观察边缘变化
- 移动到地图边缘
- 观察屏幕边框外出现/消失的纹理

#### 方法 3: 使用缩放辅助
```
1. 放大到 2.0x
2. 找一个特征瓦片(如特殊颜色的地砖)
3. 让它位于十字准星上
4. 移动方向键,确认该瓦片移开
```

#### 方法 4: 对比控制台数据
```
移动前: tiles(337,336 -> 363,364)
按→键:  tiles(347,336 -> 373,364)  ← X 范围增加了 10
```

## 🛠️ 技术参数

### 地图坐标系
```
原点: (0, 0) 在地图左上角
X 轴: 向右递增
Y 轴: 向下递增
单位: 像素
```

### 格子尺寸
```
CELL_WIDTH = 48 像素
CELL_HEIGHT = 32 像素
```

### 摄像机默认值
```rust
Camera::new(screen_width, screen_height)
  x: 地图中心 X
  y: 地图中心 Y
  zoom: 1.0
```

### 移动速度
```
camera_speed: 100.0 像素/次
实际移动: camera_speed * 5 = 500 像素/次按键
```
