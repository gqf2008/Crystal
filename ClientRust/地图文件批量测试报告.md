### 加密地图 (Type 1)

Type 1 格式使用 XOR 加密:

```rust
// 尺寸加密
width = (w ^ xor_key)
height = (h ^ xor_key)

// 图像加密
BackImage = raw ^ 0xAA38AA38
MiddleImage = raw ^ xor_key
FrontImage = raw ^ xor_key
```

**测试验证**: 457 个 Type 1 文件全部成功解密

### 压缩存储 (Type 5)

```rust
// 2x2 格子共享 BackTile，每 3 字节存储 4 个格子

    for y in 0..(height / 2) {
        // 读取 3 字节，分配给 4 个格子
        ...
    }
}
```

**测试验证**: 5 个 Type 5 文件全部正确解压

### 标记位处理

所有格式都正确处理了标记位:

1. **BackImage 高墙标记** (`0x20000000`):

   - 测试: 0.map, 1.map 等全部正确

2. **FrontImage 低墙标记** (`0x8000`):
