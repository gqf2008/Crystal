## 🎯 测试内容

### 1. 文本输入测试

#### 账号输入框
```
✓ 点击账号框 → 光标出现并闪烁
✓ 输入字母数字 → 显示在输入框
✓ 输入特殊字符 → 被忽略（只接受 a-z, A-Z, 0-9）
✓ 输入超过20字符 → 不再接受
✓ 光标位置 → 在文本末尾闪烁
```

**测试步骤:**
1. 程序启动后，账号框自动获得焦点
2. 输入 "test123" → 应该正常显示
3. 输入 "@#$%" → 应该被忽略
4. 继续输入直到20个字符 → 不再接受更多

#### 密码输入框
```
✓ 点击密码框 → 焦点切换，光标出现
✓ 输入字符 → 显示为 *** 遮挡
✓ 字符数量正确 → 5个字符显示 *****
✓ Backspace删除 → 星号相应减少
```

**测试步骤:**
1. 点击密码框或按 Tab 键
2. 输入 "pass123" → 应显示 *******
3. 按 Backspace 3次 → 应显示 ****
4. 光标应在星号末尾闪烁

---

### 2. 焦点切换测试

#### Tab键切换
```
✓ 账号框 → Tab → 密码框
✓ 密码框 → Tab → 账号框
✓ 焦点切换时光标重置 → 立即显示
```

#### 鼠标点击切换
```
✓ 点击账号框 → 焦点到账号
✓ 点击密码框 → 焦点到密码
✓ 点击对话框空白处 → 焦点清除，光标消失
```

---

### 3. 光标动画测试

```
✓ 光标闪烁频率 → 0.5秒/次
✓ 光标位置 → 文本末尾
✓ 光标大小 → 1x12 像素
✓ 空文本时 → 光标在输入框起始位置
✓ 切换焦点时 → 光标立即显示
```

**观察要点:**
- 光标应该平滑闪烁，不卡顿
- 位置应该紧跟文本末尾
- 切换焦点时应立即显示（不等待闪烁周期）

---

### 4. 按钮悬停测试

#### OK/登录按钮
```
✓ 鼠标移入 → 图像变为高亮版本（索引321）
✓ 鼠标移出 → 恢复普通版本（索引320）
✓ 响应流畅 → 无延迟
```

#### 其他按钮
```
✓ 新建账号按钮 → 索引 323 → 324
✓ 修改密码按钮 → 索引 326 → 327
✓ 关闭按钮 → 索引 329 → 330
```

**测试步骤:**

2. 观察图像是否变化
3. 检查是否有延迟或闪烁

### 5. 按钮点击测试

#### OK按钮
```
✓ 账号和密码都为空 → 点击无效
✓ 只有账号 → 点击无效
✓ 账号和密码都有效 → 触发登录
✓ 账号不足3字符 → 点击无效
```

**测试步骤:**
1. 输入有效账号 "test123"
2. 输入有效密码 "pass123"
3. 点击 OK 按钮
4. 控制台应输出 "Login button clicked"

#### 其他按钮
```
✓ 新建账号 → 控制台输出 "New account button clicked"
✓ 修改密码 → 控制台输出 "Change password button clicked"
✓ 关闭 → 控制台输出 "Close button clicked"
```

### 6. 键盘快捷键测试

#### Enter键
```
✓ 账号为空，在账号框 → 无反应（焦点保持）
✓ 账号有效，在账号框 → 切换到密码框
✓ 两者都有效 → 提交登录
```

#### Backspace键
```
✓ 账号框有焦点 → 删除账号字符
✓ 密码框有焦点 → 删除密码字符
✓ 无焦点 → 无反应
```

#### Tab键
```
✓ 任何时候按Tab → 在两个输入框之间循环切换
```

#### Escape键
```
✓ 有焦点时 → 清除焦点
✓ 无焦点时 → （将来实现退出）
```

#### Ctrl+Q
```
✓ 任何时候 → 退出程序
```

### 7. 输入验证测试

#### 有效输入
```
✓ "abc123" → 接受（字母+数字）
✓ "TEST" → 接受（大写字母）
✓ "123456" → 接受（纯数字）
✓ "User99" → 接受（混合）
```

#### 无效输入（应被忽略）
```
✗ "@#$%" → 特殊字符
✗ "test@123" → 包含@
✗ "你好" → 中文字符
✗ "test 123" → 包含空格
```

#### 长度限制
```
✓ 3个字符 → 最小有效
✓ 20个字符 → 最大有效
✗ 2个字符 → 太短（OK按钮禁用）
✗ 21个字符 → 不接受新字符
```
