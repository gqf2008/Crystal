### 最佳实践总结

#### 添加新包的标准流程

```rust
// 1. 在 trait 中添加方法 (2行)
fn on_new_packet(&mut self, _packet: packets::NewPacket) {}

// 2. 在 dispatch_packet 中添加 case (4行)
x if x == ServerPacketIds::NewPacket as u16 => {
    let packet = packets::NewPacket::read_body(&mut cursor)?;
    handler.on_new_packet(packet);
}

// 3. 验证编译
cargo check

// 完成！平均 < 2分钟
```

#### 系统分组原则

1. **功能相关性**: 同一系统的包放在一起
2. **使用频率**: 常用包放在前面（跳转表优化）
3. **依赖关系**: 基础包先，衍生包后

#### 命名规范

1. **trait方法**: `on_<action>_<object>`
   - 例: `on_user_location`, `on_object_died`

2. **参数名**: 统一使用 `_packet`
   - 避免未使用警告
   - 清晰表达意图

3. **注释分类**: `// <系统名称>`
   - 例: `// 战斗系统`, `// 物品系统`

#### 1. trait系统的强大

**原因**: 
- 编译时单态化
