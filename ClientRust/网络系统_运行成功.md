  // 保存 runtime 到 CrystalGame 结构体中

## ⚠️ 已知问题

### 1. 服务器端包解析错误
```
[ERROR] Failed to dispatch packet (opcode=0): 数据不足: 需要至少4字节
[ERROR] Failed to dispatch packet (opcode=1): 数据不足: 需要至少4字节
[ERROR] Failed to dispatch packet (opcode=3): failed to fill whole buffer
[ERROR] Failed to dispatch packet (opcode=7): 数据不足: 需要至少4字节
```

**原因分析:**
- 客户端发送的包格式正确
- 服务器返回的包格式不匹配客户端预期
- 服务器端的包序列化/反序列化需要完善

**解决方案:**
- ✅ 客户端无需修改 (已正确实现)
- ⏳ 需要检查服务器端的 packet encoding
- ⏳ 确保服务器使用相同的 mir2_shared::packets 定义

### 2. 重复的 Connected 事件
```
[DEBUG] 收到网络事件: Connected (重复多次)
```

**原因:**
- NetworkManager 在多个位置发送了 Connected 事件
- 可能是重连逻辑触发了多次

**影响:**
- ⚠️ 导致 send_client_version() 被调用多次
- ⚠️ 不影响功能,但日志混乱

**解决方案:**
- 🔧 添加连接状态标志,避免重复发送
- 🔧 或在 LoginScene 中添加防重逻辑

## 🔧 技术要点总结

### 1. Tokio Runtime 管理
**核心代码:**
```rust
// main.rs
let runtime = tokio::runtime::Runtime::new()?;
let game = CrystalGame::new(&mut ctx, settings, runtime)?;

// main_ggez.rs
impl CrystalGame {
    fn new(_ctx: &mut Context, settings: ClientSettings, runtime: tokio::runtime::Runtime) -> Result<Self> {
        let _guard = runtime.enter(); // ← 关键: 提供 spawn 上下文
        
        let network_task = Some(tokio::spawn(async move {
            // ... 网络任务
        }));
        
        Ok(Self {
            runtime, // ← 保存 runtime 保持生命周期
            network_task,
            // ...
        })
    }
}
```

**重要性:**
- ggez 运行同步事件循环,不兼容 Tokio
- 必须显式创建和管理 Tokio runtime
- runtime.enter() 提供 spawn 所需的上下文
- runtime 必须活到程序结束

### 2. 跨线程通信
**Command 通道 (UI → Network):**
```rust
// 发送端 (LoginScene)
if let Some(tx) = &self.command_tx {
    tx.send(NetworkCommand::Login { username, password })?;
}

// 接收端 (NetworkManager)
while let Some(command) = self.command_rx.recv().await {
    match command {
        NetworkCommand::Login { username, password } => {
            // 处理登录...
        }
    }
}
```

**Event 通道 (Network → UI):**
```rust
// 发送端 (NetworkManager)
self.event_tx.send(GameEvent::Connected)?;

// 接收端 (CrystalGame::update)
while let Ok(event) = self.event_rx.try_recv() {
    scene_manager.process_event(&event);
}
```

### 3. Scene 下传
**问题:** SceneManager 如何传递 game_client 和 command_tx 到具体场景?

**解决方案:** 运行时类型转换 (downcast)
```rust
// scenes/mod.rs - 添加 trait 方法
pub trait Scene {
    fn as_any_mut(&mut self) -> &mut dyn std::any::Any;
}

// scene_manager.rs - 下传网络对象
pub fn set_game_client(&mut self, client: SharedGameClient) {
    self.game_client = Some(client);
    
    if let Some(scene) = &mut self.current_scene {
        if scene.scene_type() == SceneType::Login {
            if let Some(login_scene) = scene.as_any_mut().downcast_mut::<LoginScene>() {
                login_scene.set_game_client(self.game_client.clone());
            }
        }
    }
}
```
