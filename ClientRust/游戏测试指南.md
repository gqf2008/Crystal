## 📊 性能监控

### 查看纹理缓存日志

启动游戏后,观察终端输出:

```
✅ Texture cached: index=123, size=48x32
✅ Map loaded: D2 (560x400)
🧹 Cleaned 5 old textures from cache
```

### 关键日志标识

| 标识 | 含义 |
|------|------|
| `✅ Texture cached` | 纹理成功缓存 |
| `🧹 Cleaned X textures` | 自动清理旧纹理 |
| `✅ Map loaded` | 地图加载成功 |
| `MapControl draw: XXms` | 渲染耗时 (如果有) |

## 🐛 可能的问题

### 问题 1: 找不到 Data 目录

**症状**:
```
❌ Failed to load map: No such file or directory
```

**解决**:
```powershell
# 确认 Data 目录存在
ls Data/*.lib

# 应该看到:
# Prguse.lib, Prguse2.lib, Map/WemadeMir2/...
```

### 问题 2: 地图文件缺失

**症状**:
```
❌ Failed to load map: Maps/0.map
```

**解决**:
```powershell
# 检查地图文件
ls Data/Map/*.map

# 如果没有,需要从服务器下载
```

### 问题 3: 纹理缓存未生效

**症状**:
- 终端没有 "✅ Texture cached" 日志
- 性能仍然很低

**检查**:
```powershell
# 确认使用 Release 模式
cargo run --release --bin mir2_client_ggez

# 查看编译输出
cargo build --release 2>&1 | Select-String "纹理缓存"
```
