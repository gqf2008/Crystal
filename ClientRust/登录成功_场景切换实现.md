## 🚀 新增功能: 自动场景切换

### 实现逻辑

当 `LoginSuccess` 事件收到后:
1. `LoginScene` 设置 `ready_for_character_select = true`
2. 主循环检测到这个标志
3. 自动切换到 `SelectScene` (角色选择场景)

### 代码实现

**main_ggez.rs - update() 方法:**
```rust
// 检查 LoginScene 是否需要切换到 SelectScene
if scene_manager.current_scene_type() == Some(SceneType::Login) {
    if let Some(login_scene) = scene.as_any_mut().downcast_mut::<LoginScene>() {
        if login_scene.ready_for_character_select {
            tracing::info!("✅ 登录成功,切换到角色选择场景 ({} 个角色)", login_scene.characters.len());
            
            // 获取角色列表
            let characters = login_scene.characters.clone();
            
            // 创建 SelectScene
            let mut select_scene = Box::new(SelectScene::new(characters));
            select_scene.initialize();
            
            // 替换当前场景
            scene_manager.set_current_scene(select_scene);
            tracing::info!("场景切换完成: Select");
        }
    }
}
```

**scene_manager.rs - 新增方法:**
```rust
/// Get mutable reference to current scene
pub fn current_scene_mut(&mut self) -> Option<&mut Box<dyn Scene>> {
    self.current_scene.as_mut()
}

/// Set current scene (用于直接替换场景)
pub fn set_current_scene(&mut self, scene: Box<dyn Scene>) {
    self.current_scene = Some(scene);
}
```
