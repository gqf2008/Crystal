# 🎮 角色界面进入游戏 - 快速修复参考

## 问题
```
Parameter `Res<MapData>` failed validation: Resource does not exist
```

## 修复清单

### ✅ 1. 初始化 MapData (mod.rs)
```rust
commands.insert_resource(MapData::default());
```

### ✅ 2. 使用 chain() 保证顺序 (main_bevy.rs)
```rust
app.add_systems(OnEnter(GameState::Game), (
    setup_game_scene,
    load_map_system,
    create_map_layers_system,
).chain());  // ← 关键
```

### ✅ 3. 修改 load_map_system (map_systems.rs)
```rust
pub fn load_map_system(
    mut map_data: ResMut<MapData>,  // 改为 ResMut
) {
    *map_data = MapData::new(...);  // 直接修改
}
```

### ✅ 4. ChatManager 初始化 (chat_systems.rs)
```rust
commands.insert_resource(ChatManager::default());
```

### ✅ 5. 使用 Option 安全访问 (map_renderer.rs, network_systems.rs)
```rust
pub fn render_map_system(
    mlibrary: Option<ResMut<MLibraryAssets>>,  // Option
) {
    let Some(mut mlibrary) = mlibrary else { return; };
}
```

### ✅ 6. 测试模式切换 (button_systems.rs)
```rust
next_state.set(crate::bevy::GameState::Game);
```

4. ✅ 进入游戏场景！
