# 🎨 摄像机和纹理修复总结

## 问题发现历程

### 问题 1: 游戏场景无纹理和角色 ❌
**现象**: 
- 进入游戏场景后屏幕黑屏
- 没有地图纹理
- 没有角色显示

**根本原因**:
1. **双摄像机冲突**: `setup()` 和 `setup_game_rendering()` 各创建一个摄像机
2. **MLibraryAssets 未初始化**: `setup_map_renderer` 没有创建 MLibraryAssets

### 问题 2: 登录界面纹理消失 ❌
**现象**: 
- 修复游戏场景后，登录界面也没有纹理了

**根本原因**:
- 移除了 `setup()` 中的全局摄像机
- LoginScene 和 SelectScene 都依赖这个全局摄像机

---

## 修复方案

### 修复 1: 移除全局摄像机 ✅

**文件**: `src/bin/main_bevy.rs`

```rust
// 修改前
fn setup(mut commands: Commands, mut next_state: ResMut<NextState<GameState>>) {
    commands.spawn(Camera2d::default());  // ← 全局摄像机,会冲突
    next_state.set(GameState::Login);
}

// 修改后
fn setup(mut commands: Commands, mut next_state: ResMut<NextState<GameState>>) {
    // 不创建全局摄像机,让各场景自己管理
    next_state.set(GameState::Login);
}
```

**原因**: 
- 多个摄像机会导致 "Camera order ambiguities" 警告
- 渲染顺序不确定
- 可能导致渲染失败

---

### 修复 2: 初始化 MLibraryAssets ✅

**文件**: `src/bevy/scenes/game_scene/rendering/map_renderer.rs`

```rust
// 修改前
pub fn setup_map_renderer(mut commands: Commands) {
    commands.insert_resource(MapRenderData::empty());
    commands.insert_resource(TileCache::default());
    // ❌ 缺少 MLibraryAssets 初始化
}

// 修改后
pub fn setup_map_renderer(mut commands: Commands) {
    use std::path::PathBuf;
    use super::mlibrary_assets::MLibraryAssets;
    
    commands.insert_resource(MapRenderData::empty());
    commands.insert_resource(TileCache::default());
    
    // ✅ 初始化 MLibrary 资源
    let data_path = PathBuf::from("Data");
    commands.insert_resource(MLibraryAssets::new(data_path));
    info!("✅ MLibraryAssets 已初始化");
    
    info!("✅ MapRenderer 初始化完成");
}
```

**原因**:
- `render_map_system` 需要 `MLibraryAssets` 来加载纹理
- 如果资源不存在,会提前 return,导致黑屏

## 摄像机生命周期管理

### 设计原则
每个场景都有**独立的摄像机**,与场景实体同生共灭:

```
Login 状态:
  ├── LoginCamera (LoginSceneRoot 组件)
  └── 登录 UI

Select 状态:
  ├── SelectCamera (SelectSceneRoot 组件)
  └── 角色选择 UI

Game 状态:
  ├── GameCamera (GameCamera 组件)
  └── 游戏世界
```

### 自动清理
```rust
// 退出场景时,带有场景标记的实体会被自动删除
app.add_systems(OnExit(GameState::Login), cleanup_login_scene);
app.add_systems(OnExit(GameState::Select), cleanup_select_scene);
app.add_systems(OnExit(GameState::Game), cleanup_game_rendering);

// cleanup 函数会查询并删除带标记的实体
pub fn cleanup_login_scene(
    mut commands: Commands,
    query: Query<Entity, With<LoginSceneRoot>>,
) {
    for entity in query.iter() {
        commands.entity(entity).despawn_recursive();
    }
}
```

## 架构改进

### 修改前 (有问题)
```
setup() 
  └─→ 创建全局摄像机 ❌

LoginScene
  └─→ 依赖全局摄像机 ❌
  
SelectScene
  └─→ 依赖全局摄像机 ❌
  
GameScene
  └─→ 创建自己的摄像机 ⚠️ (冲突)
```

**问题**:
- 多个摄像机共存
- 渲染顺序冲突
- 生命周期混乱

### 修改后 (正确)
```
setup() 
  └─→ 不创建摄像机 ✅

LoginScene (OnEnter)
  └─→ 创建 LoginCamera ✅
  
SelectScene (OnEnter)
  └─→ 创建 SelectCamera ✅
  
GameScene (OnEnter)
  └─→ 创建 GameCamera ✅

每个场景 (OnExit)
  └─→ 自动清理自己的摄像机 ✅
```

**优点**:
- 每个场景独立管理摄像机
- 没有冲突
- 生命周期清晰
- 符合 Bevy ECS 设计原则

```rust
    Camera2d::default(),
```

### 2. MLibraryAssets 初始化时机
```rust

    setup_game_scene,
    setup_map_renderer,  // ← 在这里初始化 MLibraryAssets
    setup_game_rendering,
    // ...
).chain());
```

