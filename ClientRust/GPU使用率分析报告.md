## 🔬 深度分析：为什么不是 100%？

### GPU 绑定 vs CPU 绑定

```
帧渲染管线：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CPU 工作（逻辑处理）：
  ├─ 更新动画 (1ms)
  ├─ 视口裁剪 (0.5ms)
  ├─ Z 轴排序 (0.3ms)
  └─ 准备渲染数据 (0.2ms)
         ↓
GPU 工作（绘制）：
  ├─ 绘制 Back 层 (1.5ms)
  ├─ 绘制 Middle 层 (1.0ms)
  ├─ 绘制 Front 层 (1.2ms)
  └─ UI 绘制 (0.3ms)
         ↓
垂直同步 + 帧率限制：
  └─ 等待下一帧 (剩余时间)

总帧时间: ~6.25ms (160 FPS)
```

**瓶颈分析**：
- **帧率限制**：GPU 完成工作后等待
- **CPU 逻辑**：可能占用 ~2ms
- **GPU 渲染**：可能占用 ~4ms
- **剩余时间**：等待下一帧

**结论**：GPU 有空闲时间 → 使用率 65%
