## 命名规范对齐

### 对齐策略

根据 Rust 语言规范,我们采用**智能对齐**策略:

| 元素 | C# 规范 | Rust 规范 | 对齐方式 |
|------|---------|-----------|----------|
| **类型名** | PascalCase | PascalCase | ✅ 100% 一致 |
| **字段名** | PascalCase | snake_case | ⚠️ 转换 + 注释标注 |
| **方法名** | PascalCase | snake_case | ⚠️ 转换 + 注释标注 |
| **模块路径** | 命名空间 | 模块系统 | ✅ 100% 对应 |

### 为什么不能完全一致?

**Rust 编译器强制 snake_case**:

```rust
// ❌ 这样会有编译警告
pub struct GameScene {
    pub HasHero: bool,        // warning: field should have a snake case name
    pub HeroSpawnState: bool, // warning: field should have a snake case name
}

// ✅ 正确的 Rust 风格
pub struct GameScene {
    /// 是否拥有英雄 (C#: HasHero)
    pub has_hero: bool,
    
    /// 英雄召唤状态 (C#: HeroSpawnState)
    pub hero_spawn_state: HeroSpawnState,
}
```

**原因**: Rust 语言设计决定,强制使用 snake_case 以保持生态统一。

## 模块组织对齐

### C# 命名空间结构
```csharp
namespace Client.MirScenes {
    public sealed class GameScene : MirScene {
        public sealed class MapControl : MirControl { }
    }
}
```

### Rust 模块结构 ✅
```
ClientRust/src/scenes/
├── game_scene.rs               # GameScene 主结构
└── game_scene/
    ├── mod.rs                  # 子模块导出
    ├── map_control.rs          # MapControl (对应 C# 嵌套类)
    └── tile_texture_manager.rs # 纹理管理
```

**对应关系**:
- C# `Client.MirScenes` → Rust `crate::scenes`
- C# `GameScene` → Rust `scenes::GameScene`
- C# 嵌套类 `GameScene.MapControl` → Rust `scenes::game_scene::MapControl`

### ⚠️ 转换项(符合 Rust 规范)

1. **字段名**: PascalCase → snake_case (编译器强制)
2. **方法名**: PascalCase → snake_case (编译器强制)

### ❌ 拒绝的反模式

1. **不使用 PascalCase 字段名** (会有编译警告)
2. **不使用 PascalCase 方法名** (违反 Rust 规范)
3. **不完全镜像 C# 单文件结构** (12,000+ 行单文件不可维护)
