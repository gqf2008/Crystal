## 🔥 核心优化

### 优化前 (每帧创建纹理)
```
每帧 200 个瓦片:
  ├─ load_rgba_data() × 200    ➜ 解压 GZIP
  ├─ BGRA→RGBA 转换 × 200      ➜ CPU 处理
  ├─ Image::from_pixels() × 200 ➜ GPU 上传
  └─ 总耗时: ~1000ms/帧        ➜ 1 FPS ❌
```

### 优化后 (纹理缓存)
```
首帧:
  └─ 加载 200 个纹理到缓存     ➜ ~1000ms (一次性)

后续帧:
  ├─ HashMap 查找 × 200        ➜ 0.01ms/次
  ├─ 直接使用缓存纹理          ➜ 无 GPU 上传
  └─ 总耗时: ~2ms/帧           ➜ 500+ FPS ✅
```
