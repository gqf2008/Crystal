下面给你一套基于 ggez 的“可落地移植骨架”，把 Crystal 客户端里地图与资源的核心绘制管线（背景 → 地表缓存 → 对象/特效 → 天气粒子 → 光照贴图叠加 → 提交屏幕）按 Rust/ggez 的方式搭起来。你可以先跑通 Type100（自定义）地图与基础贴图，然后逐步补齐其他格式、资源库、对象、天气、门动画等。

说明
- ggez 0.9 提供 Canvas（离屏渲染）、BlendMode（Alpha/Add/Multiply/Replace）、Image/Drawable、Graphics::set_canvas 等，完全能覆盖 FloorTexture/LightTexture/混合叠加的需求。
- 关键迁移点已经按 C# 语义一一映射：CellInfo 字段、Floor 缓存、Front/Middle 动画、门索引偏移、光照贴图加法叠加、最终用乘法把 Light 乘到主画面。

```rust name=src/main.rs
use anyhow::Result;
use ggez::{
    conf::{WindowMode, WindowSetup},
    event::{self, EventHandler},
    graphics::{self, BlendMode, Canvas, Color, Drawable, FilterMode, PxScale, Text},
    Context, ContextBuilder, GameResult,
    input::keyboard::{KeyCode, KeyMods},
};
use glam::Vec2;

mod types;
mod resources;
mod map;
mod lighting;
mod objects;

use map::{Map, MapReader, Viewport};
use resources::ResourceManager;
use lighting::Lighting;
use objects::{ObjectManager};
use types::{Timing};

struct GameState {
    // 资源/数据
    resources: ResourceManager,
    map: Map,
    objects: ObjectManager,
    lighting: Lighting,

    // 离屏缓存
    floor_canvas: Canvas,
    light_canvas: Canvas,

    // 定时/动画
    timing: Timing,

    // 视口与屏幕信息
    viewport: Viewport,

    // 标记需要重建 Floor 缓存
    floor_valid: bool,
}

impl GameState {
    fn new(ctx: &mut Context) -> Result<Self> {
        let (w, h) = (1280.0, 720.0);

        // 资源管理（纹理库/地图库/光照贴图等）
        let mut resources = ResourceManager::new(ctx)?;
        resources.load_builtin(ctx)?; // 加载 background、lights、调试资源等

        // 地图读取（先实现 Type100，自定义格式）
        let map = MapReader::load_type100(ctx, "assets/maps/sample_type100.map")?;

        // 视口（等距格 -> 屏幕映射）
        let viewport = Viewport::new(w as i32, h as i32);

        // 对象管理（玩家/怪/NPC/掉落/法术体）
        let objects = ObjectManager::new();

        // 光照系统
        let lighting = Lighting::new(&resources)?;

        // 离屏画布
        let floor_canvas = Canvas::with_window_size(ctx)?;
        let light_canvas = Canvas::with_window_size(ctx)?;

        Ok(Self {
            resources,
            map,
            objects,
            lighting,
            floor_canvas,
            light_canvas,
            timing: Timing::new(),
            viewport,
            floor_valid: false, // 初次需要构建
        })
    }

    fn rebuild_floor(&mut self, ctx: &mut Context) -> GameResult {
        self.floor_canvas.set_blend_mode(None);
        graphics::set_canvas(ctx, Some(&self.floor_canvas));
        graphics::clear(ctx, Color::from_rgba(0, 0, 0, 0));

        self.map.draw_floor(ctx, &mut self.resources, &self.viewport, self.timing.animation_count)?;

        graphics::set_canvas(ctx, None);
        self.floor_valid = true;
        Ok(())
    }

    fn build_lighting(&mut self, ctx: &mut Context) -> GameResult {
        self.light_canvas.set_blend_mode(None);
        graphics::set_canvas(ctx, Some(&self.light_canvas));
        // 先清为“暗度”
        let darkness = self.lighting.darkness_color(); // Dawn/Evening/Night/Normal/Day + 失明修正
        graphics::clear(ctx, darkness);

        // 加法叠加所有光源（对象光、特效光、地图灯）
        graphics::set_blend_mode(ctx, Some(BlendMode::Add))?;
        self.lighting.draw_object_lights(ctx, &self.resources, &self.objects, &self.viewport)?;
        self.lighting.draw_effect_lights(ctx, &self.resources, &self.viewport, self.timing.time_ms)?;
        self.lighting.draw_map_lights(ctx, &self.resources, &self.map, &self.viewport)?;

        // 结束光照累加
        graphics::set_canvas(ctx, None);
        Ok(())
    }
}

impl EventHandler for GameState {
    fn update(&mut self, ctx: &mut Context) -> GameResult {
        // 推进计时/动画，每 100ms 递增 AnimationCount（等价 C# MoveTime 节拍）
        self.timing.update(ctx);

        // 门动画/地表动画可能改变 -> 标记 floor_invalid
        if self.map.process_doors(self.timing.time_ms) {
            self.floor_valid = false;
        }
        if self.timing.tick100ms { // 100ms 推进地表光栅动画
            self.floor_valid = false;
        }

        // 更新对象/特效/天气等
        self.objects.update(self.timing.time_ms);

        Ok(())
    }

    fn draw(&mut self, ctx: &mut Context) -> GameResult {
        let mut frame = Canvas::from_frame(ctx, Color::BLACK);

        // 1) 背景（整张）
        self.map.draw_background(ctx, &mut frame, &self.resources, &self.viewport)?;

        // 2) 地表缓存（Back/Mid/Front 静态层 + 门动画/帧动画）
        if !self.floor_valid {
            self.rebuild_floor(ctx)?;
        }
        frame.set_blend_mode(None);
        frame.draw(&self.floor_canvas, graphics::DrawParam::default());

        // 3) 对象/尸体/重绘中间层+前景的透明重叠（必要时）/名字/聊天/飘字/血条
        self.map.draw_objects(ctx, &mut frame, &mut self.resources, &self.objects, &self.viewport, self.timing.animation_count, self.timing.time_ms)?;

        // 4) 天气粒子（可后续补充：雪/雨/雾/落叶/余烬）
        // self.map.draw_weather(ctx, &mut frame, &mut self.resources, &self.viewport, self.timing.time_ms)?;

        // 5) 光照：构建光照 Canvas（加法叠加光源）
        self.build_lighting(ctx)?;
        // 5.1) 把光照 Canvas“乘”到主画面（黑场开洞）
        frame.set_blend_mode(Some(BlendMode::Multiply));
        frame.draw(&self.light_canvas, graphics::DrawParam::default());
        frame.set_blend_mode(None);

        // 6) UI/调试
        // frame.draw(Text::new(("ggez port", PxScale::from(18.0))), graphics::DrawParam::default().dest([10.0, 10.0]));

        frame.finish(ctx)
    }

    fn key_down_event(&mut self, _ctx: &mut Context, keycode: KeyCode, _mods: KeyMods, _repeat: bool) -> GameResult {
        match keycode {
            KeyCode::F5 => self.floor_valid = false, // 强制重建地表
            _ => {}
        }
        Ok(())
    }
}

pub fn main() -> Result<()> {
    let (mut ctx, event_loop) = ContextBuilder::new("crystal_ggez_port", "you")
        .window_setup(WindowSetup::default().title("Crystal - ggez port"))
        .window_mode(WindowMode::default().dimensions(1280.0, 720.0))
        .build()?;

    let state = GameState::new(&mut ctx)?;
    event::run(ctx, event_loop, state);
}
```

```rust name=src/types.rs
            tick100ms: false,

    }

    pub screen_h: i32,
    pub cell_w: i32,

    pub offset_x: i32,
    pub offset_y: i32,
    pub view_range_x: i32,
    pub view_range_y: i32,
}

impl Viewport {
    pub fn new(w: i32, h: i32) -> Self {
        let cell_w = 48;
        let cell_h = 32;
        let offset_x = w / 2 / cell_w;
        let offset_y = h / 2 / cell_h - 1;
        let view_range_x = offset_x + 6;
        let view_range_y = offset_y + 6;
        Self { screen_w: w, screen_h: h, cell_w, cell_h, offset_x, offset_y, view_range_x, view_range_y }
    }

    pub fn world_to_screen(&self, user_cell: glam::IVec2, cell: glam::IVec2, offset_move: glam::IVec2) -> glam::IVec2 {
        let dx = (cell.x - user_cell.x + self.offset_x) * self.cell_w - self.offset_x + offset_move.x;
        let dy = (cell.y - user_cell.y + self.offset_y) * self.cell_h + offset_move.y;
        glam::ivec2(dx, dy)
    }
}
```

```rust name=src/resources.rs
use anyhow::Result;
use ggez::{graphics::{self, Image, Drawable, DrawParam, BlendMode, Color}, Context};
use std::collections::HashMap;

/// 简化版库抽象：实际建议把 .lib 转成 atlas+json，或先用占位图
pub struct Library {
    pub image: Image,        // 图集纹理
    pub frames: Vec<graphics::Rect>, // 子图矩形（0..1 归一化）
    pub offsets: Vec<glam::IVec2>,   // 每帧附加偏移（若有）
}

impl Library {
    pub fn draw(&self, canvas: &mut graphics::Canvas, frame: usize, dest: glam::IVec2, color: Color, blend: Option<BlendMode>) {
        let mut dp = DrawParam::default()
            .src(self.frames[frame])
            .dest([dest.x as f32, dest.y as f32])
            .color(color);
        if let Some(b) = blend { canvas.set_blend_mode(Some(b)); }
        canvas.draw(&self.image, dp);
        if blend.is_some() { canvas.set_blend_mode(None); }
    }
}

pub struct ResourceManager {
    // 地图库：等价于 Libraries::MapLibs[i]
    pub map_libs: HashMap<i16, Library>,
    // 背景
    pub background: Option<Image>,
    // 光照贴图（不同半径）
    pub lights: Vec<Image>,
}

impl ResourceManager {
    pub fn new(_ctx: &mut Context) -> Result<Self> {
        Ok(Self {
            map_libs: HashMap::new(),
            background: None,
            lights: Vec::new(),
        })
    }

    pub fn load_builtin(&mut self, ctx: &mut Context) -> Result<()> {
        // 占位背景
        let bg = Image::from_solid(ctx, 1, Color::from_rgb(0, 0, 0));
        self.background = Some(bg);

        // 加载光照贴图：建议准备 assets/lights/l0.png ... l10.png
        for i in 0..=10 {
            let path = format!("/lights/l{i}.png");
            match Image::from_path(ctx, path) {
                Ok(mut img) => {
                    img.set_filter(graphics::FilterMode::Linear);
                    self.lights.push(img);
                }
                Err(_) => {
                    // 退化：如果没有资源，用白色点代替
                    let img = Image::from_solid(ctx, 2, graphics::Color::WHITE);
                    self.lights.push(img);
                }
            }
        }
        Ok(())
    }

    pub fn get_map_lib(&self, idx: i16) -> Option<&Library> {
        self.map_libs.get(&idx)
    }

    // 你可以增加：register_map_lib(idx, atlas_image, frames, offsets) 等
}
```

```rust name=src/map.rs
use anyhow::Result;
use ggez::{graphics::{self, Canvas, Color, Drawable, DrawParam}, Context};
use glam::{IVec2, ivec2};
use crate::types::{CellInfo, Door, DoorState, Millis, Viewport};
use crate::resources::ResourceManager;
use crate::objects::ObjectManager;

pub struct Map {
    pub width: i32,
    pub height: i32,
    pub cells: Vec<CellInfo>, // 行主序 width*height
    pub doors: Vec<Door>,

    // 地图文件名/前缀可用于背景切换
    pub file_name: String,

    // 用户/视角（示例：用户在中心）
    pub user_cell: IVec2,
    pub user_offset_move: IVec2,
}

impl Map {
    #[inline]
    fn idx(&self, x: i32, y: i32) -> usize {
        (y as usize) * (self.width as usize) + (x as usize)
    }

    pub fn draw_background(&self, ctx: &mut Context, canvas: &mut Canvas, res: &ResourceManager, _vp: &Viewport) -> ggez::GameResult {
        if let Some(bg) = &res.background {
            canvas.draw(bg, DrawParam::default().dest([0.0, 0.0]).color(Color::from_rgb(0,0,0)));
        }
        Ok(())
    }

    pub fn draw_floor(&self, ctx: &mut Context, res: &mut ResourceManager, vp: &Viewport, anim_count: u64) -> ggez::GameResult {
        // Back → Middle → Front，按照视野+冗余行绘制
        for y in (self.user_cell.y - vp.view_range_y)..=(self.user_cell.y + vp.view_range_y + 5) {
            if y < 0 || y >= self.height { continue; }
            for x in (self.user_cell.x - vp.view_range_x)..=(self.user_cell.x + vp.view_range_x) {
                if x < 0 || x >= self.width { continue; }
                let ci = &self.cells[self.idx(x, y)];

                // Back
                if ci.back_index >= 0 && ci.back_image > 0 {
                    if let Some(lib) = res.get_map_lib(ci.back_index) {
                        let screen = vp.world_to_screen(self.user_cell, ivec2(x,y), self.user_offset_move);
                        let frame = (ci.back_image - 1) as usize;
                        lib.draw(&mut graphics::Canvas::from_frame(ctx, Color::TRANSPARENT), frame, screen, Color::WHITE, None);
                    }
                }

                // Middle（可能需要 DrawUp / 混合，根据 ci.middle_anim_frames/tick 决定 frame 偏移）
                if ci.middle_index >= 0 && ci.middle_image > 0 {
                    if let Some(lib) = res.get_map_lib(ci.middle_index) {
                        let screen = vp.world_to_screen(self.user_cell, ivec2(x,y), self.user_offset_move);
                        let mut frame = (ci.middle_image - 1) as usize;

                        // 简化动画推进（与 C# 公式等价思想）
                        if ci.middle_anim_frames > 0 && ci.middle_anim_frames < 255 {
                            let tick = 1 + ci.middle_anim_tick as u64;
                            frame += (anim_count % ((ci.middle_anim_frames as u64) * tick)) as usize / (tick as usize);
                        }

                        lib.draw(&mut graphics::Canvas::from_frame(ctx, Color::TRANSPARENT), frame, screen, Color::WHITE, None);
                    }
                }

                // Front（门动画/透明混合）
                if ci.front_index >= 0 && ci.front_image > 0 {
                    if let Some(lib) = res.get_map_lib(ci.front_index) {
                        let screen = vp.world_to_screen(self.user_cell, ivec2(x,y), self.user_offset_move);
                        let mut frame = (ci.front_image & 0x7FFF) - 1; // 移除 0x8000
                        let mut frame = frame as usize;

                        // 门：index += (door_img_index+1) * door_offset
                        if ci.door_index > 0 {
                            if let Some(door) = self.doors.iter().find(|d| d.index == ci.door_index) {
                                if door.state != DoorState::Closed {
                                    frame += ((door.image_index as usize) + 1) * (ci.door_offset as usize);
                                }
                            }
                        }

                        // 动画帧推进
                        if ci.front_anim_frames > 0 {
                            let tick = 1 + ci.front_anim_tick as u64;
                            frame += (anim_count % ((ci.front_anim_frames as u64) * tick)) as usize / (tick as usize);
                        }

                        // 混合（按资源规范决定，示例：可能需要 Add/Alpha）
                        lib.draw(&mut graphics::Canvas::from_frame(ctx, Color::TRANSPARENT), frame, screen, Color::WHITE, None);
                    }
                }
            }
        }
        Ok(())
    }

    pub fn draw_objects(&self,
        _ctx: &mut Context,
        canvas: &mut Canvas,
        res: &mut ResourceManager,
        objects: &ObjectManager,
        vp: &Viewport,
        anim_count: u64,
        now_ms: crate::types::Millis) -> ggez::GameResult
    {
        // 1) 先画“在对象背后”的特效（DrawBehind）
        objects.draw_effects(canvas, vp, true, now_ms)?;

        // 2) 逐格画尸体
        objects.draw_dead(canvas, vp)?;

        // 3) 必要时重绘中间层/前景透明覆盖（此处简化：略）

        // 4) 活体对象
        objects.draw_alive(canvas, vp, anim_count, now_ms)?;

        // 5) 名字/聊天/飘字
        objects.draw_overlays(canvas, vp, now_ms)?;

        // 6) 血条单独一遍，让血条最前
        objects.draw_healthbars(canvas, vp)?;

        Ok(())
    }

    pub fn process_doors(&mut self, now_ms: Millis) -> bool {
        let mut changed = false;
        for d in &mut self.doors {
            match d.state {
                DoorState::Opening | DoorState::Closing => {
                    if now_ms > d.last_tick_ms + 50 {
                        d.last_tick_ms = now_ms;
                        d.image_index += 1;
                        if d.image_index >= 1 { // 等价 C# 的“1帧即完成”，按资源可扩展
                            d.image_index = 0;
                            d.state = match d.state {
                                DoorState::Opening => DoorState::Open,
                                DoorState::Closing => DoorState::Closed,
                                _ => d.state,
                            };
                            changed = true;
                        }
                    }
                }
                DoorState::Open => {
                    if now_ms > d.last_tick_ms + 5000 {
                        d.last_tick_ms = now_ms;
                        d.state = DoorState::Closing;
                        changed = true;
                    }
                }
                DoorState::Closed => {}
            }
        }
        changed
    }
}

impl MapReader {
    pub fn load_type100(_ctx: &mut Context, path: &str) -> Result<Map> {
        // TODO: 实现 Type100 格式解析（参考 C# LoadMapType100）

    }
}
```

```rust name=src/lighting.rs
use ggez::graphics::{self, Canvas, Color, DrawParam, BlendMode};
use glam::IVec2;
use anyhow::Result;
use crate::{resources::ResourceManager, objects::ObjectManager, map::Map, types::Viewport};

pub struct Lighting {
    // 选用夜晚/黄昏/清晨/白天（你可以接 GameScene 的 TimeOfDay/MapDarkLight）
    pub setting: LightSetting,
    pub map_dark_light: u8,
    pub blindness: bool,
}

#[derive(Clone, Copy)]
pub enum LightSetting { Day, Normal, Dawn, Evening, Night }

impl Lighting {
    pub fn new(_res: &ResourceManager) -> Result<Self> {
        Ok(Self { setting: LightSetting::Normal, map_dark_light: 0, blindness: false })
    }

    pub fn darkness_color(&self) -> Color {
        let mut c = match self.setting {
            LightSetting::Night => match self.map_dark_light {
                1 => Color::from_rgb(20,20,20),
                2 => Color::from_rgb(119,136,153), // LightSlateGray
                3 => Color::from_rgb(135,206,235), // SkyBlue
                4 => Color::from_rgb(218,165,32),  // Goldenrod
                _ => Color::BLACK
            },
            LightSetting::Dawn | LightSetting::Evening => Color::from_rgba(50,50,50,255),
            _ => Color::from_rgba(255,255,255,255),
        };
        if self.blindness {
            // 失明：进一步压暗
            c = Color::from_rgba(c.r().min(0.2), c.g().min(0.2), c.b().min(0.2), 1.0);
        }
        c
    }

    pub fn draw_object_lights(&self, _ctx: &mut ggez::Context, res: &ResourceManager, objs: &ObjectManager, vp: &Viewport) -> ggez::GameResult {
        // 示例：遍历对象，根据对象光照等级选择 res.lights[n]，Add 叠加
        for ol in objs.object_lights_iter() {
            let n = ol.radius_idx.min(res.lights.len().saturating_sub(1));
            let light_img = &res.lights[n];
            let p = ol.screen_pos; // 已转换为屏幕像素中心
```

二、移植要点（对应 C# 语义到 ggez 的映射）
- FloorTexture/LightTexture
  - C#：Texture + SetSurface → 画入贴图；Rust：Canvas 离屏，graphics::set_canvas(ctx, Some(&canvas))，画完再 set_canvas(None)。
- 混合模式
  - C#：SourceAlpha/One（Add），Zero/SourceColor（乘）；Rust：BlendMode::Add / BlendMode::Multiply。
- 动画帧推进
  - 与 C# 一致：frame += (anim_count % (frames + frames*tick)) / (1 + tick)
- 门动画
  - frame += (door.image_index + 1) * door_offset，且 50ms 推进 1，Open 状态 5s 自动转 Closing。
- 中间层/前景层“上画/透明叠加”
  - C# 使用 DrawUp/DrawBlend；ggez 用不同 Draw 调用与 BlendMode 切换实现；必要时在 objects.draw_alive 之后再补画一遍前景半透明层，保证遮挡关系。

三、下一步建议
1) MapReader
   - 按 [Crystal/MapCode.cs 的 LoadMapType100](https://github.com/Suprcode/Crystal/blob/34553c90f88b74be4c4b7806de07bc71c9663a6c/Client/MirObjects/MapCode.cs#L622-L670) 先实现 Type100（简单直接，字段同名）。
   - 逐步实现 Type2/3/5/6：注意 0x8000 → 0x20000000 的标志变换和 Index 偏移（+100/+110/+120/+300）。
2) Library/资源
   - 建议把 .lib 转为 atlas+json（帧矩形+偏移），Rust 用 Library.draw(src_rect,dest) 即可。
   - 先把 MapLibs 用 1 张 atlas 替代，验证管线，然后扩展到多库。
3) 对象层（玩家/怪/NPC/掉落/法术）
   - 先只画一个“占位玩家”贴图/动画，打通 world_to_screen 与 Z 顺序，再完善排序/描边/血条/名字。
4) 光照
   - 把 Crystal 的 11 个 light 贴图（不同半径）放到 assets/lights/，draw_object_lights/ draw_map_lights 填充即可。
5) 天气
   - 先实现雪/雨粒子：每帧 spawn+更新+Draw；ggez 可直接 draw Image 或用 Mesh 简化。

四、与 Crystal 关键点一一对应
- 地图绘制：Map.draw_floor 对应 GameScene.MapControl.DrawFloor 的 Back/Middle/Front 顺序与动画推进。
- 对象/特效：objects.* 这些函数对应 DrawObjects 的分层（behind effects → dead → alive → overlays → health）。
- 光照：Lighting.draw_* 对应 DrawLights 中对象光/特效光/地图灯三段，加法叠加后用 Multiply 乘到主画面。
- 定时：Timing.animation_count 每 100ms 递增，对应 MoveTime；门动画 50ms，Open→关闭 5 秒。
