游戏窗口将**自动弹出**当编译完成时。

### 2. 检查编译进度

```powershell
# 在新终端中查看进程
Get-Process cargo -ErrorAction SilentlyContinue
```

输出示例:
```
ProcessName Handles Memory
----------- ------- ------
cargo           152 (内存占用)
cargo           140
cargo           138
```

- **3 个进程存在** = 编译中
- **0 个进程** = 编译完成

### 3. 手动启动游戏

如果等不了可以新开终端运行:


## 🔍 故障排除

### 如果编译一直卡住

```powershell
# 1. 停止所有 cargo 进程
Get-Process cargo -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. 等待 2 秒
Start-Sleep -Seconds 2

# 3. 清理和重新编译
cargo clean
cargo build --bin mir2_bevy
```

### 如果仍然失败

```powershell
# 尝试 Release 模式
cargo build --release --bin mir2_bevy

# 或者只检查
cargo check
```
