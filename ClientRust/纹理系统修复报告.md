# 纹理系统修复报告

## 📋 问题描述

用户报告："角色选择和游戏场景的纹理都没了"

**根本原因**: graphics 模块删除了 `GgezManager` 类型，但多个场景仍在使用它，导致纹理无法加载。

### 6. SelectScene 大规模重构
**文件**: `src/scenes/select_scene.rs`

#### 更新签名
```rust
fn draw(&mut self, ctx: &mut Context, canvas: &mut Canvas)  // 移除 ggez_manager
```

#### 纹理加载方式迁移

**旧方式（已废弃）**:
```rust
if let Some(bg_texture) = ggez_manager.get_texture("Prguse_65") {
    canvas.draw(bg_texture, DrawParam::default().dest([0.0, 0.0]));
}
```

**新方式（使用库系统）**:
```rust
use crate::graphics::libraries::{get_library, LibraryName};

if let Some(lib_arc) = get_library(LibraryName::Prguse) {
    if let Ok(mut lib) = lib_arc.try_lock() {
        let _ = lib.draw_with_color(ctx, canvas, 65, 0.0, 0.0, Color::WHITE, false);
    }
}
```

## 🔧 技术细节

### 新的纹理加载模式

**1. 基础绘制**
```rust
use crate::graphics::libraries::{get_library, LibraryName};

if let Some(lib_arc) = get_library(LibraryName::Prguse) {
    if let Ok(mut lib) = lib_arc.try_lock() {
        // image_index: usize, x: f32, y: f32, color: Color, use_offset: bool
        let _ = lib.draw_with_color(ctx, canvas, 65, 0.0, 0.0, Color::WHITE, false);
    }
}
```

**2. 带偏移绘制（角色/物体）**
```rust
// use_offset=true 自动应用图像的偏移量（用于正确定位）
let _ = lib.draw_with_color(ctx, canvas, index, x, y, Color::WHITE, true);
```

**3. 混合模式绘制（特效）**
```rust
let _ = lib.draw_blend(ctx, canvas, index, x, y, Color::WHITE, opacity);
```

### 库名映射

## 📝 注意事项

### ⚠️ 常见错误

1. **类型错误**
```rust
// ❌ 错误
lib.draw_with_color(ctx, canvas, 65, ...)  // i32

// ✅ 正确
lib.draw_with_color(ctx, canvas, 65 as usize, ...)  // usize
```

2. **偏移量错误**
```rust
// ❌ 角色/物体不正确定位
lib.draw_with_color(ctx, canvas, index, x, y, Color::WHITE, false)

// ✅ 使用偏移量正确定位
lib.draw_with_color(ctx, canvas, index, x, y, Color::WHITE, true)
```

3. **库名错误**
```rust
// ❌ 使用字符串键
ggez_manager.get_texture("Prguse_65")  // 旧方式

// ✅ 使用枚举 + 索引
get_library(LibraryName::Prguse)  // 新方式
lib.draw_with_color(ctx, canvas, 65, ...)
```
