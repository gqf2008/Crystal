# 文本和光标垂直对齐修复

## 🐛 问题描述

用户反馈:
1. **登录界面**: 光标和字符偏下
2. **新建账号界面**: 光标正确,字符偏下

## 🔍 根本原因

### ggez文本渲染机制
- ggez使用**基线(baseline)对齐**来绘制文本
- `scale(21.0)` 的文本实际高度约为 21 像素
- 文本的基线位于给定Y坐标,导致文本看起来偏下

### 原始问题
```
输入框高度: 18px (C#原版)
文本scale: 21.0
文本Y坐标: y + 2.0
光标Y坐标: y + 2.0
光标高度: 14.0

问题:
1. 文本从 y+2 开始绘制,基线对齐导致实际渲染位置偏下
2. 光标高度14px太小,无法完全覆盖21px的文本高度
```

## ✅ 修复方案

### 调整策略
1. **文本Y坐标**: 向上移动,使其在输入框中垂直居中
2. **光标高度**: 增加到16px,匹配文本高度
3. **光标Y坐标**: 与文本保持一致

## 📝 具体修改

### 1. 登录界面 (login_scene.rs)

#### 修改文本Y坐标

```rust
// 之后:
.dest([account_text_x, account_text_y - 3.0])  // 向上移3像素使其居中
```

**位置**: 第403行、第416行

#### 修改光标Y坐标
```rust
// 之前:

// 之后:
```

**位置**: 第441行、第458行


### 3. 修改密码界面 (login_scene.rs)

#### 修改文本Y坐标

```rust
// 之后:
```

**位置**: 第780行

#### 修改光标矩形和位置计算
```rust

Rect::new(cursor_x, *y + 2.0, 2.0, 14.0)

// 之后:
let text_width = content_text.measure(ctx).map(|m| m.x).unwrap_or(0.0);  // 精确测量

Rect::new(cursor_x, *y + 1.0, 2.0, 16.0)  // 高度改为16px,Y坐标+1
```

**位置**: 第786-794行

## 🔧 技术细节

### Y坐标调整原理

**登录界面** (输入框位置由固定坐标决定):
- 输入框大约20-22px高
- 文本scale 21.0,实际渲染高度约21px
- 向上移动3px让文本在输入框中居中

**新建账号/修改密码** (输入框高度18px):
- 输入框高度: 18px (Rect边框)
- 文本scale: 21.0
- 原Y坐标: y + 2 (输入框顶部向下2px)
- 新Y坐标: y - 1 (输入框顶部向上1px)
- 实际效果: 文本在18px输入框中更居中

### 光标高度选择

- 原高度: 14px (太小)
- 新高度: 16px (约占21px文本的76%)
- 选择16px而非21px的原因:
  1. 避免光标超出输入框边界
  2. 保持视觉平衡
  3. 与C#原版风格一致
