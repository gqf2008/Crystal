# 地图查看器寻路调试功能说明

## 功能概述

为 ECS 地图查看器添加了寻路路径可视化功能,用于调试和验证 A* 寻路算法的正确性。

## 修复的问题

### 1. ✅ 右键寻路不触发问题

**问题原因:**
- 原来的逻辑: `!player.is_moving || (距离检查)`
- 当 `player.is_moving=false` 时,逻辑短路返回 false,寻路永远不触发

**解决方案:**
```rust
let should_recalculate = if player.path.is_empty() {
    true  // 没有路径时必须寻路
} else {
    // 目标移动超过3格才重新寻路
    let dx = (target_grid_x - current_target.0).abs();
    let dy = (target_grid_y - current_target.1).abs();
    dx > 3 || dy > 3
};
```

**结果:** ✅ 右键点击立即触发寻路

---

### 2. ✅ 鼠标静止时方向抖动问题

**问题原因:**
- 每帧都更新方向,即使距离目标很近
- 浮点数精度导致在近距离时方向计算不稳定

**解决方案:**
```rust
// 只在距离目标超过10像素时才更新方向
if distance > 10.0 {
    let target_dir = Self::calculate_direction(dx, dy);
    player.direction = Self::smooth_direction(player.direction, target_dir);
}
```

**结果:** ✅ 鼠标静止时角色方向稳定

---

### 3. ✅ 寻路路径可视化

**新增功能:**

#### 路径绘制 (`draw_path`)
- **从玩家到第一个路径点**: 黄色线段 (2px)
- **路径点之间**: 青色线段 (2px)
- **路径点标记**:
  - 当前目标点: 红色圆圈 (半径 6px)
  - 未来路径点: 黄色圆圈 (半径 3px)
  - 已走过的点: 不显示

#### 键盘快捷键
- **P 键**: 切换寻路路径显示/隐藏
- 默认状态: 隐藏
- 控制台输出: `🎯 寻路路径 (P): 显示/隐藏`

## 使用方法

### 基本操作
1. **启动程序**: `cargo run --bin map_viewer_ecs`
2. **鼠标左键长按**: 角色走动 (速度 1.33 px/frame)
3. **鼠标右键长按**: 角色跑动 + 自动寻路 (速度 1.6 px/frame)
4. **按 P 键**: 显示/隐藏寻路路径

### 调试寻路
1. 按 **P** 键启用路径显示
2. 右键点击远处目标
3. 观察路径线条和路径点:
   - **黄色线**: 玩家→第一路径点
   - **青色线**: 路径点之间的连接
   - **红色圆**: 当前正在移动向的目标点
   - **黄色圆**: 后续路径点

### 验证寻路正确性
- ✅ 路径避开障碍物(黑色/红色方块)
- ✅ 路径点逐渐减少(走过的点消失)
- ✅ 到达目标后路径清空
- ✅ 可以绕过墙壁、树木等障碍

## 技术细节

### 坐标转换
1. **鼠标屏幕坐标** → 世界坐标 (`screen_to_world`)
2. **世界坐标** → 地图格子坐标 (`world_to_grid`)
3. **格子坐标** → 世界坐标 (`grid_to_world`)
4. **世界坐标** → 屏幕坐标 (`world_to_screen`)

### A* 寻路参数
- **障碍物检测**: `door_index == 0 && front_image == 0`
- **对角移动**: 启用
- **最大迭代次数**: 1000
- **重新寻路阈值**: 目标移动 >3 格

### 方向系统
- **8 方向**: 0=上, 1=右上, 2=右, 3=右下, 4=下, 5=左下, 6=左, 7=左上
- **平滑转向**: 每次只旋转 1 个方向(45°)
- **稳定阈值**: 距离 >10px 才更新方向

## 性能影响

### 路径绘制开销
- **线段绘制**: 每条路径 N-1 条线段
- **圆形绘制**: 每个路径点 1 个圆
- **建议**: 仅在调试时启用(默认关闭)

### 优化措施
- ✅ 只绘制未走过的路径点
- ✅ 使用 `Mesh::new_line` 和 `Mesh::new_circle` (高效)
- ✅ 可通过 P 键随时关闭
