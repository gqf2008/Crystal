# 地图瓦片不显示 - 诊断指南 🔍

## 问题: 看不到地图瓦片,只有文字

### 可能原因和解决方案

---

## 1. 检查 Tiles.lib 文件是否存在 ⭐ 最可能

**位置**: `ClientRust/Data/Tiles/` 或 `Build/Client/Data/Tiles/`

**需要的文件**:
- `Tiles.lib`
- `Tiles1.lib`
- `Tiles2.lib`
- ... (可选)

### 检查方法:

```powershell
# 在 ClientRust 目录下运行
ls Data/Tiles/Tiles.lib
ls ../Build/Client/Data/Tiles/Tiles.lib
```

### 如果文件不存在:

**解决方案**: 从传奇客户端复制 Tiles 文件

1. 找到原版传奇客户端目录 (例如 `C:\MirClient\`)
2. 复制 `Data\Tiles\*.lib` 文件
3. 粘贴到 `ClientRust\Data\Tiles\` 目录

```powershell
# 创建目录
mkdir -p Data/Tiles

# 从原版客户端复制 (假设在 C:\MirClient)
copy "C:\MirClient\Data\Tiles\*.lib" Data\Tiles\
```

---

## 2. 检查 .map 文件是否存在

**位置**: `ClientRust/Data/Map/` 或 `Build/Client/Data/Map/`

**需要的文件**: 例如 `0.map` (地图编号)

### 检查方法:

```powershell
ls Data/Map/0.map
ls ../Build/Client/Data/Map/0.map
```

### 如果文件不存在:

从传奇服务端复制地图文件:

```powershell
mkdir -p Data/Map
copy "C:\MirServer\Mir200\Envir\Map\*.map" Data\Map\
```

---

## 4. 检查服务器是否发送地图信息

### 问题: 服务器没有发送 MapInformation 事件

**症状**: 控制台没有 "Loading map" 日志

**原因**: 
- 服务器未发送地图数据包
- 网络连接问题
- 角色未正确进入游戏

**解决方案**:
1. 检查服务器日志
2. 确认角色成功登录
3. 检查 GameClient 是否接收到 MapInformation 事件

---

## 5. 数据路径配置问题

### 当前配置

在 `main_ggez.rs` 中:

```rust
let data_path = "Data".to_string();
graphics::libraries::set_data_path(data_path);
```

### 搜索路径

代码会按以下顺序搜索:
1. `Data/Tiles/`
2. `../Data/Tiles/`
3. `../../Data/Tiles/`
4. `../../../Build/Client/Data/Tiles/`

### 检查方法:

确保至少一个路径存在:

```powershell
# 检查所有可能路径
Get-ChildItem -Path Data\Tiles\Tiles.lib -ErrorAction SilentlyContinue
Get-ChildItem -Path ..\Data\Tiles\Tiles.lib -ErrorAction SilentlyContinue
Get-ChildItem -Path ..\..\Data\Tiles\Tiles.lib -ErrorAction SilentlyContinue
Get-ChildItem -Path ..\..\..\Build\Client\Data\Tiles\Tiles.lib -ErrorAction SilentlyContinue
```

## 6. 快速诊断脚本

创建 `check_files.ps1`:

```powershell
# 检查 Tiles 库
Write-Host "=== Checking Tiles Libraries ===" -ForegroundColor Cyan

$tilesPath = "Data/Tiles"
if (Test-Path $tilesPath) {
    Write-Host "✓ Tiles directory exists" -ForegroundColor Green
    $libFiles = Get-ChildItem "$tilesPath/*.lib"
    Write-Host "  Found $($libFiles.Count) .lib files:" -ForegroundColor Yellow
    $libFiles | ForEach-Object { Write-Host "    - $($_.Name)" }
} else {
    Write-Host "✗ Tiles directory NOT found!" -ForegroundColor Red
    Write-Host "  Create it: mkdir $tilesPath" -ForegroundColor Yellow
}

Write-Host ""

# 检查地图文件
Write-Host "=== Checking Map Files ===" -ForegroundColor Cyan

$mapPath = "Data/Map"
if (Test-Path $mapPath) {
    Write-Host "✓ Map directory exists" -ForegroundColor Green
    $mapFiles = Get-ChildItem "$mapPath/*.map"
    Write-Host "  Found $($mapFiles.Count) .map files:" -ForegroundColor Yellow
    $mapFiles | ForEach-Object { Write-Host "    - $($_.Name)" }
} else {
    Write-Host "✗ Map directory NOT found!" -ForegroundColor Red
    Write-Host "  Create it: mkdir $mapPath" -ForegroundColor Yellow
}

Write-Host ""
Write-Host "=== Diagnosis Complete ===" -ForegroundColor Cyan
```

运行:

```powershell
cd ClientRust
.\check_files.ps1
```
