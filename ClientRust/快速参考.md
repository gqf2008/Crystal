# 🎮 GameScene 渲染系统 - 快速参考

## ⚡ 快速开始

```powershell
# 编译和运行
cargo run --bin mir2_bevy

# 按 F3 进入游戏场景
# 按 F5 重新加载地图
```

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| **F1** | 登录场景 |
| **F2** | 选择场景 |
| **F3** | 游戏场景 (地图渲染) |
| **F5** | 重新加载地图 |
| **ESC** | 返回登录 |

## 📝 关键 API

### MapLoadRequest (地图加载)
```rust
load_request.request("0".to_string());
```

### GameCamera (摄像机)
```rust
camera.follow_target(x, y);
camera.set_map_bounds(width, height);
```

### MapRenderData (地图数据)
```rust
map_data.cells;    // 格子数据
map_data.width;    // 宽度
map_data.height;   // 高度
map_data.doors;    // 门列表
```
