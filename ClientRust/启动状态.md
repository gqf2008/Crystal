## 📋 预期初始化流程

游戏启动时会执行以下步骤：

1. **初始化 Bevy 引擎** (~0.5s)
   - 创建应用上下文
   - 初始化渲染系统
   - 设置输入处理

2. **加载游戏资源** (~1-2s)
   - 加载地图数据
   - 初始化玩家实体
   - 加载对话树

3. **初始化游戏系统** (~0.5s)
   - setup_player_system
   - setup_game_loop_system
   - setup_chat_system

4. **进入游戏场景** (~0.5s)
   - OnEnter(Game) 状态
   - 激活所有游戏系统
   - 显示游戏窗口

**总初始化时间**: ~2-3 秒

## ⚠️ 可能的问题和解决方案

### 问题 1: 编译失败

**症状**: 看到红色错误信息  
**原因**: 依赖版本冲突或代码问题  
**解决**:
```powershell
cargo clean
cargo build --bin mir2_bevy
```

### 问题 2: 窗口无法打开

**症状**: 编译完成但无窗口出现  
**原因**: 可能需要图形驱动支持  
**解决**:
- 确保显卡驱动已安装
- 尝试运行调试版本

### 问题 3: 低帧率

**症状**: FPS 低于 30  
**原因**: 这是 Debug 模式的特性  
**解决**: 使用 Release 模式编译

### 完整的 ECS 架构

- **Entity**: 游戏对象 (玩家, NPC, 地图对象)
- **Component**: 数据结构 (位置, 属性, 状态)

- **Message**: 事件系统 (34 种消息)
