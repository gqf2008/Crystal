### ✅ **C# 原版的真实实现**

**瓦片绘制逻辑在 `GameScene` 中，直接访问 `M2CellInfo` 数组**：

```csharp
// Client/MirScenes/GameScene.cs

public class GameScene {
    public CellInfo[,] M2CellInfo;  // 地图格子数组（从 MapReader 加载）
    
    private void DrawFloor() {
        // ========== BACK LAYER ==========
        for (int y = ...; y <= ...; y++) {
            for (int x = ...; x <= ...; x++) {
                // ✅ 直接访问 CellInfo 的字段
                if ((M2CellInfo[x, y].BackImage == 0) || 
                    (M2CellInfo[x, y].BackIndex == -1)) continue;
                
                index = (M2CellInfo[x, y].BackImage & 0x1FFFFFFF) - 1;
                
                // ✅ 直接调用 MLibrary 绘制
                Libraries.MapLibs[M2CellInfo[x, y].BackIndex].Draw(index, drawX, drawY);
            }
        }
        
        // ========== MIDDLE LAYER ==========
        for (int y = ...; y <= ...; y++) {
            for (int x = ...; x <= ...; x++) {
                index = M2CellInfo[x, y].MiddleImage - 1;
                if ((index < 0) || (M2CellInfo[x, y].MiddleIndex == -1)) continue;
                
                // 尺寸验证
                Size s = Libraries.MapLibs[M2CellInfo[x, y].MiddleIndex].GetSize(index);
                if ((s.Width != 48 || s.Height != 32) && ...) continue;
                
                // ✅ 直接调用 MLibrary 绘制
                Libraries.MapLibs[M2CellInfo[x, y].MiddleIndex].Draw(index, drawX, drawY);
            }
        }
        
        // ========== FRONT LAYER ==========
        for (int y = ...; y <= ...; y++) {
            for (int x = ...; x <= ...; x++) {
                index = (M2CellInfo[x, y].FrontImage & 0x7FFF) - 1;
                int fileIndex = M2CellInfo[x, y].FrontIndex;
                
                // 门动画处理
                if (M2CellInfo[x, y].DoorIndex > 0) {
                    Door door = GetDoor(M2CellInfo[x, y].DoorIndex);
                    if (door != null && door.DoorState != 0) {
                        index += (door.ImageIndex + 1) * M2CellInfo[x, y].DoorOffset;
                    }
                }
                
                // ✅ 直接调用 MLibrary 绘制
                Libraries.MapLibs[fileIndex].Draw(index, drawX, drawY);
            }
        }
    }
}
```

### 📝 **CellInfo 的真实职责**

C# 原版中，`CellInfo` **只有4个方法**：

1. ✅ `AddObject(MapObject)` - 添加对象
2. ✅ `RemoveObject(MapObject)` - 移除对象
3. ✅ `FindObject(uint)` - 查找对象
4. ✅ `DrawObjects()` - 绘制该格子上的对象
5. ✅ `DrawDeadObjects()` - 绘制死亡对象
6. ✅ `Sort()` - 对象排序

**没有任何瓦片绘制方法！**

```rust
// ClientRust/examples/simple_map_viewer.rs

impl SimpleMapViewer {
    // ✅ 这就是正确的做法！
    fn draw_back_layer(&mut self, ctx: &mut Context, canvas: &mut Canvas) -> GameResult {
        for map_y in (start_y..end_y).step_by(2) {
            for map_x in (start_x..end_x).step_by(2) {
                let Some(cell) = self.cell(map_x, map_y) else { continue };
                
                // ✅ 直接访问 CellInfo 的字段
                if cell.back_image <= 0 || cell.back_index < 0 {
                    continue;
                }
                
                let lib_index = cell.back_index as usize;
                let image_index = ((cell.back_image & 0x1FFF_FFFF) as usize).saturating_sub(1);
                
                // ✅ 直接调用 MLibrary 绘制
                if let Ok(texture) = lib.get_or_create_texture(ctx, image_index) {
                    canvas.draw(texture, DrawParam::default().dest([screen_x, screen_y]));
                }
            }
        }
        Ok(())
    }
}
```

## 📖 关键启示

**设计原则**：
1. **数据与逻辑分离** - CellInfo 只存数据，不管绘制
2. **场景管理器负责渲染** - GameScene/SimpleMapViewer 协调一切
3. **图库提供基础绘制** - MLibrary 只管画图，不管业务逻辑
