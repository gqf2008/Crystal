# 新建账号对话框按钮纹理修复

## 问题
新建账号对话框的 OK 和 Cancel 按钮显示的纹理不正确。

## 原因分析
错误地使用了更改密码对话框的按钮纹理索引:
- 错误的索引: OK=107, Cancel=110
- 正确的索引: OK=200, Cancel=203

## C# 原工程参考
在 `Client/MirScenes/LoginScene.cs` 的 `NewAccountDialog` 类中:

```csharp
// OK Button
OKButton = new MirButton
{
    Enabled = false,
    HoverIndex = 201,      // 悬停时的纹理索引
    Index = 200,           // 正常状态的纹理索引
    Library = Libraries.Title,
    Location = new Point(135, 425),
    Parent = this,
    PressedIndex = 202,    // 按下时的纹理索引
};

// Cancel Button
CancelButton = new MirButton
{
    HoverIndex = 204,
    Index = 203,
    Library = Libraries.Title,
    Location = new Point(409, 425),
    Parent = this,
    PressedIndex = 205
};
```

## 修复内容

文件: `ClientRust/src/bevy/scenes/login_scene_v2/mod.rs`

### 修改 1: 按钮纹理加载 (行 ~1295)
```rust
// 修改前:
let ok_button_tex = mlibrary_assets.get_texture("Title", 107, images)
let cancel_button_tex = mlibrary_assets.get_texture("Title", 110, images)

// 修改后:
let ok_button_tex = mlibrary_assets.get_texture("Title", 200, images)
let cancel_button_tex = mlibrary_assets.get_texture("Title", 203, images)
```

### 修改 2: OK 按钮纹理索引 (行 ~1345)
```rust
ButtonTextures {
    normal_index: 200,   // 原来是 107
    hover_index: 201,    // 原来是 108
    pressed_index: 202,  // 原来是 109
}
```

### 修改 3: Cancel 按钮纹理索引 (行 ~1360)
```rust
ButtonTextures {
    normal_index: 203,   // 原来是 110
    hover_index: 204,    // 原来是 111
    pressed_index: 205,  // 原来是 112
}
```

## 对话框按钮纹理索引总结

| 对话框 | 按钮 | Normal | Hover | Pressed | Library |
|-------|------|--------|-------|---------|---------|
| 新建账号 | OK | 200 | 201 | 202 | Title |
| 新建账号 | Cancel | 203 | 204 | 205 | Title |
| 更改密码 | OK | 107 | 108 | 109 | Title |
| 更改密码 | Cancel | 110 | 111 | 112 | Title |

## 测试
修复后,新建账号对话框的按钮应该:
1. ✅ 正常状态显示正确的纹理
2. ✅ 鼠标悬停时改变为悬停纹理
3. ✅ 鼠标按下时显示按下纹理
4. ✅ 按钮位置正确 (OK: 135,425  Cancel: 409,425)
