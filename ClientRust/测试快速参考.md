## 🎨 图像标记处理

### BackImage 标记

```rust
// 高位标记转换
if (back_image & 0x8000) != 0 {
    back_image = (back_image & 0x7FFF) | 0x20000000
}

// 屏蔽标记位
actual_index = back_image & 0x1FFFFFFF
```

### FrontImage 标记

```rust
// 屏蔽高位
actual_index = front_image & 0x7FFF
```

### 动画标记

```rust
// 混合模式标记 (0x80)
has_blend = (frame_count & 0x80) != 0
frame_count = frame_count & 0x7F

// 瓦片动画
offset = offset ^ 0x2000
```
