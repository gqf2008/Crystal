# GameScene 黑屏问题诊断指南

**问题**: 进入游戏场景后出现黑屏
**最后更新**: 2024年

---

## 一、问题分析

### 可能的原因

1. **状态机卡在加载状态**
   - `WaitingForData` - 等待 MapInformation 或 UserInformation
   - `LoadingMap` - 地图加载失败或卡住
   - `WaitingForPlayer` - UserInformation 未到达

2. **状态是 Ready 但地图未渲染**
   - 地图数据为空
   - 摄像机位置错误
   - 纹理库加载失败

3. **加载提示文本未显示**
   - 文本颜色与背景色相同
   - 文本位置超出屏幕
   - Canvas 绘制失败

---

## 二、快速诊断步骤

### 步骤 1: 检查控制台日志

启动游戏后,在控制台(PowerShell)中查找以下关键日志:

#### ✅ 正常流程的日志:
```
[INFO] 🎬 GameScene::draw() 第 1 帧, 当前状态: WaitingForData
[INFO] 📺 绘制加载屏幕: "等待服务器数据..." (屏幕: 1024x768)
[INFO] 🗺️  收到服务器地图信息:
[INFO] 🔄 状态切换: WaitingForData → LoadingMap(0.map)
[INFO] 🎬 GameScene::draw() 第 10 帧, 当前状态: LoadingMap("0.map")
[INFO] 📺 绘制加载屏幕: "正在加载地图: 0.map" (屏幕: 1024x768)
[INFO] ✅ 地图加载成功: 200 x 200 格子
[INFO] 🔄 状态切换: LoadingMap → WaitingForPlayer
[INFO] ✅ 玩家对象创建成功: ObjectID: 12345
[INFO] 🔄 状态切换: WaitingForPlayer → Ready
[INFO] 🎬 GameScene::draw() 第 100 帧, 当前状态: Ready
[INFO] 🎬 状态 = Ready, 开始正常渲染游戏内容
```

#### ❌ 异常情况:

**情况 A: 卡在 WaitingForData**
```
[INFO] 🎬 GameScene::draw() 第 1 帧, 当前状态: WaitingForData
[INFO] 🎬 GameScene::draw() 第 61 帧, 当前状态: WaitingForData
[INFO] 🎬 GameScene::draw() 第 121 帧, 当前状态: WaitingForData
... (一直是 WaitingForData)
```
**诊断**: MapInformation 或 UserInformation 未到达
**解决**: 检查网络连接和服务器配置

**情况 B: 卡在 LoadingMap**
```
[INFO] 🔄 状态切换: WaitingForData → LoadingMap(0.map)
[ERROR] ❌ 地图加载失败: 找不到地图文件 "Data/Map/0.map"
```
**诊断**: 地图文件不存在或路径错误
**解决**: 检查 `ClientRust/Data/Map/` 目录是否有 `0.map` 文件

**情况 C: 状态是 Ready 但黑屏**
```
[INFO] 🔄 状态切换: WaitingForPlayer → Ready
[INFO] 🎬 状态 = Ready, 开始正常渲染游戏内容
[INFO] 🎥 玩家位置 (格): (100, 100)
[INFO] 🎥 摄像机位置: (4800.0, 3200.0)
... (但屏幕仍然是黑色)
```
**诊断**: 地图渲染逻辑有问题
**解决**: 检查 MapRenderer 和纹理库

---

### 步骤 2: 检查游戏窗口

在游戏窗口中观察:

1. **完全黑屏,无任何文字**
   - 可能是加载提示文本未显示
   - 检查 `draw_loading_screen()` 是否被调用

2. **黑屏,但有白色文字提示**
   - 正常的加载状态
   - 等待服务器数据或地图加载

3. **深绿色屏幕,无地图**
   - 状态已经是 Ready,但地图未渲染
   - 检查 MapRenderer 是否有数据

### 修复 2: 改进加载屏幕显示 (已实施)

**问题**: 加载提示文本太小或颜色不明显
**解决**: 
- 字体大小从默认改为 32px
- 使用纯白色文本 (Color::WHITE)
- 先绘制黑色背景覆盖绿色底色

**代码**:
```rust
fn draw_loading_screen(&self, canvas: &mut Canvas, message: &str, ...) {
    // 1. 绘制黑色背景覆盖整个屏幕
    canvas.draw(&ggez::graphics::Quad, 
        DrawParam::default()
            .scale(Vec2::new(screen_width, screen_height))
            .color(Color::BLACK));
    
    // 2. 绘制大号白色文本
    let mut text = Text::new(message);
    text.set_scale(PxScale::from(32.0));  // 32px 大字体
    canvas.draw(&text, 
        DrawParam::default()
            .dest(Vec2::new(text_x, text_y))
            .color(Color::WHITE));
}
```

## 五、常见问题 FAQ

### Q1: 一直显示 "等待服务器数据..." 怎么办?

**A**: 服务器未发送 MapInformation 或 UserInformation
- 检查服务器是否正常运行
- 检查网络连接
- 查看服务器日志,确认角色数据已发送

---

### Q2: 显示 "正在加载地图: 0.map" 后卡住

**A**: 地图加载失败
- 检查 `ClientRust/Data/Map/0.map` 文件是否存在
- 检查控制台是否有 `[ERROR] ❌ 地图加载失败` 错误
- 确认地图文件格式正确

---

### Q3: 状态变成 Ready 但屏幕是深绿色,没有地图

**A**: 地图渲染有问题
- 检查 MapRenderer 是否加载了地图数据:
  ```
  [INFO] ✅ 地图加载成功: 200 x 200 格子
  ```
- 检查摄像机位置是否在地图范围内
- 检查纹理库 (Tiles.lib) 是否加载成功

---

### Q4: 看不到加载提示文字

**A**: draw_loading_screen() 可能未被调用或文字颜色问题
- 查找日志: `📺 绘制加载屏幕: "XXX"`
- 如果没有这条日志,说明状态检查有问题
- 如果有日志但看不到文字,可能是颜色或位置问题
