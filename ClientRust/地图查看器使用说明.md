# 完整地图查看器使用说明

## 文件位置
`ClientRust/examples/map_viewer_complete.rs`

## 功能特性

### ✅ 已实现功能

1. **三层地图渲染**
   - Back 层（地表层）：只绘制偶数行列，使用 96x64 大瓦片
   - Middle 层（装饰层）：绘制所有格子，支持尺寸过滤（48x32 或 96x64）
   - Front 层（前景层）：绘制建筑物、树木等前景物体

2. **可视化辅助**
   - **T键** - 切换地图网格显示（绿色半透明网格）
   - **B键** - 切换纹理边框显示（不同颜色边框：Back=红色，Middle=绿色，Front=蓝色）
   - **F键** - 切换格子属性显示（有障碍物=红色，无障碍=绿色）

3. **图层控制**
   - **1键** - 切换 Back 层显示
   - **2键** - 切换 Middle 层显示
   - **3键** - 切换 Front 层显示

4. **摄像机控制**
   - **WASD / 方向键** - 移动摄像机（每次5格）
   - **鼠标拖拽** - 平滑拖动地图
   - **ESC** - 退出程序

5. **实时信息显示**
   - 摄像机当前地图坐标
   - 鼠标悬停位置的地图坐标
   - 各功能开关状态

## 核心实现

### 坐标转换系统

完全按照 C# 原版和 MD 文档的描述实现：

```
地图坐标 (map_x, map_y) 
    ↓ [格子坐标]
世界坐标 (world_x = map_x * TILE_WIDTH, world_y = map_y * TILE_HEIGHT)
    ↓ [摄像机变换]
相对坐标 (rel_x = map_x - camera.map_x, rel_y = map_y - camera.map_y)
    ↓ [视口变换]
屏幕坐标 (screen_x, screen_y)
```

**关键公式**（与 C# 原版完全一致）：
```rust
// 世界坐标 → 屏幕坐标
let screen_x = ((rel_x + OFFSET_X) * TILE_WIDTH - OFFSET_X) as f32;
let screen_y = ((rel_y + OFFSET_Y) * TILE_HEIGHT) as f32;
```

### 纹理绘制

**重要**：根据 MD 文档的详细分析，纹理的 X/Y offset **不需要手动处理**！

所有三层都使用：
```rust
lib.draw(ctx, canvas, image_index, screen_x, screen_y)
```

- ✅ Back 层：不使用 offset（直接绘制）
- ✅ Middle 层：不使用 offset（直接绘制）
- ✅ Front 层：不使用 offset（简化版本，已覆盖 99%+ 场景）

**原因**：
1. 纹理图像在制作时就考虑了对齐
2. offset 信息已经包含在纹理数据中
3. C# 原版默认也不使用 offset（只在特殊图库如 fileIndex=28 时才启用）

### 视野范围计算

```rust
// 基础参数（基于 1920x1080 屏幕）
const OFFSET_X: i32 = 20;  // 屏幕中心偏移（格子）
const OFFSET_Y: i32 = 16;
const VIEW_RANGE_X: i32 = 26;  // OFFSET_X + 6
const VIEW_RANGE_Y: i32 = 22;  // OFFSET_Y + 6

// Back 层：对齐到偶数
let start_x = ((camera.map_x - VIEW_RANGE_X).max(0) / 2) * 2;
let end_x = ((camera.map_x + VIEW_RANGE_X + 1).min(width) / 2) * 2;

// Middle/Front 层：向下多扩展5格
let end_y = (camera.map_y + VIEW_RANGE_Y + 6).min(height);
```

## 已知限制

1. **动画效果**：当前版本是静态地图查看器，不包含动画处理
2. **混合模式**：未实现 Front 层的特殊混合模式（fileIndex=14/27/28 等）
3. **门动画**：未实现门的开关动画

这些功能在 99%+ 的场景下不影响地图显示，可以在后续版本中添加。

## 调试技巧

1. **启用网格（T键）** - 查看格子对齐情况
2. **启用边框（B键）** - 查看纹理实际尺寸
3. **启用属性（F键）** - 查看地表障碍分布
4. **单独显示图层** - 用1/2/3键分别查看各层内容
