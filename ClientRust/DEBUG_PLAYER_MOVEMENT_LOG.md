# 玩家移动调试日志说明

## 日志输出格式

### 1. 帧开始 - 玩家状态总览

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎮 [玩家移动] 帧开始
  📍 当前位置: world=(1234.5, 567.8) grid=(25, 11)
  🖱️ 鼠标: screen=(640, 360) world=(1300.0, 600.0)
  🎯 移动状态: mode=DirectFollow moving=true waiting_server=false
  🎬 动画: action=Walk dir=3 frame=2
  🔽 鼠标按下: left=true (8帧) right=false (0帧)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**说明**:
- `world`: 世界坐标（像素）
- `grid`: 格子坐标（整数）
- `mode`: 移动模式（Idle/DirectFollow/AutoPathfinding）
- `moving`: 是否正在移动
- `waiting_server`: 是否等待服务器确认
- `action`: 当前动画（Stand/Walk/Run）
- `dir`: 方向（0-7）
- `frame`: 当前动画帧

### 2. 输入处理

#### 2.1 进入DirectFollow模式

```
🎯 [输入] 进入DirectFollow模式: target=(1300.0, 600.0) speed=1.8 action=Walk
```

**触发条件**: 长按鼠标左/右键 ≥ 5帧

#### 2.2 DirectFollow更新目标

```
🎯 [输入] DirectFollow更新目标: old=(1300.0, 600.0) new=(1350.0, 650.0) dist=70.7
```

**触发条件**: 鼠标移动距离 > 20像素

#### 2.3 切换走/跑速度

```
🎯 [输入] 切换速度: Walk -> Run speed=2.5
```

**触发条件**: 在DirectFollow模式下切换左/右键

#### 2.4 松开鼠标

```
🖱️ [输入] 松开鼠标 - DirectFollow模式继续移动到目标格子
```

**行为**: 不立即停止，继续移动到当前目标

### 3. DirectFollow移动逻辑

```
🚶 [DirectFollow] 开始移动
  📍 当前: (1234.5, 567.8)
  🎯 目标: (1300.0, 600.0)
  📏 距离: 70.7 (停止阈值: 3.6)
  🔄 [方向] 更新: 2 -> 3
  🔍 [碰撞] 检查下一步: world=(1236.3, 569.6) grid=(25, 11)
  ✅ [碰撞] 可行走 - 移动到: (1236.3, 569.6)
```

**说明**:
- 每帧移动`speed`像素（Walk=1.8, Run=2.5）
- 距离 < `speed * 2.0`时到达目标
- 碰撞检测：检查下一步格子是否可行走

#### 3.1 到达目标

```
  ✅ [碰撞] 目标可行走: grid=(27, 12)
  ✅ [移动] DirectFollow到达目标，停止移动
```

#### 3.2 遇到障碍

```
  ⛔ [碰撞] 遇到障碍 - 停止移动但保持动画
```

**行为**: 停止位置更新，继续播放走/跑动画（原地踏步）

### 4. 网络同步

#### 4.1 发送移动命令（AutoPathfinding）

```
🌐 [网络] 发送Walk命令: dir=DownRight grid=(25, 11)
  ⏳ [网络] 等待服务器确认: waiting_server_confirm=true
```

**说明**: 
- AutoPathfinding模式每到达一个格子发送命令
- DirectFollow模式不发送移动命令（纯客户端预测）

#### 4.2 收到服务器位置确认

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🌐 [网络] 收到服务器位置: grid=(25, 11)
  📊 位置对比:
    客户端: grid=(25, 11) world=(1234.5, 567.8)
    服务器: grid=(25, 11) world=(1224.0, 552.0)
  📏 偏差: x=0 y=0
  ✅ [同步] 清除waiting_server_confirm标志
  ✅ [同步] 位置一致: 保持客户端插值
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 4.3 DirectFollow模式跳过同步

```
  🎮 [同步] DirectFollow模式: 忽略服务器位置，使用客户端预测
```

**说明**: DirectFollow使用纯客户端预测，不被服务器位置回滚

#### 4.4 位置偏差过大强制同步

```
  ⚠️ [同步] 位置偏差较大! 强制同步: (25, 11) -> (23, 10)
  🔄 [同步] 强制更新位置: world=(1128.0, 504.0)
```

**触发条件**: 格子偏差 > 1

## 问题诊断指南

### 问题1: 长按鼠标走/跑两步就停

**查看日志**:
1. 检查是否进入DirectFollow模式
2. 检查是否有"松开鼠标"日志
3. 检查是否有"到达目标，停止移动"日志

**正常流程**:
```
🎯 [输入] 进入DirectFollow模式
🚶 [DirectFollow] 开始移动
...（多帧移动）
🖱️ [输入] 松开鼠标 - DirectFollow模式继续移动到目标格子
🚶 [DirectFollow] 开始移动
...（继续移动到目标）
✅ [移动] DirectFollow到达目标，停止移动
```

### 问题2: 玩家坐标被服务器重置

**查看日志**:
1. 检查移动模式（mode=DirectFollow?）
2. 检查是否有"强制同步"日志
3. 检查偏差值

**正常DirectFollow**:
```
🌐 [网络] 收到服务器位置: grid=(25, 11)
  🎮 [同步] DirectFollow模式: 忽略服务器位置，使用客户端预测
```

**异常情况**（不应该发生）:
```
  ⚠️ [同步] 位置偏差较大! 强制同步: (25, 11) -> (23, 10)
```

### 问题3: 方向计算错误导致方向相反

**查看日志**:
1. 检查鼠标世界坐标
2. 检查目标坐标
3. 检查方向更新

**正常流程**:
```
  🖱️ 鼠标: screen=(640, 360) world=(1300.0, 600.0)
  📍 当前: (1234.5, 567.8)
  🎯 目标: (1300.0, 600.0)
  🔄 [方向] 更新: 2 -> 3
```

**异常情况**（方向反转）:
```
  🔄 [方向] 更新: 3 -> 7  // 突然反向
```

### 问题4: 碰撞检测导致停止

**查看日志**:
```
  🔍 [碰撞] 检查下一步: world=(1236.3, 569.6) grid=(25, 11)
  ⛔ [碰撞] 遇到障碍 - 停止移动但保持动画
```

**说明**: 玩家遇到不可行走的格子，停止移动

## 日志过滤技巧

### 只看玩家移动
```powershell
cargo run 2>&1 | Select-String "玩家移动|DirectFollow|输入|移动|碰撞"
```

### 只看网络同步
```powershell
cargo run 2>&1 | Select-String "网络|同步|服务器"
```

### 只看坐标变化
```powershell
cargo run 2>&1 | Select-String "当前位置|目标|偏差"
```

## 性能影响

这些日志使用`println!`输出到控制台，会有性能影响：
- 每帧输出约10-20行日志
- 建议调试完成后注释掉或使用条件编译
- 生产环境应移除这些日志

## 移除日志的方法

```rust
// 方法1: 注释掉println!宏
// println!("🎮 [玩家移动] 帧开始");

// 方法2: 使用条件编译
#[cfg(debug_assertions)]
println!("🎮 [玩家移动] 帧开始");

// 方法3: 使用feature flag
#[cfg(feature = "debug_movement")]
println!("🎮 [玩家移动] 帧开始");
```
