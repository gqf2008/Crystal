## 技术细节 📋

### .map 文件结构

每个地图单元格 (CellInfo) 包含:
```rust
pub struct CellInfo {
    pub back_index: i32,      // MapLibs 索引 (0,1,2,100,110...)
    pub back_image: i16,      // 背景图像索引
    pub middle_index: i32,    // 中间层索引
    pub middle_image: i16,    // 中间层图像
    pub front_index: i32,     // 前景层索引
    pub front_image: i16,     // 前景图像
    pub door_index: u8,       // 门索引
    pub door_offset: u8,      // 门偏移
}
```

### 渲染流程

```
.map 文件 → CellInfo.back_index (0)
          → map_file_index_to_lib_index(0) → lib_index = 0
          → tiles_libraries[0] → Data/Map/WemadeMir2/Tiles.lib
          → load_rgba_data(back_image) → RGBA pixels
          → create_texture_from_rgba() → GPU texture
          → Canvas.draw() → 屏幕!
```

### C# 版本 (MLibrary.cs):
```csharp
// Sparse array - 400 elements, most are null
public static readonly MLibrary[] MapLibs = new MLibrary[400];

MapLibs[0] = new MLibrary(Settings.DataPath + "Map\\WemadeMir2\\Tiles");
MapLibs[1] = new MLibrary(Settings.DataPath + "Map\\WemadeMir2\\Smtiles");

MapLibs[110] = new MLibrary(Settings.DataPath + "Map\\ShandaMir2\\SmTiles");
```

### Rust 版本 (tile_texture_manager.rs):
```rust
// Dense Vec - only used indices
pub tiles_libraries: Vec<Arc<Mutex<MLibrary>>>

// Load sequentially: 0,1,2,3,4,5,6
// Map via function: 0→0, 1→1, 100→3, 110→4

fn map_file_index_to_lib_index(&self, file_index: i32) -> Option<usize> {
    match file_index {
        0 => Some(0), 1 => Some(1), 2 => Some(2),
        100 => Some(3), 110 => Some(4), 120 => Some(5), 190 => Some(6),
        _ => None
    }
}
```

**优势**: 节省内存 (7 个元素 vs 400 个元素)

**解决**: 添加到 `map_file_index_to_lib_index()`:
```rust
match file_index {

```

```rust
(200, "Data/Map/ShandaMir3/..."),
```
