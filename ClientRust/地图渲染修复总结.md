### 2. 纹理对齐到地图网格（不使用ImageInfo的offset）✅
**原因**: Bevy的Sprite原点在中心，需要正确计算Y坐标

**修改内容**:
```rust
// Bevy Sprite原点在中心，所以Y坐标 = 格子底部 + 纹理高度/2
let (grid_x, grid_y) = MapRenderData::map_to_world(x, y);
let texture_height = texture_data.height as f32;
let sprite_y = grid_y + texture_height / 2.0;

Transform::from_xyz(grid_x, sprite_y, z_value)
```

**应用到三个层**:
- Back层 (Z=0.0)
- Middle层 (Z=1.0)  
- Front层 (Z=2.0)

**同时移除offset**:
```rust
// 修改前
offset_x: texture_data.offset_x,
offset_y: texture_data.offset_y,

// 修改后
offset_x: 0,
offset_y: 0,
```

```rust
pub fn toggle_grid_system(
    keyboard: Res<ButtonInput<KeyCode>>,
    mut map_data: ResMut<MapRenderData>,
) {
    if keyboard.just_pressed(KeyCode::KeyG) {
        map_data.show_grid = !map_data.show_grid;
        if map_data.show_grid {
            info!("🟢 开启地图网格显示");
        } else {
            info!("⚫ 关闭地图网格显示");
        }
    }
}

pub fn render_grid_system(
    mut gizmos: Gizmos,
    map_data: Res<MapRenderData>,
    camera_query: Query<&Transform, With<GameCamera>>,
) {
    if !map_data.show_grid {
        return;
    }
    
    // 绘制绿色网格线（48x32格子）
    gizmos.line(start, end, Color::srgba(0.0, 1.0, 0.0, 0.5));
}
```

## 关键坐标系统说明

### Bevy vs GGEZ
```
GGEZ坐标系:
- 原点：屏幕左上角
- Y轴：向下
- Sprite原点：左上角

Bevy坐标系:
- 原点：屏幕中心
- Y轴：向上  
- Sprite原点：中心 ⚠️ 这是关键差异！
```

### 纹理定位计算
```rust
// 步骤1: 计算格子底部坐标
let (grid_x, grid_y) = MapRenderData::map_to_world(x, y);
// grid_y 是负数（因为Y向上，地图在下方）

// 步骤2: 计算Sprite中心位置
// Sprite原点在中心，所以要加上纹理高度的一半
let texture_height = texture_data.height as f32;
let sprite_center_y = grid_y + texture_height / 2.0;

// 步骤3: 创建Transform
Transform::from_xyz(grid_x, sprite_center_y, z_value)
```

### Z层级
```
Z=0.0  → Back层（地面）
Z=1.0  → Middle层（建筑底部、树木底部）
Z=1.5  → 玩家和角色
Z=2.0  → Front层（建筑顶部、树冠）
Z=0.5  → 网格线（调试用）
```

## 下一步优化

1. 如果纹理仍然错位，可能需要考虑：
   - 检查`map_to_world`函数的正确性
   - 验证纹理尺寸是否正确读取
   - 确认地图数据本身是否正确

2. 如果需要真正的ADD混合：
   - 需要使用自定义材质和shader
   - Bevy 0.17的材质系统比较复杂

3. 性能优化：
   - 网格线目前每帧绘制，可以优化为只在摄像机移动时更新
   - Back层缓存可以进一步优化
