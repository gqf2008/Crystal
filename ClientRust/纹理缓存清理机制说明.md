# 纹理缓存清理机制说明

## 📋 概述

本文档说明 MIR2 游戏中纹理缓存的清理机制，对比 C# 原版和 Rust 移植版的实现。

## 🎮 C# 原版实现

### 1. 清理时机

**主循环调用:**
```csharp
// CMain.cs - UpdateEnviroment()
private static void UpdateEnviroment()
{
    if (Time >= _cleanTime)
    {
        _cleanTime = Time + 1000;  // 每秒检查一次
        DXManager.Clean();         // 清理纹理缓存
    }
    // ... 其他更新逻辑
}
```

**调用频率**: 每秒检查一次 (每 1000ms)

### 2. 清理策略

**DXManager.cs - Clean() 方法:**
```csharp
public static void Clean()
{
    // 遍历所有纹理
    for (int i = TextureList.Count - 1; i >= 0; i--)
    {
        MImage m = TextureList[i];
        
        if (m == null)
        {
            TextureList.RemoveAt(i);
            continue;
        }
        
        // ⏰ 检查是否超过清理延迟
        if (CMain.Time <= m.CleanTime) continue;
        
        // 🗑️ 释放纹理
        m.DisposeTexture();
    }
    
    // 同样清理控件纹理
    for (int i = ControlList.Count - 1; i >= 0; i--)
    {
        MirControl c = ControlList[i];
        if (c == null)
        {
            ControlList.RemoveAt(i);
            continue;
        }
        if (CMain.Time <= c.CleanTime) continue;
        c.DisposeTexture();
    }
}
```

## 🦀 Rust 移植版实现

### 1. 清理时机

**GameScene.rs - update() 方法:**
```rust
fn update(&mut self, _delta_time: f32) {
    // 定期清理纹理缓存 (每 5 秒检查一次,清理超过 30 秒未使用的纹理)
    static mut LAST_CLEANUP_TIME: Option<std::time::Instant> = None;
    unsafe {
        let now = std::time::Instant::now();
        if LAST_CLEANUP_TIME.is_none() 
            || now.duration_since(LAST_CLEANUP_TIME.unwrap()) > std::time::Duration::from_secs(5) 
        {
            self.cleanup_texture_cache();
            LAST_CLEANUP_TIME = Some(now);
        }
    }
    // TODO: 其他更新逻辑
}
```

**调用频率**: 每 5 秒检查一次

### 2. 清理策略

**GameScene.rs - cleanup_texture_cache():**
```rust
fn cleanup_texture_cache(&mut self) {
    use crate::graphics::get_all_map_libraries;
    use std::time::Duration;
    
    // 清理超过 30 秒未使用的纹理
    // (C# 使用 CleanDelay = 600000ms = 10分钟)
    // Rust 使用更激进的清理策略以节省内存
    let max_age = Duration::from_secs(30);
    
    let libs = get_all_map_libraries();
    let mut total_cleaned = 0;
    
    for (idx, lib) in libs.iter().enumerate() {
        if let Ok(mut library) = lib.lock() {
            let (before, _) = library.get_cache_stats();
            library.cleanup_old_textures(max_age);
            let (after, _) = library.get_cache_stats();
            
            let cleaned = before.saturating_sub(after);
            if cleaned > 0 {
                total_cleaned += cleaned;
                tracing::debug!("🧹 MapLib[{}]: cleaned {} textures ({} → {})", 
                    idx, cleaned, before, after);
            }
        }
    }
    
    if total_cleaned > 0 {
        tracing::info!("🧹 Texture cache cleanup: removed {} old textures", total_cleaned);
    }
}
```

### 3. MLibrary 实现

**mlibrary.rs - cleanup_old_textures():**
```rust
pub fn cleanup_old_textures(&mut self, max_age: std::time::Duration) {
    use std::time::Instant;
    let now = Instant::now();
    let mut removed = 0;
    
    self.cached_info.iter_mut().for_each(|image| {
        if let Some(access_time) = image.last_access_time {
            let age = now.duration_since(access_time);
            if age > max_age {
                image.image = None;              // 释放主纹理
                image.mask_image = None;         // 释放遮罩纹理
                image.last_access_time = None;   // 清除访问时间
                removed += 1;
            }
        }
    });

    if removed > 0 {
        tracing::info!("🧹 Cleaned {} old textures from cache", removed);
    }
}
```

## 📊 C# vs Rust 对比

| 方面 | C# 原版 | Rust 移植版 | 差异分析 |
|------|---------|------------|---------|
| **检查频率** | 每 1 秒 | 每 5 秒 | Rust 更宽松 |
| **清理延迟** | 10 分钟 | 30 秒 | ⚠️ **Rust 更激进** |
| **时间类型** | `long` (毫秒) | `Instant` + `Duration` | Rust 更精确 |
| **访问时间** | 每次 Draw 更新 | 只在 get_or_create_texture 更新 | 相同效果 |
| **清理范围** | 全局 TextureList | 每个 MLibrary 独立 | Rust 更细粒度 |
| **内存策略** | 宽松保留 | 激进清理 | Rust 优先节省内存 |

### ⚠️ 关键差异

**C# 策略（宽松）:**
- 10 分钟不用才清理
- 适合内存充足的环境
- 减少重新加载开销

**Rust 策略（激进）:**
- 30 秒不用就清理
- 优先节省内存
- 可能增加重新加载频率

### 问题1: Rust 清理太激进

**症状:**
- 频繁的纹理重新加载
- FPS 下降 (解压开销)
- 日志中大量 "🧹 Cleaned X textures"

**解决方案:**

```rust
// GameScene.rs

    // 选项1: 延长清理延迟 (更接近 C#)
    let max_age = Duration::from_secs(300);  // 5 分钟

    // 选项2: 降低检查频率
    // 在 update() 中改为:
    // Duration::from_secs(30)  // 30秒检查一次
    
    // 选项3: 使用 C# 的 10 分钟
    let max_age = Duration::from_secs(600);
}
```

### 问题2: 内存占用过高

**症状:**
- 内存使用持续增长
- 系统变慢
- 缓存统计显示大量纹理

**解决方案:**

```rust
impl MLibrary {
    /// 强制清理,无视访问时间
    pub fn force_cleanup(&mut self) {
        self.cached_info.iter_mut().for_each(|image| {
            image.image = None;
            image.mask_image = None;
            image.last_access_time = None;
        });
    }
    
    /// 限制缓存大小
    pub fn enforce_cache_limit(&mut self, max_cached: usize) {
        let mut entries: Vec<_> = self.cached_info.iter_mut()
            .filter(|info| info.texture_valid)
            .collect();
        
        if entries.len() <= max_cached {
            return;
        }
        
        // 按访问时间排序,清理最老的
        entries.sort_by_key(|info| info.last_access_time);
        let to_remove = entries.len() - max_cached;
        
        for entry in entries.iter_mut().take(to_remove) {
            entry.image = None;
            entry.mask_image = None;
            entry.last_access_time = None;
        }
    }
}
```

### 问题3: 需要调试信息

**添加监控:**

```rust
impl MLibrary {
    /// 获取详细缓存统计
    pub fn get_detailed_stats(&self) -> CacheStats {
        let total = self.cached_info.len();
        let loaded = self.cached_info.iter()
            .filter(|info| info.texture_valid)
            .count();
        let total_memory: usize = self.cached_info.iter()
            .filter_map(|info| info.rgba_data.as_ref().map(|v| v.len()))
            .sum();
        
        CacheStats {
            total_entries: total,
            loaded_textures: loaded,
            total_memory_bytes: total_memory,
        }
    }
}

pub struct CacheStats {
    pub total_entries: usize,
    pub loaded_textures: usize,
    pub total_memory_bytes: usize,
}
```

## 📚 总结

### 当前状态

✅ **已实现功能:**
- ✅ 定期清理机制 (每 5 秒)
- ✅ 基于访问时间的清理
- ✅ 自动更新访问时间
- ✅ 统计信息支持

⚠️ **与 C# 差异:**
- ⚠️ 清理延迟: 30秒 vs 10分钟
- ⚠️ 检查频率: 5秒 vs 1秒
- ⚠️ 清理策略: 更激进

**平衡模式 (推荐):**

```rust
// 检查频率: 3 秒
```
