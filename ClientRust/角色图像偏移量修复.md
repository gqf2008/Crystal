# 🔧 角色图像偏移量修复

**问题**: 角色图像显示位置偏右下方

**原因**: 
MLibrary中的图像包含偏移量信息（`x`, `y`），用于精确定位图像。
C#代码中使用了 `UseOffSet = true`，但Rust版本没有应用这些偏移量。

## 📐 技术背景

### MLibrary图像结构
```rust
pub struct ImageInfo {
    pub width: i16,
    pub height: i16,
    pub x: i16,      // 偏移量X - 用于精确定位
    pub y: i16,      // 偏移量Y - 用于精确定位
    pub shadow_x: i16,
    pub shadow_y: i16,
    pub shadow: u8,
    pub length: i32,
    pub has_mask: bool,
}
```

### C#原始代码
```csharp
CharacterDisplay = new MirAnimatedControl
{
    Animated = true,
    AnimationCount = 16,
    AnimationDelay = 250,
    Index = 20,
    Library = Libraries.ChrSel,
    Location = new Point(260, 420),
    Parent = this,
    UseOffSet = true,  // ⚠️ 关键：使用偏移量
};
```

## ✅ 修复内容

### 1. SelectScene 角色预览
**位置**: `src/scenes/select_scene.rs` (第609-629行)

```rust
// 修复前 ❌
if let Some(texture) = ggez_manager.get_texture(&anim_key) {
    canvas.draw(texture, DrawParam::default().dest([preview_x, preview_y]));
}

// 修复后 ✅
// 获取纹理偏移量（从MLibrary）
use crate::graphics::libraries::{get_library, LibraryName};
let (offset_x, offset_y) = if let Some(lib_arc) = get_library(LibraryName::ChrSel) {
    let mut lib = lib_arc.lock().unwrap();
    if let Ok(info) = lib.get_image_info(anim_index as usize) {
        (info.x as f32, info.y as f32)
    } else {
        (0.0, 0.0)
    }
} else {
    (0.0, 0.0)
};

if let Some(texture) = ggez_manager.get_texture(&anim_key) {
    // 应用偏移量（C# UseOffSet = true）
    canvas.draw(texture, DrawParam::default().dest([preview_x + offset_x, preview_y + offset_y]));
}
```

## 🎯 偏移量的作用

### 为什么需要偏移量？

1. **精确定位**: 角色动画帧可能不是完全居中的
2. **动画连贯性**: 不同帧需要对齐以避免"抖动"
3. **视觉平衡**: 角色的"锚点"可能不在图像中心

### 示例
```
不使用偏移量 ❌:
┌─────────────┐
│   图像      │  → 直接绘制在(260, 420)
│             │     视觉上偏移
└─────────────┘

使用偏移量 ✅:
┌─────────────┐
│   图像      │  → 绘制在(260 + offset_x, 420 + offset_y)
│             │     视觉上居中对齐
└─────────────┘
```

## 🔍 偏移量数据示例

典型的ChrSel图像偏移量（战士男性站立动画）:
```
Frame 0 (ChrSel_20): offset_x = -40, offset_y = -80
Frame 1 (ChrSel_21): offset_x = -38, offset_y = -82
Frame 2 (ChrSel_22): offset_x = -41, offset_y = -79
...
```

每帧的偏移量略有不同，确保动画流畅。

## 🎮 受益的场景

此修复影响以下两个位置的角色预览：

1. **SelectScene**: 选择角色界面的角色预览
   - 位置: (260, 420)
   - 动画: 16帧循环
   
2. **NewCharacterDialog**: 创建角色对话框的角色预览
   - 位置: (dialog.x + 120, dialog.y + 250)
   - 动画: 16帧循环
   - 包括法师混合效果

## 📊 性能影响

**开销**: 极小
- 每帧只需查询一次偏移量
- 偏移量数据从MLibrary缓存中读取
- 不影响帧率

**优化**: 
- 偏移量查询在渲染时进行
- 使用已有的MLibrary锁
- 无额外内存开销
