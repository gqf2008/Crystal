## 🎯 实现功能概述

### 1. 网络系统集成 ✅

- **NetworkManager**: 已集成到主程序,自动启动Tokio异步任务
- **GameClient**: 与SceneManager连接,支持事件传递
- **Command Channel**: UI线程与网络线程双向通信

### 2. 登录流程 ✅

#### 2.1 连接服务器
- 启动游戏后自动连接到服务器 (`server_host:server_port`)
- 连接成功后发送 `GameEvent::Connected` 事件
- 连接失败自动重试(由NetworkManager处理)

#### 2.2 客户端版本验证
- 收到`Connected`事件后计算客户端MD5哈希
- **临时方案**: 跳过版本验证,直接启用登录对话框
- **未来**: 通过NetworkManager发送ClientVersion包

#### 2.3 提交登录
- 用户输入账号密码,点击登录按钮
- 验证格式 → 发送`NetworkCommand::Login` → NetworkManager处理 → 服务器响应
- 支持的响应:
  - `LoginResponse` (失败): 显示错误消息
  - `LoginBanned`: 显示封禁信息
  - `LoginSuccess`: 记录角色列表,准备进入SelectScene

## 🔧 技术细节

### 数据包流程

```
UI Thread (ggez)                    Network Thread (Tokio)
    |                                        |
    |  NetworkCommand::Login                 |
    | --------------------------------------> |
    |                                        |
    |                               serialize & send
    |                                        | -----> Server
    |                                        |
    |                                   receive response
    |                                        | <----- Server
    |                                        |
    |  GameEvent::LoginResponse              |
    | <-------------------------------------- |
    |                                        |
   Scene.process_event()                    |
```

### 线程安全

- **GameClient**: `Arc<tokio::sync::RwLock<GameClient>>`
- **Command Channel**: `tokio::sync::mpsc::UnboundedSender/Receiver`
- **Event Channel**: `tokio::sync::mpsc::UnboundedSender/Receiver`

### 依赖添加

```toml
[dependencies]
md5 = "0.8.0"  # 用于计算客户端版本哈希
```

## 🎓 架构说明

### 为什么使用Command/Event模式?

1. **线程分离**: UI(ggez)在主线程,网络(Tokio)在异步线程
2. **解耦合**: Scene不直接访问网络层,只发送命令
3. **异步支持**: NetworkManager可以await网络I/O
4. **事件驱动**: 网络事件异步到达,通过channel通知UI

### NetworkCommand vs 直接调用

| NetworkCommand (当前)            | 直接调用                   |
|---------------------------------|--------------------------|
| ✅ 线程安全                       | ❌ 需要手动加锁             |
| ✅ 支持异步操作                   | ❌ 会阻塞UI线程             |
| ✅ 队列化处理                     | ❌ 立即执行(可能失败)        |
| ❌ 需要枚举所有命令类型            | ✅ 直接调用方法             |
