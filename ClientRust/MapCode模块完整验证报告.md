### 2. 压缩存储 (Type 5)

**测试文件**: 5 个 Type 5 地图 (HF1.map 等)

**压缩逻辑**:
```rust
// 2x2 格子共享 BackTile，每 3 字节存储 4 个格子
for x in 0..(width / 2) {
    for y in 0..(height / 2) {
        let back_index = bytes[offset];
        let back_image = u16::from_le_bytes([bytes[offset+1], bytes[offset+2]]);
        
        // 分配给 4 个格子
        for i in 0..4 {
            map_cells[cell_x][cell_y].back_index = back_index;
            map_cells[cell_x][cell_y].back_image = back_image;
        }
        offset += 3;
    }
}
```

**验证结果**: ✅ 所有 5 个文件正确解压
