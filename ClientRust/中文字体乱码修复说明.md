# 中文字体乱码修复说明

**问题**: GameScene 加载屏幕中文显示为乱码 (方框或问号)
**原因**: `draw_loading_screen()` 方法未设置中文字体
**修复时间**: 2024年

---

## 一、问题根源

### 1.1 ggez 默认字体不支持中文

ggez 使用的默认字体 (DejaVuSans) 不包含中文字符,导致:
- 中文字符显示为 `□` (空白方框)
- 或者显示为 `?` (问号)
- 或者完全不显示

### 1.2 已有的中文字体支持

项目中已经实现了中文字体支持:

**字体文件**:
- 位置: `ClientRust/resources/font/AlibabaPuHuiTi-3-55-Regular.ttf`
- 字体名称: "AlibabaPuHuiTi" (阿里巴巴普惠体)

**加载位置**: `src/bin/main_ggez.rs` (Line 65-81)
```rust
let font_path = std::path::Path::new("resources/font/AlibabaPuHuiTi-3-55-Regular.ttf");
if font_path.exists() {
    match std::fs::read(font_path) {
        Ok(font_bytes) => {
            ctx.gfx.add_font("AlibabaPuHuiTi", FontData::from_vec(font_bytes)?);
            tracing::info!("✓ 中文字体加载成功: AlibabaPuHuiTi");
        }
        Err(e) => {
            tracing::warn!("⚠ 中文字体加载失败: {}", e);
        }
    }
}
```

**已使用字体的地方**:
- LoginScene - 登录界面输入框和提示文字
- SelectScene - 选择角色界面所有文本
- ⚠️ **GameScene - 漏掉了!**

---

## 二、修复方案

### 修复: GameScene 加载屏幕设置字体

**文件**: `src/scenes/game_scene.rs` (Line ~1147)

**原代码** (Line 1147-1149):
```rust
// ❌ 错误: 未设置字体,使用默认字体,中文乱码
let mut text = ggez::graphics::Text::new(message);
text.set_scale(PxScale::from(32.0));
```

**修复后代码**:
```rust
// ✅ 正确: 设置中文字体
let mut text = ggez::graphics::Text::new(message);
text.set_font("AlibabaPuHuiTi");  // 🔧 关键修复: 设置中文字体!
text.set_scale(PxScale::from(32.0));
```

**效果**:
- "等待服务器数据..." ✅ 正常显示
- "正在加载地图: 0.map" ✅ 正常显示
- "等待角色数据..." ✅ 正常显示

## 四、常见问题

### Q1: 仍然显示乱码怎么办?

**可能原因 A: 字体文件不存在**

检查文件是否存在:
```powershell
Test-Path "d:\Users\gxh\Documents\GitHub\Crystal\ClientRust\resources\font\AlibabaPuHuiTi-3-55-Regular.ttf"
```

如果返回 `False`,需要下载字体文件。

**可能原因 B: 字体加载失败**

查看启动日志:
```
[WARN] ⚠ 字体文件不存在: "resources/font/AlibabaPuHuiTi-3-55-Regular.ttf"
```
或
```
[WARN] ⚠ 中文字体加载失败: ...
```

解决方法: 检查文件路径和权限。

**可能原因 C: 旧版本未重新编译**

确保执行了 `cargo build` 并且看到 `Compiling mir2_client`。

如果只看到 `Finished` 没有 `Compiling`,说明代码没有变化,可能是:
- 文件保存失败
- 修改了错误的文件

强制重新编译:
```powershell
cargo clean
cargo build --bin mir2_client
```

---

### Q2: 字体显示但太小/太大?

调整字体大小:

**文件**: `src/scenes/game_scene.rs` (Line ~1149)
```rust
text.set_scale(PxScale::from(32.0));  // 调整这个数字
```

- 更大: `48.0` (48px)
- 中等: `32.0` (32px) - 当前设置
- 更小: `24.0` (24px)

---

### Q3: 字体颜色看不清?

调整字体颜色:

**文件**: `src/scenes/game_scene.rs` (Line ~1159)
```rust
.color(Color::WHITE),  // 白色
```

可选颜色:
- `Color::WHITE` - 白色 (推荐用于黑色背景)
- `Color::from_rgb(255, 255, 0)` - 黄色
- `Color::from_rgb(0, 255, 255)` - 青色
- `Color::from_rgb(255, 200, 0)` - 橙色

## 五、其他场景的字体设置

如果发现其他地方也有中文乱码,参考以下修复模板:

### 模板 1: Text::new() 创建文本

```rust
// ❌ 错误
let text = ggez::graphics::Text::new("中文文本");

// ✅ 正确
let mut text = ggez::graphics::Text::new("中文文本");
text.set_font("AlibabaPuHuiTi");  // 设置中文字体
```

### 模板 2: TextFragment 创建文本

```rust
// ❌ 错误
let fragment = ggez::graphics::TextFragment::new("中文文本");

// ✅ 正确
let fragment = ggez::graphics::TextFragment::new("中文文本")
    .font("AlibabaPuHuiTi");  // 链式调用设置字体
```

### 模板 3: Text::new() 后追加内容

```rust
let mut text = ggez::graphics::Text::new("标题");
text.set_font("AlibabaPuHuiTi");  // 为整个 Text 设置字体

// 追加的内容会继承字体
text.add("\n这是第二行");
```

## 六、字体文件说明

### 当前使用的字体

**名称**: 阿里巴巴普惠体 3.0 (Alibaba PuHuiTi 3.0)
**版本**: 55-Regular (常规体重)
**文件大小**: 约 6-8 MB
**字符集**: 包含 GB18030 中文字符集
**授权**: 免费商用

### 为什么选择这个字体?

1. **开源免费**: 阿里巴巴开源,可免费商用
2. **字符完整**: 包含所有常用中文字符
3. **显示清晰**: 屏幕显示效果好,适合游戏界面
4. **文件不大**: 相比宋体、黑体等系统字体,文件较小

### 如果字体文件丢失

**方案 A: 从阿里巴巴官网下载**

访问: https://www.alibabafonts.com/#/font
下载 "阿里巴巴普惠体 3.0"

**方案 B: 使用系统字体 (Windows)**

修改 `main_ggez.rs`:
```rust
// 使用 Windows 自带的微软雅黑
let font_path = std::path::Path::new("C:/Windows/Fonts/msyh.ttc");
if font_path.exists() {
    // ... 加载代码
    ctx.gfx.add_font("微软雅黑", FontData::from_path(font_path)?);
}
```

然后修改所有 `.set_font("AlibabaPuHuiTi")` 为 `.set_font("微软雅黑")`。

**注意**: 系统字体需要正确的授权才能用于商业发布。
