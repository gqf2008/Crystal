## 📝 故障排除

### 如果游戏窗口未出现

1. **检查进程**
   ```powershell
   Get-Process | grep mir
   ```

2. **查看图形驱动**
   - 确保显卡驱动已正确安装
   - Bevy 使用 WGPU，需要图形支持

3. **尝试 Release 版本**
   ```powershell
   cargo run --release --bin mir2_bevy
   ```

### 如果游戏加载缓慢

- 这是 Debug 模式的特性
- Release 版本会快得多
- 可能需要等待 2-5 秒

### 如果遇到错误

检查错误信息，但由于是 GUI 应用，错误可能不显示在终端。
