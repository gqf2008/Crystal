## 对照原版C#代码

### 按钮布局公式

```csharp
// C# SelectScene.cs
int xPoint = 1024 / 5;  // 约204.8
Location = new Point(
    100 + (xPoint * n) - (xPoint / 2) - 50,  // X坐标
    Settings.ScreenHeight - 32               // Y坐标 (768-32=736)
);

n = 1: StartGameButton    → X = 100 + 204.8*1 - 102.4 - 50 ≈ 152
n = 2: NewCharacterButton → X = 100 + 204.8*2 - 102.4 - 50 ≈ 357
n = 3: DeleteButton       → X = 100 + 204.8*3 - 102.4 - 50 ≈ 562
n = 4: CreditsButton      → X = 100 + 204.8*4 - 102.4 - 50 ≈ 767
n = 5: ExitButton         → X = 100 + 204.8*5 - 102.4 - 50 ≈ 972
```

```rust
// 检查点击是否在矩形区域内
if x >= rect_x as i32 && x <= (rect_x + rect_width) as i32 &&
   y >= rect_y as i32 && y <= (rect_y + rect_height) as i32 {
    // 点击命中
}
```

### 选中状态管理

```rust
// 点击角色槽位时
self.selected_index = i as i32;
tracing::info!("Selected character {}: {}", i, self.characters[i].name);

// 绘制时根据选中状态选择纹理
```
