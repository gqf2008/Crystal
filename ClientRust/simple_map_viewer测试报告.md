### 🔍 关于"视觉变化不明显"的原因

#### 原因 1: 地图尺寸巨大
- 地图总尺寸: **33600 x 22400 像素** (700x700 格子)
- 屏幕可见区域: 约 **1024 x 768 像素** (27x29 格子)
- 单次移动距离: **500 像素** (约 10 格子)

相对于地图总尺寸,单次移动只占 1.5%,如果该区域纹理相似,视觉变化可能不明显。

#### 原因 2: 渲染的是同质化区域
如果测试的地图区域(格子 337-462 之间)纹理比较统一(如大片草地、沙漠等),视觉上确实难以察觉移动。

#### 原因 3: 缩放功能未测试
从日志看,用户主要测试了方向键,但**没有按 +/- 进行缩放测试**。缩放是最明显的视觉变化。

### 🎮 建议测试步骤

1. **测试缩放**:
   - 按 `+` 或 `=` 键放大(zoom 会增加到 1.1x, 1.21x, 1.33x...)
   - 按 `-` 键缩小(zoom 会减小到 0.9x, 0.81x...)
   - 观察地图瓦片尺寸变化

2. **测试边界**:
   - 按住方向键移动到地图边缘
   - 观察是否正确裁剪在边界处

3. **测试组合操作**:
   - 先放大到 2x (`zoom: 2.00`)
   - 再移动摄像机
   - 此时移动视觉变化会更明显

### 🛠️ 技术细节

#### Camera 坐标变换
```rust
// 世界坐标 → 屏幕坐标
screen_x = (world_x - camera.x) * zoom + screen_width / 2
screen_y = (world_y - camera.y) * zoom + screen_height / 2

// 屏幕坐标 → 世界坐标
world_x = camera.x + (screen_x - screen_width / 2) / zoom
world_y = camera.y + (screen_y - screen_height / 2) / zoom
```

#### 可见区域计算
```rust
let left = camera.screen_to_world_x(0.0);           // 左边界世界坐标
let right = camera.screen_to_world_x(screen_width); // 右边界世界坐标
let top = camera.screen_to_world_y(0.0);            // 上边界世界坐标
let bottom = camera.screen_to_world_y(screen_height); // 下边界世界坐标

// 转换为格子索引(带2格边距)
start_x = (left / 48).floor() - 2
end_x = (right / 48).ceil() + 2
start_y = (top / 32).floor() - 2
end_y = (bottom / 32).ceil() + 2
```
