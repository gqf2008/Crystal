## 根本原因分析

### 问题 1: 双摄像机冲突 ⚠️
**位置**: `src/bin/main_bevy.rs`

```rust
// setup() - 启动时创建
fn setup(mut commands: Commands, mut next_state: ResMut<NextState<GameState>>) {
    commands.spawn(Camera2d::default());  // ← 摄像机 1
}

// setup_game_rendering() - 游戏场景创建
pub fn setup_game_rendering(mut commands: Commands) {
    commands.spawn((
        Camera2d::default(),  // ← 摄像机 2
        GameCamera::new(),
    ));
}
```

**结果**: 
- 两个摄像机同时渲染
- 渲染顺序不确定
- 可能导致渲染失败

---

## 修复方案

### 修复 1: 移除启动摄像机 ✅

**修改**: `src/bin/main_bevy.rs`

```rust
// 修改前
fn setup(mut commands: Commands, mut next_state: ResMut<NextState<GameState>>) {
    commands.spawn(Camera2d::default());  // ← 删除这行
    next_state.set(GameState::Login);
}

// 修改后
fn setup(mut commands: Commands, mut next_state: ResMut<NextState<GameState>>) {
    // 不创建摄像机，让各个场景自己创建
    next_state.set(GameState::Login);
}
```

**原因**: 
- Login/Select 场景有自己的摄像机
- Game 场景也有自己的摄像机
- 不需要全局摄像机

---

### 修复 2: 注册 render_map_system 到 Update ✅

**修改**: `src/bin/main_bevy.rs`

```rust
// 在 Update 系统中添加
app.add_systems(Update, (
    // ... 现有系统
    render_map_system,      // ← 新增：地图渲染
    update_animation_system, // ← 新增：动画更新

```
