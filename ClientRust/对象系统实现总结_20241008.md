- 跟踪帧索引(frame_index)和帧时间

**MapObject集成**:
```rust

```

**AnimationStep返回值**:
- `frames_advanced`: 推进了多少帧
- `completed_cycles`: 完成了多少个循环

**使用示例**:

## 📝 集成指南

### 在GameScene中使用对象系统

```rust
impl GameScene {
    fn update(&mut self, delta_time: f32) {
        // 1. 更新所有对象的移动
        for monster in &mut self.monsters {
            monster.map_object.update_movement(delta_time);
            monster.map_object.update_draw_location();
        }
        
        // 2. 更新动画
        let delta_ms = (delta_time * 1000.0) as u32;
        for monster in &mut self.monsters {
            monster.map_object.advance(delta_ms);
        }
    }
    
    fn draw(&mut self, ctx: &mut Context, canvas: &mut Canvas) -> GameResult {
        // 绘制所有对象
        for monster in &self.monsters {
            let draw_pos = monster.map_object.draw_location;
            monster.draw(ctx, canvas, draw_pos)?;
        }
        Ok(())
    }
    
    fn spawn_monster(&mut self, packet: ObjectMonster) {
        let monster = ObjectFactory::create_monster(&packet);
        self.monsters.push(monster);
    }
}
```
