## 📋 功能清单

### ✅ 已实现

#### 1. **鼠标输入系统** (src/bevy/systems/input.rs)
```rust
pub fn mouse_input_system(
    mouse_button: Res<ButtonInput<MouseButton>>,
    camera_query: Query<(&Camera, &GlobalTransform)>,
    windows: Query<&Window>,
    mut player_query: Query<(&GridPosition, &mut Movement), With<Player>>,
)
```

**功能**:
- ✅ 左键点击 = 走路（Walk）
- ✅ 右键点击 = 跑步（Run）
- ✅ 屏幕坐标转世界坐标
- ✅ 世界坐标转网格坐标（48×32 格子）
- ✅ 计算点击位置的相对方向

**支持的方向** (8向):
- Up（向上）
- Down（向下）
- Left（向左）
- Right（向右）
- UpLeft（左上）
- UpRight（右上）
- DownLeft（左下）
- DownRight（右下）

#### 2. **方向计算函数**
```rust
fn calculate_direction(source_x: i32, source_y: i32, dest_x: i32, dest_y: i32) -> MirDirection
```

**逻辑**:
1. 比较源点和目标点的 X 坐标差异
2. 比较源点和目标点的 Y 坐标差异
3. 返回对应的 8 向方向

#### 3. **系统注册**
在 `src/bin/main_bevy.rs` 中已注册:

```rust
// GameState::Game 时运行
app.add_systems(Update, (
    mouse_input_system,  // ← 鼠标输入
    ...
).run_if(in_state(GameState::Game)));
```

## 🎯 工作流程

```
玩家操作 (鼠标点击)
    ↓
window.cursor_position()  [获取鼠标屏幕位置]
    ↓
camera.viewport_to_world_2d()  [转换为世界坐标]
    ↓
world_pos / CELL_SIZE  [转换为网格坐标]
    ↓
calculate_direction()  [计算 8 向方向]
    ↓
movement.direction = direction  [更新移动方向]
movement.set_running(is_running)  [设置移动速度]
    ↓
其他系统使用 Movement 更新位置
    ↓
角色跟随鼠标方向移动 ✨
```

## 📊 坐标系统

### 屏幕坐标 → 世界坐标 → 网格坐标

```
屏幕空间 (Screen)
  │
  ├─ cursor_position (像素)
  │
  └─ camera.viewport_to_world_2d()
        ↓
    世界空间 (World)
      │
      ├─ world_pos (浮点数)
      │
      └─ / CELL_SIZE (48×32)
            ↓
        网格空间 (Grid)
          │
          └─ (grid_x, grid_y) 整数坐标
```

```rust
const CELL_WIDTH: f32 = 48.0;   // 格子宽度

```

这对应游戏的等距视图（Isometric）格子大小
