# mir2_shared

Rust 移植版的 `Shared` 组件，承载客户端与服务器之间的通用数据结构、枚举与协议序列化逻辑。当前处于早期阶段，仅包含基础的职业、属性枚举以及与基础属性相关的数据模型。

## 目标

- 逐步对照 C# `Shared` 项目的结构迁移关键枚举与数据模型。
- 提供稳定、序列化兼容的封包定义与读写工具，供 Rust 客户端与服务器复用。
- 为后续迁移提供测试夹具和示例。

## 结构

- `enums`：迁移后的基础枚举类型，例如职业、性别、属性、聊天类型等。
- `stats`：属性面板相关的数据模型与算法实现。
- `packet`：预留的封包读写接口，后续将扩展。
- `packet_ids`：客户端/服务器封包编号，确保与原始协议兼容。

## 运行

```powershell
cd SharedRust
cargo check
```
