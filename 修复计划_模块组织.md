# 模块组织修复计划

## 🎯 修复目标

将模块组织完全对齐到 C# 原工程结构：
- LoginScene 的内嵌对话框 → login_scene 子模块
- 独立对话框 → dialogs/ 目录
- 正确的导入关系

## 📋 具体修复步骤

### 步骤 1: 移动 LoginDialog

```bash
# 从 dialogs/login_dialog/ 移动到 login_scene/
源: ClientRust/src/scenes/dialogs/login_dialog/mod.rs
目标: ClientRust/src/scenes/login_scene/login_dialog.rs
```

**理由**: C# 中 LoginDialog 是 LoginScene 的内嵌类（Line 323）

### 步骤 2: 移动 NewAccountDialog

```bash
# 从 dialogs/new_account_dialog/ 移动到 login_scene/
源: ClientRust/src/scenes/dialogs/new_account_dialog/mod.rs
目标: ClientRust/src/scenes/login_scene/new_account_dialog.rs
```

**理由**: C# 中 NewAccountDialog 是 LoginScene 的内嵌类（Line 746）

### 步骤 3: 移动并重命名 NewCharacterDialog

```bash
# 从 select_scene/ 移动到 dialogs/new_character_dialog/
源: ClientRust/src/scenes/select_scene/character_creation_dialog.rs
目标: ClientRust/src/scenes/dialogs/new_character_dialog/mod.rs
重命名: CharacterCreationDialog → NewCharacterDialog
```

**理由**: C# 中 NewCharacterDialog 是独立文件 Dialogs/NewCharacterDialog.cs

### 步骤 4: 更新 login_scene.rs

```rust
// 修改前:
use super::dialogs::{LoginDialog, NewAccountDialog};

pub mod change_password_dialog;
pub use change_password_dialog::{ChangePasswordDialog, ChangePasswordResult};

// 修改后:
pub mod login_dialog;
pub mod new_account_dialog;
pub mod change_password_dialog;

pub use login_dialog::LoginDialog;
pub use new_account_dialog::{NewAccountDialog, NewAccountResult, AccountRegistration};
pub use change_password_dialog::{ChangePasswordDialog, ChangePasswordResult};
```

### 步骤 5: 更新 select_scene.rs

```rust
// 修改前:
pub mod character_creation_dialog;
pub use character_creation_dialog::CharacterCreationDialog;

// 修改后:
use super::dialogs::NewCharacterDialog;

// 修改字段名:
pub character_creation_dialog: Option<CharacterCreationDialog>,
// 改为:
pub new_character_dialog: Option<NewCharacterDialog>,
```

### 步骤 6: 更新 dialogs/mod.rs

```rust
// 删除:
pub mod login_dialog;
pub mod new_account_dialog;

// 添加:
pub mod new_character_dialog;

// 删除导出:
pub use login_dialog::LoginDialog;
pub use new_account_dialog::{NewAccountDialog, NewAccountResult, AccountRegistration};

// 添加导出:
pub use new_character_dialog::{NewCharacterDialog, NewCharacterResult};
```

### 步骤 7: 删除空目录

```bash
Remove-Item dialogs/login_dialog/
Remove-Item dialogs/new_account_dialog/
```
