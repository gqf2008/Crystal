# LibraryName 便捷方法快速参考

## 概述

`LibraryName` 现在提供了便捷的链式调用方法，让代码更简洁、更易读。

## 核心便捷方法

### 1. 获取纹理

```rust
// ✅ 新方式 - 链式调用
let info = LibraryName::Prguse.get_texture(100)?;

// ❌ 旧方式 - 函数调用
let info = resources::get_texture(LibraryName::Prguse, 100)?;
```

### 2. 获取 egui 纹理

```rust
// ✅ 新方式
let handle = LibraryName::ChrSel.get_egui_texture(ctx, 0)?;

// ❌ 旧方式
let handle = resources::get_egui_texture(ctx, LibraryName::ChrSel, 0)?;
```

### 3. 获取尺寸

```rust
// ✅ 新方式 - 更直观
let (w, h) = LibraryName::Items.get_size(200)?;

// ❌ 旧方式
let (w, h) = resources::get_size(LibraryName::Items, 200)?;
```

### 4. 获取库引用

```rust
// ✅ 新方式
let lib = LibraryName::Magic.get_library()?;

// ❌ 旧方式
let lib = resources::get_library(LibraryName::Magic)?;
```

## 库分类方法

### 检查库类型

```rust
let lib = LibraryName::Prguse;

// 检查是否为 UI 库
if lib.is_ui_library() {
    println!("这是 UI 库");
}

// 检查是否为特效库
if lib.is_effect_library() {
    println!("这是特效库");
}

// 检查是否为物品库
if lib.is_item_library() {
    println!("这是物品库");
}

// 检查是否为角色装备库
if lib.is_character_library() {
    println!("这是角色装备库");
}
```

### 获取库分类

```rust
use client_macroquad::resources::{LibraryName, LibraryCategory};

let lib = LibraryName::Magic;

match lib.category() {
    LibraryCategory::UI => println!("UI 库"),
    LibraryCategory::Effect => println!("特效库"),
    LibraryCategory::Item => println!("物品库"),
    LibraryCategory::Character => println!("角色库"),
    LibraryCategory::Other => println!("其他库"),
}
```

## 实用示例

### 示例 1: 简洁的绘制代码

```rust
// 绘制 UI 元素
if let Some(info) = LibraryName::Prguse.get_texture(100) {
    if let Some(texture) = &info.image {
        draw_texture_ex(texture, x, y, WHITE, params);
    }
}
```

### 示例 2: 批量预加载特定类型

```rust
let all_libs = vec![
    LibraryName::Prguse,
    LibraryName::Magic,
    LibraryName::Items,
    LibraryName::ChrSel,
];

// 只预加载 UI 库
let ui_libs: Vec<_> = all_libs
    .iter()
    .filter(|lib| lib.is_ui_library())
    .copied()
    .collect();

resources::preload_libraries(&ui_libs);
```

### 示例 3: 条件加载

```rust
fn load_scene_resources(scene: Scene) {
    let libs = match scene {
        Scene::Login => vec![
            LibraryName::ChrSel,
            LibraryName::Prguse,
            LibraryName::Title,
        ],
        Scene::Game => vec![
            LibraryName::Items,
            LibraryName::Magic,
            LibraryName::Weather,
        ],
    };

    // 使用便捷方法预加载
    for lib in &libs {
        let _ = lib.get_library();
    }
}
```

### 示例 4: egui 界面

```rust
egui::Window::new("资源查看器").show(ctx, |ui| {
    // 使用链式调用
    if let Some(handle) = LibraryName::ChrSel.get_egui_texture(ctx, 0) {
        ui.image(&handle);
    }
    
    if let Some(handle) = LibraryName::Title.get_egui_texture(ctx, 100) {
        ui.image(&handle);
    }

```

### 示例 5: 动态库选择

```rust
fn get_equipment_texture(class: CharacterClass, index: usize) -> Option<ImageInfo> {
    let lib = match class {
        CharacterClass::Warrior => LibraryName::CArmours(0),
        CharacterClass::Wizard => LibraryName::CArmours(1),
        CharacterClass::Taoist => LibraryName::CArmours(2),
        CharacterClass::Assassin => LibraryName::AArmours(0),
    };
    
    // 链式调用获取纹理
    lib.get_texture(index)
}
```

## 性能说明

所有便捷方法都是内联的（`#[inline]`），不会产生额外开销：

```rust
#[inline]
pub fn get_texture(self, index: usize) -> Option<ImageInfo> {
    crate::resources::resource_manager::get_texture(self, index)
}
```

编译器会将其优化为直接调用，性能与直接使用 `resources::get_texture()` 完全相同。

## 优势总结

### 代码更简洁

```rust
// 从这样
resources::get_texture(LibraryName::Prguse, 100)

// 变成这样
LibraryName::Prguse.get_texture(100)
```

减少了 40% 的字符！

### 更符合 Rust 习惯

```rust
// 链式调用更自然
LibraryName::Items
    .get_texture(200)
    .map(|info| info.width)
    .unwrap_or(0)
```

### 类型安全

```rust
// 类型推断更清晰
let libs: Vec<LibraryName> = all_libs
    .into_iter()
    .filter(|lib| lib.is_ui_library())  // 方法调用，类型明确
    .collect();
```

### 代码可读性

```rust
// 一眼就能看出在做什么
if LibraryName::Prguse.is_ui_library() {
    // 处理 UI 库
}
```

## 迁移建议

### 渐进式迁移

新旧方法可以共存，不需要一次性迁移：

```rust
// 旧代码继续工作
let info = resources::get_texture(LibraryName::Prguse, 100);

// 新代码使用便捷方法
let info = LibraryName::Prguse.get_texture(100);
```

### 推荐迁移场景

1. **新功能开发**：直接使用便捷方法
2. **代码重构**：逐步替换为便捷方法
3. **UI 代码**：特别适合使用链式调用

### 不推荐迁移的场景

1. **性能关键路径**：保持现有代码（虽然性能相同）
2. **大规模重构**：避免引入不必要的改动
3. **已稳定代码**：如果没有 bug，不要动它

    }
