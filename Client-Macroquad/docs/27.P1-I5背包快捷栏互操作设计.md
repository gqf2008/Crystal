# Client-Macroquad P1-I5 背包/快捷栏互操作设计

日期：2026-02-13

## 1. 目标

在不大改现有 Hybrid UI 结构的前提下，实现 `InventoryDialog` 与 `BeltDialog` 的最小数据交换闭环（I5）。

## 2. 设计范围（最小闭环）

### 2.1 支持的路径

1. 背包 -> 快捷栏（放入）
2. 快捷栏 -> 背包（回收）

### 2.2 本阶段不做

- 不做跨页自动寻位策略优化
- 不做复杂堆叠规则（仅最小叠加或占位）
- 不做服务器同步协议扩展（先本地交互闭环）

## 3. 数据交换协议（UI 内部）

建议在 `MainDialog` 层做协调（避免 `InventoryDialog` 与 `BeltDialog` 互相依赖）：

1. `InventoryDialog` 暴露“待绑定请求”读取接口（一次性消费）
2. `BeltDialog` 暴露“自动放置”与“取回请求”接口（一次性消费）
3. `MainDialog` 在每帧 `show_dialogs()` 末尾统一协调交换

## 4. 放置策略（推荐）

### 4.1 背包 -> 快捷栏

- 若快捷栏存在同 `icon_index` 且可叠加：优先叠加
- 否则放入第一个空格
- 若都失败：回滚到背包原位（避免物品丢失）

### 4.2 快捷栏 -> 背包

- 放入当前背包页第一个空格
- 失败则回滚到快捷栏原位

## 5. 验收标准（I5）

- [ ] 背包可成功放入快捷栏（至少一例）
- [ ] 快捷栏可回收到背包（至少一例）
- [ ] 快捷栏已满时，背包放入失败且物品不丢失
- [ ] 背包已满时，快捷栏回收失败且物品不丢失
