# Macroquad UI 学习笔记

## 核心概念

### 1. UI 入口点

```rust
use macroquad::ui::{hash, root_ui, widgets};

// root_ui() 是主UI入口,在每帧末尾以默认相机渲染
root_ui().label(None, "hello");
if root_ui().button(None, "Push me") {
    println!("pushed");
}
```

### 2. 窗口 (Window)

```rust
use macroquad::ui::widgets::Window;

Window::new(hash!(), vec2(x, y), vec2(width, height))
    .label("窗口标题")
    .titlebar(true)      // 显示标题栏
    .movable(true)       // 可拖动
    .close_button(false) // 关闭按钮
    .ui(&mut *root_ui(), |ui| {
        // 窗口内容
    });
```

### 3. 输入框 (InputText)

```rust
use macroquad::ui::widgets::InputText;

let mut text = String::new();

// 方法1: 使用便捷函数
ui.input_text(hash!(), "标签:", &mut text);

// 方法2: 使用构造器模式
InputText::new(hash!())
    .label("账号:")
    .size(vec2(200., 30.))
    .position(vec2(100., 100.))
    .password(false)  // 密码模式
    .ratio(0.5)       // 标签/输入框宽度比例
    .ui(ui, &mut text);

// 密码输入框
ui.input_password(hash!(), "密码:", &mut password);
```

### 4. 按钮 (Button)

```rust
use macroquad::ui::widgets::Button;

// 文本按钮
if Button::new("登录")
    .size(vec2(100., 40.))
    .position(vec2(x, y))
    .ui(ui) 
{
    println!("按钮被点击");
}

// 便捷方法
if ui.button(None, "点我") {
    // 自动布局
}

if ui.button(vec2(x, y), "固定位置") {
    // 指定位置
}

// 图片按钮
let texture: Texture2D = load_texture("path.png").await.unwrap();
Button::new(texture.clone())
    .size(vec2(120., 70.))
    .ui(ui);
```

### 5. 标签 (Label)

```rust
// 自动布局
ui.label(None, "文本内容");

// 指定位置
ui.label(vec2(10., 20.), "固定位置文本");
```

### 6. 分组 (Group)

```rust
use macroquad::ui::widgets::Group;

Group::new(hash!(), Vec2::new(width, height))
    .position(vec2(x, y))  // 可选位置
    .draggable(true)       // 可拖动
    .hoverable(true)       // 可悬停
    .highlight(false)      // 高亮
    .ui(ui, |ui| {
        // 分组内容
        ui.label(None, "分组内的元素");
    });
```

### 7. 其他控件

```rust
// 复选框
let mut checked = false;
ui.checkbox(hash!(), "选项", &mut checked);

// 滑块
let mut value = 0.0f32;
ui.slider(hash!(), "滑块", 0.0..100.0, &mut value);

// 下拉框
let mut selected = 0;
ui.combo_box(hash!(), "选择", &["选项1", "选项2"], &mut selected);

// 编辑框 (多行文本)
use macroquad::ui::widgets::Editbox;
let mut text = String::new();
Editbox::new(hash!(), vec2(200., 100.))
    .multiline(true)
    .ui(ui, &mut text);
```

## ID 生成 (hash!)

每个控件需要唯一ID来追踪状态:

```rust
use macroquad::ui::hash;

// 简单ID
hash!()

// 带参数的ID (用于循环等场景)
hash!("prefix", i)
hash!("window", "login")
hash!(slot.id, "input")
```

## UI皮肤 (Skin)

### 创建自定义皮肤

```rust
use macroquad::ui::{Skin, root_ui};
use macroquad::math::RectOffset;

// 加载字体
let font = load_ttf_font("path/to/font.ttf").await.unwrap();

// 创建按钮样式
let button_style = root_ui()
    .style_builder()
    .background(
        Image::from_file_with_format(
            include_bytes!("button_bg.png"),
            None,
        ).unwrap(),
    )
    .background_margin(RectOffset::new(8.0, 8.0, 8.0, 8.0))
    .background_hovered(
        Image::from_file_with_format(
            include_bytes!("button_hover.png"),
            None,
        ).unwrap(),
    )
    .background_clicked(
        Image::from_file_with_format(
            include_bytes!("button_click.png"),
            None,
        ).unwrap(),
    )
    .with_font(&font).unwrap()
    .text_color(Color::from_rgba(255, 255, 255, 255))
    .font_size(20)
    .build();

// 组合成皮肤
let custom_skin = Skin {
    button_style,
    window_style,
    label_style,
    editbox_style,
    ..root_ui().default_skin()
};

// 使用皮肤
root_ui().push_skin(&custom_skin);
// ... UI代码 ...
root_ui().pop_skin();
```

## 事件处理

```rust
// 按钮点击
if ui.button(None, "点击") {
    println!("已点击");
}

// 窗口关闭
let closed = Window::new(hash!(), pos, size)
    .close_button(true)
    .ui(ui, |ui| {
        // 内容
    });
if closed {
    println!("窗口已关闭");
}

// 拖放
let drag = Group::new(hash!(), size)
    .draggable(true)
    .ui(ui, |ui| {
        // 内容
    });

match drag {
    Drag::Dropped(pos, Some(target_id)) => {
        // 拖到某个目标
    }
    Drag::Dropped(pos, None) => {
        // 拖到空白处
    }
    Drag::Dragging(pos, id) => {
        // 正在拖动
    }
    Drag::No => {}
}
```

## 登录场景UI示例

基于C# LoginScene和macroquad UI学习,登录界面应该这样实现:

```rust
use macroquad::prelude::*;
use macroquad::ui::{hash, root_ui, widgets};

pub struct LoginScene {
    // UI状态
    account_text: String,
    password_text: String,
    
    // 资源
    background: Option<Texture2D>,
    title_image: Option<Texture2D>,
    button_images: ButtonImages,
    
    // 动画
    background_frame: usize,
    animation_playing: bool,
}

struct ButtonImages {
    ok_normal: Texture2D,
    ok_hover: Texture2D,
    ok_pressed: Texture2D,
    // ... 其他按钮
}

impl LoginScene {
    pub fn new() -> Self {
        Self {
            account_text: String::new(),
            password_text: String::new(),
            background: None,
            title_image: None,
            button_images: ButtonImages::default(),
            background_frame: 0,
            animation_playing: false,
        }
    }
    
    pub async fn load_resources(&mut self) {
        // 加载资源 (对应 Libraries.ChrSel, Libraries.Title 等)
        self.background = Some(load_texture("Data/ChrSel.png").await.unwrap());
        self.title_image = Some(load_texture("Data/Title.png").await.unwrap());
        // ...
    }
    
    pub fn update(&mut self, ctx: &GameContext) {
        // 背景动画更新
        if self.animation_playing {
            self.background_frame += 1;
            if self.background_frame >= 19 {
                // 切换场景
            }
        }
    }
    
    pub fn draw(&mut self) {
        clear_background(BLACK);
        
        // 绘制背景
        if let Some(bg) = &self.background {
            draw_texture(bg, 0., 0., WHITE);
        }
        
        // 绘制UI
        self.draw_ui();
    }
    
    fn draw_ui(&mut self) {
        let ui = &mut *root_ui();
        
        // 登录对话框 (328x220, 居中)
        let screen_w = screen_width();
        let screen_h = screen_height();
        let dialog_w = 328.;
        let dialog_h = 220.;
        let dialog_x = (screen_w - dialog_w) / 2.;
        let dialog_y = (screen_h - dialog_h) / 2.;
        
        widgets::Window::new(hash!("login_dialog"), 
                           vec2(dialog_x, dialog_y), 
                           vec2(dialog_w, dialog_h))
            .titlebar(false)
            .movable(false)
            .ui(ui, |ui| {
                // 标题图片
                if let Some(title) = &self.title_image {
                    draw_texture(title, dialog_x + 50., dialog_y + 12., WHITE);
                }
                
                // 账号标签位置: (52, 83)
                ui.label(vec2(52., 83.), "账号:");
                
                // 账号输入框: (85, 85), 136x15
                widgets::InputText::new(hash!("account"))
                    .position(vec2(85., 85.))
                    .size(vec2(136., 15.))
                    .ui(ui, &mut self.account_text);
                
                // 密码标签: (43, 105)
                ui.label(vec2(43., 105.), "密码:");
                
                // 密码输入框: (85, 108), 136x15
                widgets::InputText::new(hash!("password"))
                    .position(vec2(85., 108.))
                    .size(vec2(136., 15.))
                    .password(true)
                    .ui(ui, &mut self.password_text);
                
                // OK按钮: (227, 81), 42x42
                if widgets::Button::new("OK")
                    .position(vec2(227., 81.))
                    .size(vec2(42., 42.))
                    .ui(ui) 
                {
                    self.on_login();
                }
                
                // 创建账号按钮: (60, 163)
                if widgets::Button::new("创建账号")
                    .position(vec2(60., 163.))
                    .ui(ui) 
                {
                    // 显示创建账号对话框
                }
                
                // 修改密码按钮: (166, 163)
                if widgets::Button::new("修改密码")
                    .position(vec2(166., 163.))
                    .ui(ui) 
                {
                    // 显示修改密码对话框
                }
                
                // 关闭按钮: (166, 189)
                if widgets::Button::new("关闭")
                    .position(vec2(166., 189.))
                    .ui(ui) 
                {
                    // 关闭游戏
                }
            });
        
        // 版本信息 (左下角)
        ui.label(vec2(5., screen_h - 20.), 
                &format!("Build: Crystal-Rust v{}", env!("CARGO_PKG_VERSION")));
    }
    
    fn on_login(&mut self) {
        // 验证输入
        if self.account_text.is_empty() || self.password_text.is_empty() {
            return;
        }
        
        // 发送登录包
        // Network.Enqueue(new C.Login { 
        //     AccountID = account, 
        //     Password = password 
        // });
        
        // 开始动画
        self.animation_playing = true;
    }
}
```

## 关键要点

1. **ID管理**: 每个控件必须有唯一ID,使用 `hash!()` 宏生成
2. **位置控制**: 可以用 `position()` 指定绝对位置,或让UI自动布局
3. **皮肤系统**: 支持完全自定义UI外观,可加载9-patch图片
4. **闭包UI**: Window和Group使用闭包模式构建子UI
5. **状态保存**: UI系统自动保存窗口位置、滚动等状态
6. **响应式**: 控件返回是否被点击/修改,用于事件处理

## 与C#对比

| C# (WinForms风格) | Rust macroquad |
|------------------|----------------|
| `new MirTextBox()` | `InputText::new(hash!())` |
| `textBox.Text` | `&mut String` 参数 |
| `button.Click += handler` | `if ui.button() { ... }` |
| `control.Parent = this` | 闭包内自动层级 |
| `control.Location = new Point()` | `.position(vec2())` |
| `control.Size = new Size()` | `.size(vec2())` |

## 资源映射

C# Libraries → Rust 资源路径:
- `Libraries.ChrSel` → `Data/ChrSel/` (背景动画, 19帧)
- `Libraries.Title` → `Data/Title/` (标题图片, 按钮图片)
- `Libraries.Prguse` → `Data/Prguse/` (UI元素)

需要实现资源加载器来读取.Lib文件格式。
