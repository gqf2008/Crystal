# Client-Macroquad 移植完成度审查与下一步计划

日期：2026-02-13

## 1. 审查范围与依据

- 代码范围：`Client-Macroquad/src/`、`Client/MirScenes/Dialogs/`
- 文档范围：`Client-Macroquad/GAMESCENE_UI_TODO.md`
- 可构建性验证：在 `Client-Macroquad/` 执行 `cargo test --quiet`

## 2. 当前完成度结论（审查结果）

### 2.1 工程可构建性：⚠️ 未达到稳定基线

- 现状：`cargo test --quiet` 失败，报错为本地 patch 依赖缺失：
  - `failed to load source for dependency miniquad`
  - 路径 `Client-Macroquad/miniquad/Cargo.toml` 不存在
- 影响：当前无法在 CI/本地形成稳定的“可验证基线”，会阻塞后续移植验收。

### 2.2 场景骨架：✅ 已形成可运行主链路

- 已有场景文件：`login_scene.rs`、`select_scene.rs`、`game_scene.rs`、`loading_scene.rs`
- `game_scene.rs` 已接入 `SystemScheduler`，并串联了网络、移动、战斗、渲染、UI 等系统调度。
- 结论：从“场景架构”维度看，主干迁移已基本成型。

### 2.3 Game Dialog 移植覆盖：🚧 中低完成度

- 原 C# 对话框类（`Client/MirScenes/Dialogs/*.cs`）：约 **68** 个
- Macroquad 游戏对话框结构体（`Client-Macroquad/src/scenes/dialogs/game`）：约 **15** 个主对话框实现（Hybrid）
- 粗略覆盖率：**~22%（15/68）**

> 说明：当前 Rust 侧已覆盖主界面、聊天、背包、NPC 商店等核心入口，但大量社交/邮件/任务细分/英雄扩展类对话框仍未落地。

### 2.4 关键 UI 模块状态（结合 `GAMESCENE_UI_TODO.md`）

- 已有基础实现：`MainDialog`、`BeltDialog`、`ChatDialog`、`ChatControlBar`、`InventoryDialog`（框架层）
- 仍缺关键交互：背包物品图标/数量/拖拽、角色面板细项、聊天高级功能、多类功能对话框
- 结论：当前更接近“可演示框架”，尚未达到“玩法完整迁移”。

## 3. 下一步移植计划（建议执行顺序）

## P0（本周，先打通“可验证 + 可玩闭环”）

1. **修复构建阻塞**
   - 目标：恢复 `cargo check` / `cargo test` 基线可执行
   - 验收：至少一个标准命令可在干净环境稳定通过

2. **建立移植台账（对话框映射表）**
   - 以“C# 对话框类 -> Rust 文件 -> 状态（未开始/骨架/可交互/可联机）”管理
   - 验收：覆盖 `Client/MirScenes/Dialogs` 全量类名

3. **固化最小可玩链路**
   - 链路：登录 -> 选角 -> 进游戏 -> 主 UI（聊天/背包/快捷栏）
   - 验收：链路无致命中断，基础输入与开关可用

## P1（1~2 周，补齐高频核心交互）

4. **InventoryDialog 功能补齐（最高优先级）**
   - 物品图标、数量、拖拽（背包内与快捷栏之间）
   - 验收：完成“拿起-放下-交换-丢弃”最小闭环

5. **CharacterDialog 补齐**
   - 装备槽显示与基础属性展示，技能页最小可用
   - 验收：支持查看/切页，基础数据正确显示

6. **MiniMap / Menu / Option 可用化**
   - 保证常驻开关与设置项可交互
   - 验收：入口按钮与快捷键行为稳定

## P2（2~4 周，扩展到 NPC 与社交系统）

7. **NPC 系列对话框分批迁移**
   - `NPCDialog`、`NPCGoodsDialog` 后续扩展到 Craft/Refine/Socket 等
   - 验收：关键 NPC 业务链（对话->购买/操作）可跑通

8. **社交与系统功能模块**
   - Trade/Group/Guild/Friend/Mail/Quest 等按业务优先级推进
   - 验收：每完成一类模块，补充对应联调脚本与状态记录

## P3（持续，质量与验收）

9. **回归与性能**
   - 建立“场景切换 + 常用对话框开关 + 网络事件”回归清单
   - 验收：关键链路无回退，性能指标可观测

10. **文档同步**
    - 每周更新移植台账与里程碑状态（完成率、阻塞项、下周目标）
    - 验收：文档状态与代码状态一致

## 4. 建议的里程碑定义（用于跟踪）

- **M1（可构建）**：构建/测试基线恢复
- **M2（可玩闭环）**：登录->选角->主场景基础 UI 可持续运行
- **M3（核心交互）**：背包/角色/小地图/设置可稳定使用
- **M4（业务扩展）**：NPC 与社交模块按优先级逐步上线

当前建议状态判定：**介于 M1 与 M2 之间（架构在前，功能补齐在后）**。
