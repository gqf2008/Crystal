## 1. 快速开始

### 1.1 初始化

```rust
use client_macroquad::resources;

fn main() {
    // 设置数据路径
    resources::set_data_path("Data");
    
    // 设置缓存大小 (可选)
    resources::set_cache_size(2000, 500);  // Macroquad 纹理, egui 纹理
}
```

### 1.2 第一个示例 - UI 资源

```rust
use client_macroquad::resources::LibraryName;
use egui_macroquad::egui;

// egui 中显示 UI 图标
egui::Window::new("物品").show(ctx, |ui| {
    // ✅ 一行代码搞定！
    if let Some(info) = LibraryName::Items.get_egui_texture(ctx, 0) {
        if let Some(handle) = &info.egui_texture {
            ui.image(handle);
            ui.label(format!("尺寸: {}x{}", info.width, info.height));
        }
    }
});
```

### 1.3 第二个示例 - 地图资源

```rust
use client_macroquad::resources::get_map_texture;
use macroquad::prelude::*;

// 渲染地图瓦片
fn render_tile(file_index: i16, image_index: i32, x: f32, y: f32) {
    // ✅ 一行加载，自动缓存
    if let Some(info) = get_map_texture(file_index, image_index) {
        if let Some(texture) = &info.image {
            draw_texture_ex(
                texture,
                x - info.x as f32,  // 自动使用偏移
                y - info.y as f32,
                WHITE,
                DrawTextureParams::default(),
            );
        }
    }
}
```

## 2. 资源分类

传奇2 资源按用途分为两大类：

### 2.1 UI 资源（egui + Macroquad）

用于界面显示，支持双渲染引擎：

| 库名 | 用途 | 图像数量 | 特点 |
|------|------|----------|------|
| `Prguse` | 主界面元素 | 2447 | 按钮、窗口、边框 |
| `Prguse2` | 扩展界面 | - | 额外 UI 元素 |
| `Prguse3` | 更多界面 | - | 辅助元素 |
| `ChrSel` | 角色选择 | 1146 | 角色界面 |
| `Items` | 物品图标 | - | 背包物品 |
| `Title` | 标题界面 | 899 | 登录界面 |
| `Magic` | 技能图标 | - | 技能特效 |
| `MagicC` | 技能特效 | - | 角色职业技能 |

**API：**
```rust
LibraryName::Items.get_egui_texture(ctx, index)   // egui 渲染
LibraryName::Items.get_texture(index)              // Macroquad 渲染
```

### 2.2 地图资源（仅 Macroquad）

用于游戏世界渲染，只支持 Macroquad：

| 库类型 | 索引范围 | 数量 | 来源 |
|--------|----------|------|------|
| 盛大 Mir2 | 0-99 | 100 | 官方地图 |
| WeMade Mir2 | 100-199 | 100 | 韩国版 |
| 盛大 Mir3 | 200-299 | 100 | 扩展地图 |
| WeMade Mir3 | 300-399 | 100 | 新地图 |

**API：**
```rust
get_map_texture(file_index, image_index)  // 游戏世界渲染
get_map_size(file_index, image_index)     // 高效获取尺寸
```

### 2.3 为什么分类？

| 原因 | UI 资源 | 地图资源 |
|------|---------|----------|
| **数量** | 少（数百） | 多（数千） |
| **更新** | 低频（界面切换） | 高频（每帧） |
| **渲染** | egui 适合 | Macroquad 批量渲染 |
| **内存** | egui 需要 TextureHandle | 仅需 Texture2D |

**设计原则：让合适的工具做合适的事！**

## 3. 基础 API

### 3.1 LibraryName 枚举方法

所有 UI 库都支持便捷方法：

```rust
use client_macroquad::resources::LibraryName;

// 1. 获取 egui 纹理（返回 ImageInfo）
let info = LibraryName::Prguse.get_egui_texture(ctx, 0)?;
if let Some(handle) = &info.egui_texture {
    ui.image(handle);
}

// 2. 获取 Macroquad 纹理（返回 ImageInfo）
let info = LibraryName::Items.get_texture(200)?;
if let Some(texture) = &info.image {
    draw_texture(texture, x, y, WHITE);
}

// 3. 高效获取尺寸（无需加载纹理）
if let Some((w, h)) = LibraryName::Magic.get_size(5) {
    println!("技能图标尺寸: {}x{}", w, h);
}

// 4. 获取库引用（高级用法）
let lib = LibraryName::ChrSel.get_library()?;
let mut lib_ref = lib.borrow_mut();
// ... 直接操作库
```

### 3.2 全局函数 API

```rust
use client_macroquad::resources;

// 1. 配置
resources::set_data_path("Data");

resources::clear_cache();
```

### 3.3 ImageInfo 结构

所有纹理加载函数都返回 `ImageInfo`：

```rust
    pub has_mask: bool,          // 是否有遮罩
    pub mask_width: i16,         // 遮罩宽度
    pub mask_height: i16,        // 遮罩高度
    pub mask_x: i16,             // 遮罩 X 偏移
    pub mask_y: i16,             // 遮罩 Y 偏移
    
    // 纹理
    pub image: Option<Texture2D>,              // Macroquad 纹理
```

## 4. 进阶用法

### 4.1 混合渲染（UI 资源）

UI 资源支持同时在 egui 和 Macroquad 中渲染：

```rust
// 加载一次
let info = LibraryName::Items.get_egui_texture(ctx, 200)?;

// 在 egui 中显示
egui::Window::new("物品详情").show(ctx, |ui| {
    if let Some(handle) = &info.egui_texture {
        ui.image(handle);
    }
    ui.label(format!("尺寸: {}x{}", info.width, info.height));
});

// 同时在 Macroquad 中渲染（同一帧）
if let Some(texture) = &info.image {
    draw_texture_ex(
        texture,
        player_x - info.x as f32,
        player_y - info.y as f32,
        WHITE,
        DrawTextureParams {
            dest_size: Some(vec2(info.width as f32, info.height as f32)),
            ..Default::default()
        },
    );
}
```

### 4.2 批量地图渲染

```rust
use client_macroquad::resources::{get_map_texture, MapReader};

fn render_map_layer(map: &MapReader, layer: &str, camera_x: i32, camera_y: i32) {
    let visible_range = 10;  // 可见范围
    
    for dy in -visible_range..=visible_range {
        for dx in -visible_range..=visible_range {
            let x = camera_x + dx;
            let y = camera_y + dy;
            
            if let Some(cell) = map.get_cell(x, y) {
                // 根据层级获取瓦片
                let (file_idx, img_idx) = match layer {
                    "back" => cell.back_tile(),
                    "middle" => cell.middle_tile(),
                    "front" => cell.front_tile(),
                    _ => continue,
                };
                
                if let Some((f, i)) = (file_idx, img_idx) {
                    // ✅ 自动 LRU 缓存
                    if let Some(info) = get_map_texture(f, i) {
                        if let Some(texture) = &info.image {
                            let screen_x = (x * 48) as f32;
                            let screen_y = (y * 32) as f32;
                            draw_texture_ex(
                                texture,
                                screen_x,
                                screen_y - texture.height() + 32.0,
                                WHITE,
                                DrawTextureParams::default(),
                            );
                        }
                    }
                }
            }
        }
    }
}
```

### 4.3 预加载优化

```rust
// 预加载热点区域
fn preload_around_player(map: &MapReader, player_x: i32, player_y: i32) {
    let preload_range = 15;  // 比可见范围大一点
    
    for dy in -preload_range..=preload_range {
        for dx in -preload_range..=preload_range {
            if let Some(cell) = map.get_cell(player_x + dx, player_y + dy) {
                // 预加载所有层
                if let Some((f, i)) = cell.back_tile() {
                    let _ = get_map_texture(f, i);
                }
                if let Some((f, i)) = cell.middle_tile() {
                    let _ = get_map_texture(f, i);
                }
                if let Some((f, i)) = cell.front_tile() {
                    let _ = get_map_texture(f, i);
                }
            }
        }
    }
}
```

## 5. 性能优化

### 5.1 缓存大小配置

根据场景配置合适的缓存大小：

```rust
// 小地图 (< 100x100)
resources::set_cache_size(1000, 300);

// 中等地图 (100x300)
resources::set_cache_size(2000, 500);

// 大地图 (> 300x300)
resources::set_cache_size(3000, 800);

// 调试场景（需要大量 UI 预览）
resources::set_cache_size(1500, 1000);
```

**原则：**
- Macroquad 缓存 > egui 缓存（地图瓦片更多）
- 可见瓦片数量 × 3 ≈ 推荐缓存大小
- 内存富裕可以 × 5-10

### 5.2 缓存监控

```rust
// 定期检查缓存状态
let stats = resources::cache_stats();
println!("Macroquad 缓存: {}/{}", stats.texture_cache_size, stats.texture_cache_capacity);
println!("egui 缓存: {}/{}", stats.egui_cache_size, stats.egui_cache_capacity);
println!("已加载库: {}", stats.loaded_libraries);

// 计算命中率
let hit_rate = stats.texture_cache_size as f64 / stats.texture_cache_capacity as f64;
if hit_rate < 0.5 {
    println!("⚠️ 缓存命中率低 ({:.1}%)，考虑增加缓存大小", hit_rate * 100.0);
}
```

### 5.3 性能对比

| 操作 | 旧 API | 新 API | 提升 |
|------|--------|--------|------|
| 首次加载 | 1-5 ms | 1-5 ms | 相同 |
| 缓存命中 | 0.5-1 ms | 0.01 ms | **50-100x** |
| 尺寸查询 | 0.5 ms | 0.001 ms | **500x** |
| 代码行数 | 4-5 行 | 1 行 | **75%** 减少 |

### 5.4 内存使用

```
假设配置: set_cache_size(2000, 500)

Macroquad 缓存:
- ImageInfo: 2000 × ~120 bytes = 240 KB
- 纹理数据: 由 Macroquad 管理（GPU 显存）

egui 缓存:
- ImageInfo: 500 × ~144 bytes = 72 KB
- TextureHandle: 500 × ~24 bytes = 12 KB

总内存: ~324 KB (可忽略)
```

## 6. 最佳实践

### 6.1 代码组织

```rust
// ✅ 推荐：使用便捷方法
LibraryName::Items.get_texture(index)

// ⚠️ 可用：使用全局函数
resources::get_texture(LibraryName::Items, index)

// ❌ 不推荐：直接操作库
let lib = resources::get_library(LibraryName::Items)?;
let mut lib_ref = lib.borrow_mut();
let info = lib_ref.get_or_create_texture(index)?;
```

### 6.2 错误处理

```rust
// ✅ 优雅的错误处理
if let Some(info) = get_map_texture(file_index, image_index) {
    if let Some(texture) = &info.image {
        // 渲染纹理
    } else {
        // 纹理加载失败，显示占位符
        draw_placeholder(x, y);
    }
} else {
    // 索引无效或库未加载
    log::warn!("无法加载地图纹理 {}:{}", file_index, image_index);
}

// ❌ 避免 unwrap
let info = get_map_texture(file_index, image_index).unwrap();  // 可能 panic！
```

### 6.3 资源生命周期

```rust
// ✅ 推荐：局部加载，立即使用
fn render_tile(x: i32, y: i32) {
    if let Some(info) = get_map_texture(file_index, image_index) {
        // info 在此作用域内使用
        draw_texture(&info.image, x, y);
    }
    // info 被自动 drop，但纹理已缓存
}

// ⚠️ 谨慎：长期持有 ImageInfo
struct Player {
    sprite_info: ImageInfo,  // 占用内存
}
// 更好的做法：只存储索引，需要时加载
struct Player {
    sprite_index: usize,
}
```

### 6.4 线程安全

```rust
// ✅ 单线程安全
// 资源管理器使用 thread_local! + RefCell，无锁开销

// ❌ 不支持多线程
// 如果需要多线程，请在主线程预加载：
let handles: Vec<_> = indices.iter()
    .filter_map(|&idx| get_texture(lib, idx))
    .collect();

// 然后在其他线程使用 handles（只读）
```

```rust
// 模式 3: 手动缓存管理
static TEXTURE_CACHE: Lazy<Mutex<HashMap<...>>> = ...;
```

### 7.2 迁移步骤

**步骤 1：使用便捷方法**

```rust
// ❌ 旧代码
let lib = get_library(LibraryName::Items)?;
let mut lib_ref = lib.borrow_mut();
```

```rust
let size = lib.borrow_mut().get_size(index)?;

// ✅ 新代码
let size = LibraryName::Items.get_size(index)?;
```

**步骤 3：使用 egui 支持**

```rust
// ❌ 旧代码：手动转换
let lib = get_library(LibraryName::Items)?;
let info = lib.borrow_mut().get_or_create_texture(index)?;
let texture = info.image.as_ref()?;
// ... 手动转换为 egui::ColorImage ...

// ✅ 新代码：一行搞定
```

```rust
    return Some(cached.clone());
```

## 8. 常见问题

### Q1: 如何选择 Macroquad 还是 egui 纹理？

**A:** 根据资源类型和使用场景：

| 场景 | API | 原因 |
|------|-----|------|
| UI 界面显示 | `get_egui_texture()` | egui 专门用于 UI |
| 游戏世界渲染 | `get_texture()` | Macroquad 高性能 |
| 地图瓦片 | `get_map_texture()` | 仅需 Macroquad |
| 混合渲染 | `get_egui_texture()` | 包含两种纹理 |

### Q2: 缓存什么时候被淘汰？

**A:** LRU（最近最少使用）策略：

```rust
// 缓存满时，最久未访问的项被淘汰
resources::set_cache_size(1000, 500);

// 第 1001 次加载会淘汰最旧的缓存
let info1 = get_texture(lib, 0)?;     // 缓存 1
// ... 999 次其他加载 ...
let info1000 = get_texture(lib, 999)?; // 缓存 1000
let info1001 = get_texture(lib, 1000)?; // 缓存 1001，淘汰缓存 1
```

### Q3: 为什么地图不支持 egui？

**A:** 性能和使用场景考虑：

```
地图渲染特点:
- 每帧渲染数百到数千个瓦片
- 需要世界坐标系和相机变换
- 需要批量绘制和 GPU 加速
- 需要自定义着色器支持

egui 特点:
- UI 控件系统，每个元素单独绘制
- 超过 100 个控件就会卡顿
- 不支持自定义着色器
- 适合工具和调试界面

结论: Macroquad 比 egui 快 10-50 倍用于游戏世界渲染
```

### Q4: 如何调试资源加载问题？

**A:** 使用缓存统计和日志：

```rust
// 1. 检查缓存状态
let stats = resources::cache_stats();
println!("缓存统计: {:?}", stats);

// 2. 验证资源路径
resources::set_data_path("Data");
let lib = resources::get_library(LibraryName::Items);
if lib.is_none() {
    println!("❌ 库加载失败，检查路径: Data/Items.lib");
}

// 3. 验证索引范围
if let Some(lib) = resources::get_library(LibraryName::Items) {
    let count = lib.borrow().count();
    println!("Items 库包含 {} 个图像", count);
}

// 4. 启用日志
env_logger::init();  // 在 main 函数开始
// 然后会看到详细的加载日志
```

### Q5: 性能不够怎么办？

**A:** 按优先级优化：

**优先级 1: 增加缓存**
```rust
resources::set_cache_size(5000, 1000);  // 增大缓存
```

**优先级 2: 预加载**
```rust
// 场景切换时预加载
preload_around_player(map, player_x, player_y);
```

**优先级 3: 减少加载**
```rust
// 只渲染可见区域
let visible_tiles = get_visible_tiles(camera);
for tile in visible_tiles {
    // ...
}
```

**优先级 4: 批量渲染**
```rust
// 收集所有纹理，一次性提交 GPU
let textures: Vec<_> = tiles.iter()
    .filter_map(|t| get_map_texture(t.file, t.index))
    .collect();
draw_batch(&textures);
```

### Q6: 内存占用太高怎么办？

**A:** 减少缓存或使用尺寸查询：

```rust
// 1. 减小缓存
resources::set_cache_size(1000, 300);  // 降低缓存

// 2. 定期清理（谨慎使用）
if memory_pressure_detected() {
    resources::clear_cache();  // 清空所有缓存
}

// 3. 只获取尺寸，不加载纹理
let size = get_map_size(file_index, image_index)?;  // 仅 ~1 KB
// 而不是
let info = get_map_texture(file_index, image_index)?;  // 可能 100+ KB
```

### Q7: 多个场景共享资源怎么办？

**A:** 资源管理器是全局单例，自动共享：

```rust
// 场景 1
fn login_scene() {
    let info = LibraryName::Title.get_texture(0)?;
    // ...
}

// 场景 2
fn select_scene() {
    let info = LibraryName::Title.get_texture(0)?;  // ✅ 复用缓存！
    // ...
}

// 场景切换不会清空缓存
// 除非手动调用 clear_cache()
```

### Q8: 如何实现资源热重载？

**A:** 清理缓存并重新加载：

```rust
// 检测文件变化（使用 notify 等库）
if file_changed("Data/Items.lib") {
    // 清空缓存
    resources::clear_cache();
    
    // 下次访问会自动重新加载
    let info = LibraryName::Items.get_texture(0)?;
}

// 或者只清理特定库（高级用法）
// 需要直接访问 ResourceManager
```

### 9.2 地图渲染器

```rust
use client_macroquad::resources::{get_map_texture, MapReader};
use macroquad::prelude::*;

pub struct MapRenderer {
    map: MapReader,
    camera_x: i32,
    camera_y: i32,
}

impl MapRenderer {
    pub fn new(map_path: &str) -> Result<Self, std::io::Error> {
        let map = MapReader::load(map_path)?;
        
        Ok(Self {
            map,
            camera_x: 0,
            camera_y: 0,
        })
    }
    
    pub fn render(&self) {
        let visible_range = 10;
        
        // 渲染顺序：back → middle → front
        for layer in &["back", "middle", "front"] {
            for dy in -visible_range..=visible_range {
                for dx in -visible_range..=visible_range {
                    let x = self.camera_x + dx;
                    let y = self.camera_y + dy;
                    
                    if let Some(cell) = self.map.get_cell(x, y) {
                        let tile = match *layer {
                            "back" => cell.back_tile(),
                            "middle" => cell.middle_tile(),
                            "front" => cell.front_tile(),
                            _ => None,
                        };
                        
                        if let Some((file_idx, img_idx)) = tile {
                            self.render_tile(file_idx, img_idx, x, y);
                        }
                    }
                }
            }
        }
    }
    
    fn render_tile(&self, file_index: i16, image_index: i32, x: i32, y: i32) {
        if let Some(info) = get_map_texture(file_index, image_index) {
            if let Some(texture) = &info.image {
                let screen_x = (x * 48) as f32;
                let screen_y = (y * 32) as f32 + 32.0 - texture.height();
                
                draw_texture_ex(
                    texture,
                    screen_x,
                    screen_y,
                    WHITE,
                    DrawTextureParams::default(),
                );
            }
        }
    }
    
    pub fn move_camera(&mut self, dx: i32, dy: i32) {
        self.camera_x += dx;
        self.camera_y += dy;
        
        // 预加载新区域
        self.preload();
    }
    
    fn preload(&self) {
        let preload_range = 15;
        
        for dy in -preload_range..=preload_range {
            for dx in -preload_range..=preload_range {
                if let Some(cell) = self.map.get_cell(self.camera_x + dx, self.camera_y + dy) {
                    if let Some((f, i)) = cell.back_tile() {
                        let _ = get_map_texture(f, i);
                    }
                    if let Some((f, i)) = cell.middle_tile() {
                        let _ = get_map_texture(f, i);
                    }
                    if let Some((f, i)) = cell.front_tile() {
                        let _ = get_map_texture(f, i);
                    }
                }
            }
        }
    }
}
```

```rust
        });
```
