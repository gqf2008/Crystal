- Rust 侧存在部分“近似功能但名称不同”的实现，例如：
  - `QuestLogDialogHybrid`（当前与 C# `Quest*Dialog` 组并非一一同名）
  - `AmountBoxHybrid`（用于数量输入）
  - 登录场景内嵌 `new_account` / `change_password` 对话框
- 因此本台账用于 **P0 阶段的客观基线**（精确类名对照），后续可在 P1/P2 增加“功能等价映射”列。
