# 地图纹理索引访问机制详解

## 概述

地图纹理的访问采用 **二级索引** 机制：
1. **库索引 (file_index)** - 指定从哪个地图库 (MapLibs[0-399]) 加载
2. **图像索引 (image_index)** - 指定库中的哪个图像

## 核心数据结构

### 地图单元格 (CellInfo)

每个地图格子存储三层纹理索引：

```rust
pub struct CellInfo {
    // 背景层 (Back Layer)
    pub back_index: i16,      // 库索引 (MapLibs[back_index])
    pub back_image: i32,      // 图像索引 (该库中的第几个图像)
    
    // 中间层 (Middle Layer)
    pub middle_index: i16,    // 库索引
    pub middle_image: i32,    // 图像索引
    
    // 前景层 (Front Layer)
    pub front_index: i16,     // 库索引
    pub front_image: i32,     // 图像索引
    
    // ... 其他字段
}
```

### MapLibs 数组库

地图库是一个包含 400 个元素的数组，每个元素是一个 MLibrary：

```rust
// MapLibs[0-399] 索引分配:
// - 0-99:    WeMade Mir2 地图库
// - 100-199: Shanda Mir2 地图库
// - 200-299: WeMade Mir3 地图库
// - 300-399: Shanda Mir3 地图库
```

## 纹理加载流程

### 1. 从地图格子获取索引

```rust
// 示例：获取某个格子的 Middle 层纹理索引
let cell = map_reader.get_cell(x, y)?;

// back_tile() 返回 (file_index, image_index)
if let Some((file_index, image_index)) = cell.middle_tile() {
    // file_index: 库索引 (0-399)
    // image_index: 图像索引 (库中第几个图像)
}
```

### 2. 通过库索引获取 MLibrary

```rust
// 方式1: 使用便捷函数
let lib = get_map_library(file_index)?;

// 方式2: 使用数组库访问
let lib = get_from_array(LibraryArray::MapLibs, file_index as usize)?;

// 方式3: 使用新资源管理器
let lib = resource_manager::get_from_array(LibraryArray::MapLibs, file_index as usize)?;
```

### 3. 从库中加载纹理

```rust
// 获取库的可变借用
let mut lib_guard = lib.borrow_mut();

// 根据 image_index 加载纹理
let image_info = lib_guard.get_or_create_texture(image_index as usize)?;

// 获取实际的纹理对象
if let Some(texture) = &image_info.image {
    // 使用纹理渲染...
}
```

## 完整示例

### 渲染 Back 层

```rust
fn render_back_layer(&mut self, map_reader: &MapReader, x: i32, y: i32) {
    // 1. 获取格子
    let cell = map_reader.get_cell(x, y)?;
    
    // 2. 获取纹理索引
    if let Some((file_index, image_index)) = cell.back_tile() {
        // file_index: 0-399 (MapLibs 数组索引)
        // image_index: 库中的图像编号
        
        // 3. 获取库
        let lib = get_map_library(file_index)?;
        let mut lib_guard = lib.borrow_mut();
        
        // 4. 加载纹理
        let info = lib_guard.get_or_create_texture(image_index as usize)?;
        
        // 5. 获取纹理对象
        if let Some(texture) = &info.image {
            // 6. 计算世界坐标
            let world_x = x as f32 * TILE_WIDTH;
            let world_y = y as f32 * TILE_HEIGHT;
            
            // 7. 纹理底部对齐到格子底部
            let offset_y = world_y + TILE_HEIGHT - texture.height();
            
            // 8. 绘制
            draw_texture_ex(
                texture,
                world_x,
                offset_y,
                WHITE,
                DrawTextureParams {
                    dest_size: Some(vec2(texture.width(), texture.height())),
                    ..Default::default()
                },
            );
        }
    }
}
```

### 渲染 Middle 层（带动画）

```rust
fn render_middle_animated(&mut self, map_reader: &MapReader, x: i32, y: i32) {
    let cell = map_reader.get_cell(x, y)?;
    
    if let Some((file_index, mut image_index)) = cell.middle_tile() {
        // 计算动画帧偏移
        if cell.middle_has_animation() {
            let frame_count = cell.middle_animation_frame;
            let frame_interval = cell.middle_animation_tick;
            
            // C# 动画公式:
            // index += (AnimationCount % (animation + animation * animationTick)) 
            //          / (1 + animationTick);
            let total_ticks = frame_count as u32 + frame_count as u32 * frame_interval as u32;
            let divisor = 1 + frame_interval as u32;
            let frame_offset = ((self.animation_frame % total_ticks) / divisor) as i32;
            
            image_index += frame_offset;  // ⚠️ 动态修改图像索引
        }
        
        // 使用修改后的 image_index 加载纹理
        let lib = get_map_library(file_index)?;
        let mut lib_guard = lib.borrow_mut();
        let info = lib_guard.get_or_create_texture(image_index as usize)?;
        
        // ... 渲染纹理
    }
}
```

## 索引编码规则

### file_index (库索引)

```
i16: -32768 ~ 32767

实际使用: 0 ~ 399
- 0-99:    WeMade Mir2
- 100-199: Shanda Mir2  
- 200-299: WeMade Mir3
- 300-399: Shanda Mir3
```

### image_index (图像索引)

```
i32: -2147483648 ~ 2147483647

实际使用:
- 低28位: 图像编号 (0 ~ 268435455)
- 高4位:  标志位
  - bit 28: Light (光照)
  - bit 29: Blend (混合模式 - ADD 叠加)
  - bit 30: Priority (渲染优先级)
  - bit 31: Unknown
```

### 提取标志位

```rust
// 提取图像编号（去除标志位）
let image_id = image_index & 0x0FFFFFFF;

// 检查混合模式标志
let use_blend = (image_index & 0x20000000) != 0;

// 检查优先级标志
let high_priority = (image_index & 0x20000000) != 0;

// 检查光照标志
let has_light = (image_index & 0x10000000) != 0;
```

### 场景3: 性能优化 - 纹理缓存

```rust
// 问题: 每帧都重复加载相同纹理
for each_frame {
    for each_cell {
        let lib = get_map_library(file_index)?;  // ❌ 重复获取
        let texture = lib.get_texture(image_index)?;  // ❌ 重复加载
    }
}

// 解决方案1: 使用新资源管理器（自动 LRU 缓存）
for each_frame {
    for each_cell {
        // ✅ 自动缓存，命中率 70-90%
        let info = LibraryName::from_map_index(file_index)?.get_texture(image_index)?;
    }
}

// 解决方案2: 手动缓存
let mut texture_cache: HashMap<(i16, i32), Texture2D> = HashMap::new();

for each_cell {
    let key = (file_index, image_index);
    let texture = texture_cache.entry(key)
        .or_insert_with(|| load_texture(file_index, image_index));
}
```

## 特殊情况处理

### Back 层 - 2x2 共享

```rust
// Back 层纹理被 2x2 格子共享，只在偶数坐标存储
if cell.back_index > 0 {
    // 只有偶数坐标的格子才有 back 数据
    // 奇数坐标的格子会共享左上角的 back 纹理
    
    // 渲染时只处理偶数坐标
    for y in (0..height).step_by(2) {
        for x in (0..width).step_by(2) {
            render_back_tile(x, y);
        }
    }
}
```

### Middle/Front 层 - 动画处理

```rust
// 动画瓦片索引会动态变化
let base_index = cell.middle_image;
let frame_offset = calculate_animation_frame(
    cell.middle_animation_frame,
    cell.middle_animation_tick,
    current_time
);

let animated_index = base_index + frame_offset;  // 实时计算
```

## 性能优化技巧

### 1. 批量加载

```rust
// ❌ 低效：逐个加载
for each_tile {
    let texture = load_texture(file_index, image_index);
    draw(texture);
}

// ✅ 高效：批量加载
let mut batch = Vec::new();
for each_tile {
    batch.push((file_index, image_index, x, y));
}
batch.sort_by_key(|(f, i, _, _)| (*f, *i));  // 按库和索引排序

for (file_index, image_index, x, y) in batch {
    let texture = load_texture(file_index, image_index);
    draw(texture);
}
```

### 2. 懒加载

```rust
// 只加载视口内的纹理
let visible_tiles = get_visible_tiles(camera, viewport);

for tile in visible_tiles {
    let texture = load_texture(tile.file_index, tile.image_index);
}
```

### 3. 使用 LRU 缓存

```rust
// 新资源管理器自动 LRU 缓存
resources::set_cache_size(2000, 1000);  // 缓存 2000 个纹理

// 自动淘汰最久未使用的纹理，内存可控
```

## 总结

地图纹理访问是一个 **二级索引** 系统：

```
格子 (x, y) 
  ↓
CellInfo { file_index, image_index }
  ↓
MapLibs[file_index]
  ↓
MLibrary.get_texture(image_index)
  ↓
Texture2D
```

关键点：
1. **file_index** 决定从哪个库加载 (0-399)
2. **image_index** 决定库中的哪个图像 (含标志位)
3. **Back 层** 2x2 共享，只在偶数坐标渲染
4. **Middle/Front 层** 支持动画，索引会动态变化
5. **使用 LRU 缓存** 提升性能，避免重复加载
