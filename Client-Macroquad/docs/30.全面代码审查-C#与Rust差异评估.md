## 2. 共享协议层 (Shared ↔ SharedRust)

### 2.1 枚举定义

| 类别 | C# | Rust | 差异 |
|------|-----|------|------|
| 标准枚举 (pub enum) | 61 | 52 | — |
| 位标志枚举 (bitflags!) | — | 10 | — |
| **总计** | **61** | **62** | Rust 多 StatFormula, Stat；使用 bitflags 实现 10 个 C# [Flags] 枚举 |

**C# 中未以 `pub enum` 形式出现但已通过 `bitflags!` 实现的类型（10 个）：**

- ✅ WeatherSetting — `bitflags! { pub struct WeatherSetting: u16 }`
- ✅ LevelEffects — `bitflags! { pub struct LevelEffects: u16 }`
- ✅ PoisonType — `bitflags! { pub struct PoisonType: u16 }`
- ✅ BindMode — `bitflags! { pub struct BindMode: u16 }`
- ✅ SpecialItemMode — `bitflags! { pub struct SpecialItemMode: u16 }`
- ✅ RequiredClass — `bitflags! { pub struct RequiredClass: u8 }`
- ✅ RequiredGender — `bitflags! { pub struct RequiredGender: u8 }`
- ✅ GuildRankOptions — `bitflags! { pub struct GuildRankOptions: u8 }`
- ✅ BuffProperty — `bitflags! { pub struct BuffProperty: u8 }`

**仅在 C# 中存在、Rust 未实现的枚举（1 个）：**

| 枚举名 | 影响 | 优先级 |
|--------|------|--------|
| GMOptions | GM 管理功能，非核心玩法 | P3 低 |

**结论**：SharedRust 枚举覆盖率 **98.4%**（61/62），且 bitflags 实现更符合 Rust 惯用法。

### 3.2 MapCode 关键差异

| 方面 | C# | Rust | 风险 |
|------|----|----|------|
| 瓦片索引 | 1-based (运行时减 1) | 1-based (helper 返回原值，调用方减 1) | ⚠️ 两个后端行为不同 |
| 对象存储 | `List<MapObject>` (完整对象) | `Option<Vec<u32>>` (仅 ID) | ✅ ECS 友好 |
| 障碍检测 | `(BackImage & 0x20000000) != 0` | `is_walkable()` 方法 | ✅ 更清晰 |

> **注意**：Client-Macroquad 的 map_loader 直接访问 `cell.back_image/middle_image/front_image` 并减 1；
> 而 macroquad 的 map_renderer 使用 `back_tile()/middle_tile()/front_tile()` helper 后减 1。
> 建议统一为 helper 调用方式。
