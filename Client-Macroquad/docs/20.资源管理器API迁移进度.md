## 🔄 迁移模式参考

### 1. UI 纹理加载（Macroquad 渲染）

```rust
// ❌ 旧方式（已废弃）
let info = get_or_create_texture(LibraryName::Items, 200)?;

// ✅ 新方式 1（推荐）- 使用便捷方法
let info = LibraryName::Items.get_texture(200)?;

// ✅ 新方式 2 - 使用全局函数
use resources::get_texture;
let info = get_texture(LibraryName::Items, 200)?;
```

### 2. egui 纹理加载

```rust
// ❌ 旧方式（已废弃，只返回 TextureHandle）
let handle = get_or_create_egui_texture(ctx, LibraryName::Items, 200)?;
ui.image(&handle);

// ✅ 新方式（推荐，返回完整 ImageInfo）
let info = LibraryName::Items.get_egui_texture(ctx, 200)?;
if let Some(handle) = &info.egui_texture {
    ui.image(handle);
    ui.label(format!("尺寸: {}x{}", info.width, info.height));
}
```

### 3. 地图纹理加载

```rust
// ❌ 旧方式（已废弃，需要 4 步）
let lib = get_map_library(file_index)?;
let mut lib_ref = lib.borrow_mut();
let info = lib_ref.get_or_create_texture(image_index as usize)?;
let texture = info.image.as_ref()?;
draw_texture_ex(texture, x, y, WHITE, params);

// ✅ 新方式（推荐，1 行搞定，自动 LRU 缓存）
use resources::get_map_texture;
let info = get_map_texture(file_index, image_index)?;
if let Some(texture) = &info.image {
    draw_texture_ex(texture, x, y, WHITE, params);
}
```

### 4. 尺寸查询

```rust
// ❌ 旧方式（已废弃）
let (w, h) = get_size(LibraryName::Items, 200)?;

// ✅ 新方式 1（推荐）
let (w, h) = LibraryName::Items.get_size(200)?;

// ✅ 新方式 2
use resources::get_size;
let (w, h) = get_size(LibraryName::Items, 200)?;
```

### 5. 获取库引用（高级用法）

```rust
// ❌ 旧方式（已废弃）
let lib = get_library(LibraryName::Items)?;

// ✅ 新方式 1（推荐）
let lib = LibraryName::Items.get_library()?;

// ✅ 新方式 2
use resources::get_library;
let lib = get_library(LibraryName::Items)?;
```
