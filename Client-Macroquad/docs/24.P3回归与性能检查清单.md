# Client-Macroquad P3 回归与性能检查清单

日期：2026-02-13  
适用范围：`Client-Macroquad`

> 目标：把 P3（质量与验收）从“建议”变成可执行清单，后续每次移植功能都按本清单做回归。

## 1. 回归清单（功能）

### 1.1 场景链路

- [ ] 启动到登录场景无崩溃
- [ ] 登录 -> 选角 -> 游戏场景可完成一次完整切换
- [ ] `ESC` 返回链路行为符合预期（含对话框阻塞逻辑）

### 1.2 常用 UI 对话框开关

- [ ] 主界面 `MainDialog` 可见且按钮可点击
- [ ] `BeltDialog` 可打开/关闭，布局切换正常
- [ ] `InventoryDialog` 可打开/关闭，分页切换正常
- [ ] `CharacterDialog` 可打开/关闭，标签切换正常
- [ ] `MiniMapDialog` 可打开/关闭，大小切换正常
- [ ] `MenuDialog`/`OptionDialog` 打开后不阻塞基础输入恢复

### 1.3 聊天与 NPC 交互

- [ ] `ChatDialog` 输入与发送（Enter）可用
- [ ] 聊天窗口大小切换（小/中/大）正常
- [ ] `NPCDialog` 打开与关闭正常
- [ ] `NPCGoodsDialog` 主窗口/子窗口层级与焦点行为正常

### 1.4 网络事件基础回归（Mock 或联机）

- [ ] 登录成功事件可驱动场景流转
- [ ] 断线事件有可见提示，且不会导致崩溃
- [ ] 进入游戏后地图/玩家基础状态可见

## 2. 性能与稳定性清单

- [ ] 游戏场景连续运行 10 分钟无崩溃
- [ ] 频繁开关对话框（>=50 次）无明显卡死/输入错乱
- [ ] 场景切换（登录/选角/游戏）循环 10 次无资源泄漏迹象
- [ ] Debug/日志无连续异常刷屏（可接受少量警告）

## 3. 执行与记录规范

### 3.1 执行频率

- 每完成一个 P1/P2 功能点，至少执行一次本清单“相关子集”
- 每周至少执行一次“全量清单”

## 4. 当前已知阻塞（执行前置）

- Linux 环境缺少 `wayland-client` 系统库时，`cargo test` 会在依赖构建阶段失败。
- 该问题属于环境依赖，不属于业务逻辑回归失败；执行前需先补齐系统依赖。
