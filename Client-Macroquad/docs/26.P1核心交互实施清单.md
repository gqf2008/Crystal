# Client-Macroquad P1 核心交互实施清单（Inventory / Character）

日期：2026-02-13

## 1. 目标

将 P1 从“方向性目标”细化为可执行子任务，优先完成：

1. `InventoryDialog`（物品图标/数量/拖拽最小闭环）
2. `CharacterDialog`（装备槽与基础属性可查看）

## 2. InventoryDialog（优先级：P1-High）

文件：`src/scenes/dialogs/game/inventory_dialog.rs`

### 2.1 子任务拆解

- [ ] **I1**：接入物品图标渲染（按格子索引显示）
- [ ] **I2**：接入物品数量文本（仅对可堆叠物品显示）
- [ ] **I3**：实现“拿起 -> 放下”拖拽基础流
- [ ] **I4**：实现“目标格已有物品时交换”逻辑
- [ ] **I5**：与 Belt 的最小互操作（背包格 <-> 快捷栏格）

### 2.2 验收标准

- [ ] 打开背包后可看到物品图标与数量
- [ ] 鼠标拖拽可完成同页格子内移动
- [ ] 冲突格子交换后状态一致，无丢失
- [ ] 背包与快捷栏之间至少支持单向或双向一次成功绑定

## 3. CharacterDialog（优先级：P1-High）

文件：`src/scenes/dialogs/game/character_dialog.rs`

### 3.1 子任务拆解

- [ ] **C1**：装备槽位可视化（空槽/占用）
- [ ] **C2**：基础属性面板（攻击/防御/魔法等）可展示
- [ ] **C3**：角色/技能标签切换数据稳定

### 3.2 验收标准

- [ ] 角色页可查看装备槽与基础属性
- [ ] 技能页可切换且不破坏角色页状态
- [ ] 频繁开关对话框后不出现输入焦点错乱

## 4. 实施顺序建议

1. 先完成 `I1 -> I2 -> I3`，拿到背包最小可用闭环
2. 再补 `I4 -> I5`，实现可操作性
3. 最后完成 `C1 -> C2 -> C3`

## 5. 回归要求（并入 P3）

- 每完成一个子任务，至少执行一次《24.P3回归与性能检查清单》的相关子集
- 在《25.P3回归执行记录》中追加一条执行记录（通过项/阻塞项/下次重点）
