# UI 焦点管理指南

## 概述

本文档详细说明了在 macroquad + egui 混合模式下如何正确管理多个 UI 组件的焦点和交互优先级，避免组件间相互遮挡和焦点丢失问题。

---

## 核心概念

### 1. egui 层级系统（Order）

egui 提供了 5 个渲染层级，从底到顶依次为：

```rust
pub enum Order {
    Background,  // 最底层 - 背景元素
    PanelResizeLine,
    Middle,      // 中间层 - 普通 UI
    Foreground,  // 前景层 - 需要优先交互的 UI
    Tooltip,     // 最顶层 - 提示信息
    Debug,       // 调试层
}
```

**关键原则**：
- 越上层的 UI 越优先接收输入事件（鼠标点击、键盘输入）
- 下层 UI 会被上层 UI 遮挡交互（即使视觉上可见）

### 2. egui 容器类型

#### Area（区域）
```rust
egui::Area::new(id)
    .fixed_pos(pos)           // 固定位置
    .movable(false)           // 是否可拖动
    .interactable(true)       // 是否可交互
    .order(egui::Order::Middle)  // 层级
    .show(ctx, |ui| { ... });
```

**特点**：
- 自由定位，不受布局约束
- 适合游戏界面的固定位置 UI
- 需要手动管理层级避免遮挡

#### Window（窗口）
```rust
egui::Window::new("title")
    .fixed_pos(pos)
    .resizable(false)
    .title_bar(false)
    .frame(egui::Frame::NONE)
    .order(egui::Order::Foreground)  // 注意：Window 也支持 order
    .show(ctx, |ui| { ... });
```

**特点**：
- 默认可拖动、可关闭
- 自带标题栏（可隐藏）
- 更适合临时弹窗和工具面板

## 项目中的层级架构

### 当前层级分配

```
┌─────────────────────────────────────────┐
│  Tooltip (最顶层)                       │  提示信息、调试面板
├─────────────────────────────────────────┤
│  Foreground (前景层)                    │  ChatDialog (聊天窗口)
│                                         │  ChatControlBar (聊天控制栏)
│                                         │  BeltDialog (快捷栏)
├─────────────────────────────────────────┤
│  Middle (中间层)                        │  MainDialog (主界面底栏)
│                                         │  其他功能按钮
├─────────────────────────────────────────┤
│  Background (底层)                      │  游戏场景背景
│                                         │  地图渲染
└─────────────────────────────────────────┘
```

### 为什么这样分配？

1. **MainDialog 在 Middle 层**
   - 底部工具栏是静态背景，不需要频繁交互
   - 让聊天系统优先获取焦点，提升用户体验
   
2. **ChatDialog/ChatControlBar 在 Foreground 层**
   - 聊天输入框需要频繁获取键盘焦点
   - 频道切换按钮需要优先响应点击
   - 滚动条拖动需要高优先级事件处理

3. **BeltDialog 在 Foreground 层**
   - 快捷栏按钮需要快速响应（战斗中使用）
   - 避免被其他 UI 遮挡点击

## 常见问题及解决方案

### 问题 1：输入框无法获取焦点

**症状**：
- 点击输入框没有光标
- 无法输入文字
- 按键没有响应

**原因**：
- 输入框所在的 Area/Window 层级过低
- 被其他高层级的 UI 遮挡了交互

**解决方案**：
```rust
// ❌ 错误：Background 层级太低
egui::Area::new(egui::Id::new("chat_dialog"))
    .order(egui::Order::Background)  // 被 Middle 层的 MainDialog 遮挡
    .show(ctx, |ui| {
        ui.text_edit_singleline(&mut self.input_text);
    });

// ✅ 正确：提升到 Foreground
egui::Area::new(egui::Id::new("chat_dialog"))
    .order(egui::Order::Foreground)  // 优先接收输入事件
    .show(ctx, |ui| {
        ui.text_edit_singleline(&mut self.input_text);
    });
```

### 问题 2：按钮无法点击

**症状**：
- 鼠标悬停有效果，但点击无响应
- 其他 UI 的按钮可以点击

**原因**：
- 按钮上方有透明的高层级 UI 遮挡
- 按钮所在区域被 `allocate_rect` 占用了交互

**解决方案 A：调整层级**
```rust
// ❌ 错误：按钮在 Middle，被 Foreground 的透明区域遮挡
egui::Window::new("toolbar")
    .order(egui::Order::Middle)
    .show(ctx, |ui| {
        if ui.button("按钮").clicked() { ... }
    });

// ✅ 正确：提升到 Foreground 或移除上层遮挡
egui::Window::new("toolbar")
    .order(egui::Order::Foreground)
    .show(ctx, |ui| {
        if ui.button("按钮").clicked() { ... }
    });
```

**解决方案 B：移除不必要的 allocate_rect**
```rust
// ❌ 错误：占用了整个背景区域的交互
let bg_rect = egui::Rect::from_min_size(pos, size);
ui.painter().image(...);  // 绘制背景
ui.allocate_rect(bg_rect, egui::Sense::hover());  // ← 阻止了底层按钮响应

// ✅ 正确：只绘制纹理，不占用交互
let bg_rect = egui::Rect::from_min_size(pos, size);
ui.painter().image(...);  // 只绘制，不 allocate
// 让下层的按钮自己处理交互
```

### 问题 3：拖动滑块时其他 UI 也响应

**症状**：
- 拖动滚动条时，下方的按钮也被触发
- 多个 UI 同时响应一次点击

**原因**：
- 事件没有被正确消费（consumed）
- 多个 UI 在同一位置都设置了 `Sense::click()`

**解决方案**：
```rust
// ✅ 使用 click_and_drag 提高优先级
let response = ui.interact(
    rect,
    id,
    egui::Sense::click_and_drag(),  // 拖动事件优先级高于普通点击
);

if response.dragged() {
    // 处理拖动
    // egui 会自动消费事件，下层 UI 不会收到
}

// ✅ 检查是否已被消费
if !ctx.wants_pointer_input() {
    // 只有当上层 UI 不需要鼠标输入时才处理
    handle_background_click();
}
```

### 问题 4：多个输入框焦点冲突

**症状**：
- 同时存在多个输入框时，焦点跳来跳去
- 输入的字符出现在错误的输入框

**原因**：
- 输入框没有唯一的 ID
- 多个输入框自动抢夺焦点

**解决方案**：
```rust
// ❌ 错误：ID 重复或自动生成
ui.text_edit_singleline(&mut self.text);  // 可能生成相同 ID

// ✅ 正确：手动指定唯一 ID
let response = egui::TextEdit::singleline(&mut self.text)
    .id(egui::Id::new("chat_input_main"))  // 唯一标识
    .show(ui);

// ✅ 控制焦点获取时机
if user_clicked_input_box && !response.has_focus() {
    response.request_focus();  // 主动请求焦点
}

// ✅ 避免自动获取焦点
if response.gained_focus() {
    println!("输入框获得焦点");  // 调试用
}
```

## 最佳实践

### 1. 层级分配原则

```rust
// 从底到顶的推荐分配：
Background    → 游戏场景、地图渲染（纯视觉，无交互）
Middle        → 静态 UI 背景、信息展示面板
Foreground    → 输入框、按钮、可交互控件
Tooltip       → 鼠标悬停提示、临时通知
Debug         → 调试信息面板
```

### 2. 组件创建模板

#### 无交互的背景面板
```rust
egui::Area::new(egui::Id::new("background_panel"))
    .fixed_pos(pos)
    .movable(false)
    .interactable(false)  // 完全不接收输入
    .order(egui::Order::Background)
    .show(ctx, |ui| {
        // 纯绘制，不占用交互
        ui.painter().image(...);
        ui.painter().text(...);
        // 不使用 allocate_rect
    });
```

#### 有按钮的工具栏
```rust
egui::Area::new(egui::Id::new("toolbar"))
    .fixed_pos(pos)
    .movable(false)
    .interactable(true)   // 需要接收输入
    .order(egui::Order::Middle)  // 普通优先级
    .show(ctx, |ui| {
        ui.horizontal(|ui| {
            if ui.button("按钮1").clicked() { ... }
            if ui.button("按钮2").clicked() { ... }
        });
    });
```

#### 需要输入的对话框
```rust
egui::Window::new("chat")
    .fixed_pos(pos)
    .title_bar(false)
    .resizable(false)
    .frame(egui::Frame::NONE)
    .order(egui::Order::Foreground)  // 高优先级
    .show(ctx, |ui| {
        // 输入框
        let response = egui::TextEdit::singleline(&mut self.text)
            .id(egui::Id::new("unique_input_id"))
            .show(ui);
        
        // 按钮
        if ui.button("发送").clicked() { ... }
    });
```

### 3. 调试焦点问题的方法

#### 启用 egui 调试面板
```rust
// 在主循环中添加
#[cfg(debug_assertions)]
egui::Window::new("🔍 egui 调试")
    .order(egui::Order::Debug)
    .show(ctx, |ui| {
        // 显示焦点状态
        ui.label(format!("鼠标位置: {:?}", ctx.pointer_latest_pos()));
        ui.label(format!("是否悬停 UI: {}", ctx.is_pointer_over_area()));
        ui.label(format!("键盘焦点: {:?}", ctx.memory(|m| m.focused())));
        
        // 显示所有 Area 的层级
        ctx.memory(|m| {
            for (id, layer_id) in m.areas().order() {
                ui.label(format!("{:?}: {:?}", id, layer_id));
            }
        });
    });
```

#### 打印焦点事件
```rust
let response = ui.text_edit_singleline(&mut self.text);

if response.gained_focus() {
    println!("✅ 输入框获得焦点");
}
if response.lost_focus() {
    println!("❌ 输入框失去焦点");
}
if response.has_focus() {
    println!("📝 输入框当前有焦点");
}
```

#### 可视化层级
```rust
// 给不同层级的 UI 添加调试边框
#[cfg(debug_assertions)]
ui.painter().rect_stroke(
    rect,
    0.0,
    egui::Stroke::new(2.0, egui::Color32::RED),  // 红色边框 = Foreground
);
```

## 特殊场景处理

### 场景 1：模态对话框（Modal Dialog）

需要阻止其他所有 UI 的交互：

```rust
pub struct ModalDialog {
    visible: bool,
}

impl ModalDialog {
    pub fn show(&mut self, ctx: &egui::Context) {
        if !self.visible {
            return;
        }
        
        // 1. 绘制半透明遮罩层（阻止底层交互）
        egui::Area::new(egui::Id::new("modal_overlay"))
            .fixed_pos(egui::pos2(0.0, 0.0))
            .movable(false)
            .interactable(true)  // 消费所有点击事件
            .order(egui::Order::Foreground)
            .show(ctx, |ui| {
                let screen_size = ctx.screen_rect().size();
                let overlay_rect = egui::Rect::from_min_size(
                    egui::pos2(0.0, 0.0),
                    screen_size,
                );
                ui.painter().rect_filled(
                    overlay_rect,
                    0.0,
                    egui::Color32::from_black_alpha(128),  // 半透明黑色
                );
                ui.allocate_rect(overlay_rect, egui::Sense::click());  // 消费点击
            });
        
        // 2. 在遮罩层上方显示对话框
        egui::Window::new("确认")
            .anchor(egui::Align2::CENTER_CENTER, egui::vec2(0.0, 0.0))
            .resizable(false)
            .order(egui::Order::Tooltip)  // 比遮罩层更高
            .show(ctx, |ui| {
                ui.label("确定要执行此操作吗？");
                ui.horizontal(|ui| {
                    if ui.button("确定").clicked() {
                        self.visible = false;
                        // 执行操作
                    }
                    if ui.button("取消").clicked() {
                        self.visible = false;
                    }
                });
            });
    }
}
```

### 场景 2：上下文菜单（Context Menu）

右键弹出菜单，需要临时最高优先级：

```rust
pub struct ContextMenu {
    visible: bool,
    position: egui::Pos2,
}

impl ContextMenu {
    pub fn show(&mut self, ctx: &egui::Context) {
        if !self.visible {
            return;
        }
        
        egui::Area::new(egui::Id::new("context_menu"))
            .fixed_pos(self.position)
            .movable(false)
            .interactable(true)
            .order(egui::Order::Tooltip)  // 最高优先级
            .show(ctx, |ui| {
                egui::Frame::menu(ui.style())
                    .show(ui, |ui| {
                        if ui.button("复制").clicked() {
                            self.visible = false;
                        }
                        if ui.button("粘贴").clicked() {
                            self.visible = false;
                        }
                        if ui.button("删除").clicked() {
                            self.visible = false;
                        }
                    });
            });
        
        // 点击其他地方关闭菜单
        if ctx.input(|i| i.pointer.any_click()) {
            if let Some(pos) = ctx.pointer_interact_pos() {
                // 检查点击是否在菜单外
                if !ui.rect_contains_pointer(menu_rect) {
                    self.visible = false;
                }
            }
        }
    }
}
```

### 场景 3：可拖动的浮动面板

支持拖动但不影响其他 UI：

```rust
pub struct FloatingPanel {
    position: egui::Pos2,
    dragging: bool,
    drag_offset: egui::Vec2,
}

impl FloatingPanel {
    pub fn show(&mut self, ctx: &egui::Context) {
        let panel_id = egui::Id::new("floating_panel");
        
        egui::Area::new(panel_id)
            .fixed_pos(self.position)
            .movable(false)  // 手动处理拖动
            .interactable(true)
            .order(egui::Order::Foreground)
            .show(ctx, |ui| {
                egui::Frame::window(ui.style())
                    .show(ui, |ui| {
                        // 标题栏（可拖动区域）
                        let title_response = ui.horizontal(|ui| {
                            ui.label("浮动面板");
                        }).response;
                        
                        // 处理拖动
                        if title_response.drag_started() {
                            self.dragging = true;
                            if let Some(pos) = ctx.pointer_interact_pos() {
                                self.drag_offset = pos - self.position.to_vec2();
                            }
                        }
                        
                        if self.dragging {
                            if let Some(pos) = ctx.pointer_latest_pos() {
                                self.position = (pos.to_vec2() - self.drag_offset).to_pos2();
                            }
                            
                            if title_response.drag_stopped() {
                                self.dragging = false;
                            }
                        }
                        
                        // 面板内容
                        ui.separator();
                        ui.label("这是面板内容");
                        if ui.button("关闭").clicked() {
                            // 关闭面板
                        }
                    });
            });
    }
}
```

## 性能优化建议

### 1. 避免过度 allocate_rect

```rust
// ❌ 不好：每帧都 allocate 大量矩形
for i in 0..1000 {
    let rect = egui::Rect::from_min_size(...);
    ui.allocate_rect(rect, egui::Sense::hover());
}

// ✅ 好：只在需要交互时 allocate
for (i, item) in visible_items.iter().enumerate() {
    let rect = egui::Rect::from_min_size(...);
    if item.is_interactive {
        ui.allocate_rect(rect, egui::Sense::click());
    }
}
```

### 2. 缓存纹理 ID

```rust
// ❌ 不好：每帧都查询纹理
ui.painter().image(
    LibraryName::Prguse.get_egui_texture(ctx, 100).unwrap().id(),
    rect,
    ...
);

// ✅ 好：缓存纹理 ID
struct MyUI {
    cached_texture_id: Option<egui::TextureId>,
}

impl MyUI {
    fn draw(&mut self, ui: &mut egui::Ui, ctx: &egui::Context) {
        if self.cached_texture_id.is_none() {
            if let Some(info) = LibraryName::Prguse.get_egui_texture(ctx, 100) {
                self.cached_texture_id = Some(info.egui_texture.unwrap().id());
            }
        }
        
        if let Some(id) = self.cached_texture_id {
            ui.painter().image(id, rect, ...);
        }
    }
}
```

### 3. 延迟创建复杂 UI

```rust
// ✅ 只在可见时创建
impl ComplexPanel {
    pub fn show(&mut self, ctx: &egui::Context) {
        if !self.visible {
            return;  // 早期返回，不执行任何绘制
        }
        
        egui::Window::new("复杂面板")
            .show(ctx, |ui| {
                // 复杂的 UI 逻辑
            });
    }
}
```

## 总结

### 关键要点

1. **合理分配层级**：输入控件 > 按钮 > 静态背景
2. **避免过度占用交互**：只在必要时使用 `allocate_rect`
3. **唯一 ID**：所有 Area/Window/Widget 都应有唯一标识
4. **调试优先**：使用调试面板和日志排查焦点问题
5. **性能意识**：缓存纹理、延迟创建、避免过度绘制

### 快速检查清单

- [ ] 所有 Area/Window 都设置了明确的 `order()`
- [ ] 输入框所在容器的层级 ≥ Foreground
- [ ] 没有大面积的 `allocate_rect` 阻止底层交互
- [ ] 所有 TextEdit 都有唯一的 ID
- [ ] 拖动操作使用 `Sense::click_and_drag()`
- [ ] 模态对话框使用遮罩层阻止底层交互
- [ ] 调试时启用了焦点状态打印
