# 新资源管理器使用指南

## 概述

新的 `ResourceManager` 提供了一个高性能、简洁的资源管理解决方案，具有以下特性：

- ✅ **简洁高效**：API 简单直观，性能优化
- ✅ **LRU缓存**：自动管理纹理缓存，防止内存溢出
- ✅ **无锁设计**：使用 RefCell 实现单线程高效访问
- ✅ **懒加载**：按需加载资源，减少启动时间
- ✅ **便捷函数**：全局函数直接调用，无需管理实例

## 快速开始

### 1. 基本设置

```rust
use client_macroquad::resources;

// 设置数据路径（应用启动时调用一次）
resources::set_data_path("Data");

// 可选：设置缓存大小（纹理数量，egui纹理数量）
resources::set_cache_size(2000, 1000);
```

### 2. 加载纹理

#### 方式A：获取 Macroquad 纹理

```rust
use client_macroquad::resources::{LibraryName, get_texture};

// 获取纹理（自动缓存）
if let Some(info) = get_texture(LibraryName::Prguse, 100) {
    if let Some(texture) = &info.image {
        // 使用 macroquad 纹理绘制
        draw_texture_ex(
            texture,
            x,
            y,
            WHITE,
            DrawTextureParams {
                dest_size: Some(vec2(info.width as f32, info.height as f32)),
                ..Default::default()
            },
        );
    }
}
```

#### 方式B：获取 egui 纹理

```rust
use client_macroquad::resources::{LibraryName, get_egui_texture};

// 在 egui UI 中
egui::Window::new("Test").show(ctx, |ui| {
    if let Some(handle) = get_egui_texture(ctx, LibraryName::ChrSel, 50) {
        ui.image(&handle);
    }
});
```

### 3. 获取图像尺寸（无需加载纹理）

```rust
use client_macroquad::resources::{LibraryName, get_size};

// 高效获取尺寸，不创建纹理
if let Some((width, height)) = get_size(LibraryName::Items, 200) {
    println!("图像尺寸: {}x{}", width, height);
}
```

### 4. 地图库访问

```rust
use client_macroquad::resources::get_map_library;

// 直接获取地图库
if let Some(map_lib) = get_map_library(0) {
    let mut lib = map_lib.borrow_mut();
    // 使用地图库...
}
```

### 5. 数组库管理

```rust
use client_macroquad::resources::{LibraryArray, init_array, load_to_array, get_from_array};

// 初始化数组库
init_array(LibraryArray::Monsters, 1000);

// 加载单个库到数组
load_to_array(LibraryArray::Monsters, 0, "Data/Monster/000.lib").ok();

// 获取数组库元素
if let Some(monster_lib) = get_from_array(LibraryArray::Monsters, 0) {
    // 使用怪物库...
}
```

### 6. 缓存管理

```rust
use client_macroquad::resources::{cache_stats, clear_cache};

// 获取缓存统计
let stats = cache_stats();
println!("纹理缓存: {}/{}", stats.texture_cache_size, stats.texture_cache_capacity);
println!("egui缓存: {}/{}", stats.egui_cache_size, stats.egui_cache_capacity);
println!("已加载库: {}", stats.loaded_libraries);

// 清空缓存（例如切换场景时）
clear_cache();
```

### 7. 预加载（可选优化）

```rust
use client_macroquad::resources::{LibraryName, preload_libraries};

// 在后台预加载常用库
let common_libs = vec![
    LibraryName::Prguse,
    LibraryName::Title,
    LibraryName::ChrSel,
    LibraryName::Items,
];

preload_libraries(&common_libs);
```

## 性能优化技巧

### 1. LRU 缓存自动管理

新的资源管理器使用 LRU（最近最少使用）算法自动淘汰不常用的纹理，您不需要手动管理：

```rust
// ❌ 旧方式：需要手动清理
old_library.clear_texture_cache();

// ✅ 新方式：自动管理，只需设置合适的缓存大小
set_cache_size(1000, 500);  // 根据可用内存调整
```

### 2. 按需加载

库在首次访问时自动加载，无需预先加载所有资源：

```rust
// ✅ 懒加载：只在需要时加载
let texture = get_texture(LibraryName::Magic, 100);
```

### 3. 批量预加载

对于已知会用到的资源，可以在空闲时预加载：

```rust
// 游戏启动时预加载核心资源
std::thread::spawn(|| {
    preload_libraries(&[
        LibraryName::Prguse,
        LibraryName::Items,
        LibraryName::Magic,
    ]);
});
```

## 完整示例

### 登录场景

```rust
use macroquad::prelude::*;
use egui_macroquad::egui;
use client_macroquad::resources::{self, LibraryName};

struct LoginScene {
    // 不需要存储纹理句柄，直接从缓存获取
}

impl LoginScene {
    fn new() -> Self {
        // 初始化资源管理器
        resources::set_data_path("Data");
        resources::set_cache_size(1000, 500);
        
        Self {}
    }
    
    fn draw(&self, ctx: &egui::Context) {
        // 绘制背景
        if let Some(bg_handle) = resources::get_egui_texture(ctx, LibraryName::ChrSel, 0) {
            egui::CentralPanel::default().show(ctx, |ui| {
                ui.image(&bg_handle);
            });
        }
        
        // 绘制UI元素
        egui::Window::new("Login").show(ctx, |ui| {
            if let Some(logo) = resources::get_egui_texture(ctx, LibraryName::Title, 100) {
                ui.image(&logo);
            }
            
            // ... 其他UI
        });
    }
}
```

### 游戏场景

```rust
use macroquad::prelude::*;
use client_macroquad::resources::{self, LibraryName};

struct GameScene {
    player_pos: Vec2,
}

impl GameScene {
    fn draw(&self) {
        // 绘制玩家
        if let Some(info) = resources::get_texture(LibraryName::CHumEffect(0), 50) {
            if let Some(texture) = &info.image {
                draw_texture_ex(
                    texture,
                    self.player_pos.x - info.offset_x as f32,
                    self.player_pos.y - info.offset_y as f32,
                    WHITE,
                    DrawTextureParams {
                        dest_size: Some(vec2(info.width as f32, info.height as f32)),
                        ..Default::default()
                    },
                );
            }
        }
    }
}
```

## 常见问题

### Q: 如何控制内存使用？

A: 通过设置缓存大小来控制：

```rust
// 低内存设备
resources::set_cache_size(500, 250);

// 高内存设备
resources::set_cache_size(2000, 1000);
```

### Q: 如何强制重新加载资源？

A: 清空缓存后重新获取：

```rust
resources::clear_cache();
let texture = resources::get_texture(LibraryName::Items, 100);
```

### Q: 多线程安全吗？

A: 使用 `thread_local!` 实现，每个线程有独立实例，无需担心线程安全问题。

### Q: LRU 如何工作？

A: 当缓存满时，自动淘汰最久未使用的纹理。使用频繁的纹理会保持在缓存中。

## 总结

新的 `ResourceManager` 提供了：

1. **更简洁的API**：全局函数，无需管理实例
2. **自动内存管理**：LRU 缓存防止内存溢出
3. **更高性能**：优化的数据结构和缓存策略
4. **更易维护**：清晰的代码结构

推荐在新项目中使用 `ResourceManager`，旧代码可以逐步迁移。
