# 资源管理器快速参考

## 初始化

```rust
use client_macroquad::resources::{self, LibraryName};

// 设置数据路径
resources::set_data_path("Data");

// 设置缓存大小（可选）
resources::set_cache_size(1000, 500);
```

## 核心 API

### 加载纹理

```rust
// Macroquad 纹理
let info = resources::get_texture(LibraryName::Prguse, 100)?;

// egui 纹理
let handle = resources::get_egui_texture(ctx, LibraryName::ChrSel, 0)?;

// 仅获取尺寸（高效）
let (w, h) = resources::get_size(LibraryName::Items, 200)?;
```

### 数组库

```rust
// 初始化数组
resources::init_array(LibraryArray::Monsters, 1000);

// 加载到数组
resources::load_to_array(LibraryArray::Monsters, 0, "Data/Monster/000.lib")?;

// 获取数组元素
let lib = resources::get_from_array(LibraryArray::Monsters, 0)?;

// 地图库快捷方式
let map_lib = resources::get_map_library(0)?;
```

### 缓存管理

```rust
// 获取统计
let stats = resources::cache_stats();

// 清空缓存
resources::clear_cache();

// 预加载
resources::preload_libraries(&[LibraryName::Prguse, LibraryName::Items]);
```

## 使用示例

### Macroquad 渲染

```rust
if let Some(info) = resources::get_texture(LibraryName::Prguse, 100) {
    if let Some(texture) = &info.image {
        draw_texture_ex(
            texture,
            x - info.offset_x as f32,
            y - info.offset_y as f32,
            WHITE,
            DrawTextureParams {
                dest_size: Some(vec2(info.width as f32, info.height as f32)),
                ..Default::default()
            },
        );
    }
}
```

### egui 渲染

```rust
egui::Window::new("UI").show(ctx, |ui| {
    if let Some(handle) = resources::get_egui_texture(ctx, LibraryName::ChrSel, 0) {
        ui.image(&handle);
    }
});
```

## 性能提示

### 缓存大小建议

```rust
// 低内存 (< 2GB)
resources::set_cache_size(500, 250);

// 中等内存 (2-4GB)
resources::set_cache_size(1000, 500);

// 高内存 (> 4GB)
resources::set_cache_size(2000, 1000);
```

### 预加载策略

```rust
// 启动时预加载核心资源
let core = vec![LibraryName::Prguse, LibraryName::Title, LibraryName::ChrSel];
resources::preload_libraries(&core);

// 切换场景时预加载
match next_scene {
    Scene::Login => resources::preload_libraries(&[LibraryName::ChrSel]),
    Scene::Game => resources::preload_libraries(&[LibraryName::Items, LibraryName::Magic]),
}
```

### 缓存清理时机

```rust
// 场景切换时
fn change_scene(&mut self, new_scene: Scene) {
    resources::clear_cache();  // 清空旧场景资源
    self.scene = new_scene;
}

// 内存压力时
if memory_pressure() {
    resources::clear_cache();
}
```

## 故障排除

### 纹理未加载

```rust
// 检查数据路径
resources::set_data_path("Data");  // 确保路径正确

// 检查库名和索引
if let Some(info) = resources::get_texture(lib, idx) {
    println!("✓ 加载成功");
} else {
    println!("✗ 加载失败 - 检查库和索引");
}
```

### 内存使用过高

```rust
// 减小缓存大小
resources::set_cache_size(500, 250);

// 主动清理
resources::clear_cache();

// 监控使用情况
let stats = resources::cache_stats();
println!("缓存使用: {}/{}", stats.texture_cache_size, stats.texture_cache_capacity);
```
