## 5. 执行原则

1. **ClientRust 优先复用**：凡 ClientRust 已实现的对话框/Handler，优先参考迁移，避免重复开发
2. **按业务链完整交付**：每个对话框连带所需 Handler + UI 控件一起交付，不做半成品
3. **回归保障**：每完成一个阶段任务，执行《24.P3回归与性能检查清单》对应子集
4. **进度同步**：每周更新《23.对话框移植台账》和本计划的完成状态
