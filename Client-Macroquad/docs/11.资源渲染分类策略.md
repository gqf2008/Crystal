# 资源渲染分类设计

## 核心原则

传奇2 的资源按用途分为两大类，需要不同的渲染策略：

| 资源类型 | 用途 | 渲染方式 | egui 支持 |
|---------|------|----------|-----------|
| **UI 资源** | 界面显示、物品图标、角色头像等 | egui + Macroquad | ✅ 需要 |
| **地图资源** | 游戏世界瓦片渲染 | 仅 Macroquad | ❌ 不需要 |

## 资源分类

### 1. UI 资源（需要 egui 支持）

这些资源用于用户界面显示，需要在 egui 窗口中渲染：

```rust
// UI 库
LibraryName::Prguse      // 主界面元素（按钮、窗口、边框等）
LibraryName::Prguse2     // 扩展界面元素
LibraryName::Prguse3     // 更多界面元素

// 角色选择
LibraryName::ChrSel      // 角色选择界面

// 物品
LibraryName::Items       // 物品图标
LibraryName::StateItems  // 状态物品
LibraryName::FloorItems  // 地面物品

// 界面装饰
LibraryName::Title       // 标题界面
LibraryName::Deco        // 装饰物
```

**API：**
```rust
// ✅ 返回包含 egui_texture 的 ImageInfo
let info = get_egui_texture(ctx, LibraryName::Prguse, 0)?;
if let Some(handle) = &info.egui_texture {
    ui.image(handle);
}

// 或使用便捷方法
let info = LibraryName::Items.get_egui_texture(ctx, 200)?;
```

### 2. 地图资源（仅 Macroquad 渲染）

这些资源用于游戏世界渲染，只需要 Macroquad 纹理：

```rust
// 地图瓦片库（400个文件，索引 0-399）
LibraryArray::MapLibs

// 具体分布：
// 0-99:   盛大 Mir2
// 100-199: WeMade Mir2  
// 200-299: 盛大 Mir3
// 300-399: WeMade Mir3
```

**API：**
```rust
// ✅ 仅返回 Macroquad 纹理（不包含 egui_texture）
let info = get_map_texture(file_index, image_index)?;
if let Some(texture) = &info.image {
    draw_texture_ex(texture, x, y, WHITE, params);
}
```

## 为什么地图不需要 egui？

### 1. **渲染场景不同**

```rust
// ❌ 错误：地图不应该在 egui 中渲染
egui::Window::new("Map").show(ctx, |ui| {
    // 地图有成千上万个瓦片，egui 不适合游戏世界渲染
    for tile in tiles {
        ui.image(&tile_texture); // 性能极差！
    }
});

// ✅ 正确：地图在 Macroquad 中高性能渲染
for tile in visible_tiles {
    let info = get_map_texture(tile.file_index, tile.image_index)?;
    if let Some(texture) = &info.image {
        draw_texture_ex(texture, x, y, WHITE, params);
    }
}
```

### 2. **性能考虑**

| 方面 | Macroquad 渲染 | egui 渲染 |
|------|----------------|-----------|
| **批量绘制** | ✅ 支持（GPU 加速） | ❌ 每个控件单独绘制 |
| **瓦片数量** | ✅ 数千个无压力 | ❌ 超过100个卡顿 |
| **自定义着色器** | ✅ 完全支持 | ❌ 不支持 |
| **世界坐标系** | ✅ 原生支持 | ❌ 需要转换 |

### 3. **内存开销**

```
假设地图 700x700，可见区域 20x15 = 300 个瓦片

Macroquad 渲染：
- 纹理缓存: 300 * ImageInfo ≈ 30 KB
- GPU 纹理: 由显卡管理

egui 渲染（不推荐）：
- 纹理缓存: 300 * ImageInfo ≈ 30 KB
- egui TextureHandle: 300 * 24 bytes ≈ 7 KB
- egui 内部缓存: 额外开销
总计: 多消耗 ~10-20 KB + CPU 开销
```

## 混合渲染场景

### 场景 1: 物品图标（UI 资源）

在背包界面显示物品，需要 egui：

```rust
egui::Window::new("背包").show(ctx, |ui| {
    for item in inventory {
        // ✅ 使用 UI 库的 egui 支持
        if let Some(info) = LibraryName::Items.get_egui_texture(ctx, item.icon_id) {
            if let Some(handle) = &info.egui_texture {
                ui.image(handle);
            }
        }
    }
});
```

### 场景 2: 地图调试工具（特殊情况）

如果真的需要在 egui 中预览地图瓦片（仅调试）：

```rust
// 方法 1: 手动转换（不推荐，性能差）
fn preview_map_tile_slow(ctx: &egui::Context, file_idx: i16, img_idx: i32) {
    let info = get_map_texture(file_idx, img_idx)?;
    let texture = info.image.as_ref()?;
    
    // 手动转换为 egui 纹理（临时使用）
    let image_data = texture.get_texture_data();
    let width = texture.width() as usize;
    let height = texture.height() as usize;
    
    let mut pixels = Vec::new();
    for y in 0..height {
        for x in 0..width {
            let idx = (y * width + x) * 4;
            pixels.push(egui::Color32::from_rgba_unmultiplied(
                image_data.bytes[idx],
                image_data.bytes[idx + 1],
                image_data.bytes[idx + 2],
                image_data.bytes[idx + 3],
            ));
        }
    }
    
    let handle = ctx.load_texture(
        &format!("map_{}_{}", file_idx, img_idx),
        egui::ColorImage { size: [width, height], pixels },
        Default::default()
    );
    
    ui.image(&handle);
}

// 方法 2: 仅显示元数据（推荐）
fn preview_map_tile_info(ctx: &egui::Context, file_idx: i16, img_idx: i32) {
    egui::Window::new("地图瓦片信息").show(ctx, |ui| {
        if let Some((w, h)) = get_map_size(file_idx, img_idx) {
            ui.label(format!("库索引: {}", file_idx));
            ui.label(format!("图像索引: {}", img_idx));
            ui.label(format!("尺寸: {}x{}", w, h));
            ui.label("💡 预览请在游戏世界中查看");
        }
    });
}
```

## API 使用指南

### UI 资源（egui + Macroquad）

```rust
// 1. 获取带 egui 纹理的 ImageInfo
let info = get_egui_texture(ctx, LibraryName::Prguse, 0)?;

// 2. egui 中渲染
if let Some(handle) = &info.egui_texture {
    ui.image(handle);
}

// 3. 或在 Macroquad 中渲染（混合使用）
if let Some(texture) = &info.image {
    draw_texture(texture, x, y, WHITE);
}

// 4. 使用便捷方法
let info = LibraryName::Items.get_egui_texture(ctx, 200)?;
```

### 地图资源（仅 Macroquad）

```rust
// 1. 获取 Macroquad 纹理
let info = get_map_texture(file_index, image_index)?;

// 2. 游戏世界渲染
if let Some(texture) = &info.image {
    draw_texture_ex(
        texture,
        x - info.x as f32,  // 使用偏移
        y - info.y as f32,
        WHITE,
        params,
    );
}

// 3. 高效获取尺寸（无需加载纹理）
if let Some((w, h)) = get_map_size(file_index, image_index) {
    println!("瓦片尺寸: {}x{}", w, h);
}
```

## 缓存配置建议

```rust
// 初始化时设置缓存大小
resources::set_cache_size(
    2000,  // Macroquad 纹理缓存（地图 + 游戏实体）
    500    // egui 纹理缓存（仅 UI 资源）
);

// 推荐配置：
// - Macroquad 缓存 > egui 缓存（地图瓦片更多）
// - 小地图: 1000 Macroquad + 300 egui
// - 中等地图: 2000 Macroquad + 500 egui  
// - 大地图: 3000 Macroquad + 800 egui
```

## 总结

| 特性 | UI 资源 | 地图资源 |
|------|---------|----------|
| **主要用途** | 界面显示 | 游戏世界 |
| **渲染引擎** | egui + Macroquad | 仅 Macroquad |
| **egui_texture** | ✅ 需要 | ❌ 不需要 |
| **API** | `get_egui_texture()` | `get_map_texture()` |
| **数量** | 少（数十到数百） | 多（数千） |
| **更新频率** | 低（界面切换） | 高（每帧渲染） |
| **缓存策略** | 小缓存 | 大缓存 |

**设计哲学：让合适的工具做合适的事！**
- egui：专注于工具界面和调试 UI
- Macroquad：专注于高性能游戏世界渲染
