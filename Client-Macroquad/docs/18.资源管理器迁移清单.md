### 步骤 2: 迁移 UI 资源

**旧代码：**


- [ ] 测试通过

### 步骤 3: 迁移 egui 渲染

**旧代码：**
```rust
let lib = get_library(LibraryName::Items)?;

// ... 手动转换为 egui ...
```

**新代码：**
```rust
let info = LibraryName::Items.get_egui_texture(ctx, index)?;
if let Some(handle) = &info.egui_texture {
    ui.image(handle);
}
```

- [ ] 已迁移所有 egui 渲染
- [ ] 测试通过

```rust
fn main() {
    // 设置数据路径
    resources::set_data_path("Data");
    
    // 配置缓存大小（根据场景调整）
    resources::set_cache_size(2000, 500);  // Macroquad, egui
    
    // ... 其他初始化 ...
}
```

- [ ] 已添加初始化配置
- [ ] 已根据场景调整缓存大小

### 缓存大小参考

| 场景 | Macroquad 缓存 | egui 缓存 |
|------|----------------|-----------|
| 小地图 (< 100x100) | 1000 | 300 |
| 中等地图 (100x300) | 2000 | 500 |
| 大地图 (> 300x300) | 3000 | 800 |
| 调试场景（大量 UI） | 1500 | 1000 |

- [ ] 已选择合适的缓存配置
