# 地图纹理便捷访问 API

## 概述

新增了三个便捷函数，让地图纹理加载从 **4 行代码简化为 1 行**。

## 新增函数

地图纹理专门用于游戏世界渲染（Macroquad），不需要 egui 支持。

### 1. `get_map_texture()` - 获取地图纹理（推荐）

**最常用的函数，推荐使用！**

```rust
pub fn get_map_texture(file_index: i16, image_index: i32) -> Option<ImageInfo>
```

#### 对比

```rust
// ❌ 旧方式 - 4 行代码
let lib = get_map_library(file_index)?;
let mut lib_guard = lib.borrow_mut();
let info = lib_guard.get_or_create_texture(image_index as usize)?;
let texture = info.image.as_ref()?;

// ✅ 新方式 - 1 行代码
let info = get_map_texture(file_index, image_index)?;
let texture = info.image.as_ref()?;

// 代码减少 75%！
```

#### 完整示例

```rust
use client_macroquad::resources::get_map_texture;

// 渲染地图格子
fn render_tile(file_index: i16, image_index: i32, x: f32, y: f32) {
    if let Some(info) = get_map_texture(file_index, image_index) {
        if let Some(texture) = &info.image {
            draw_texture_ex(
                texture,
                x - info.offset_x as f32,
                y - info.offset_y as f32,
                WHITE,
                DrawTextureParams {
                    dest_size: Some(vec2(info.width as f32, info.height as f32)),
                    ..Default::default()
                },
            );
        }
    }
}
```

### 2. `get_map_size()` - 获取尺寸（高效）

```rust
pub fn get_map_size(file_index: i16, image_index: i32) -> Option<(i16, i16)>
```

**无需加载纹理，只读取尺寸信息，非常高效！**

#### 示例

```rust
use client_macroquad::resources::get_map_size;

// 快速获取瓦片尺寸
if let Some((width, height)) = get_map_size(file_index, image_index) {
    println!("瓦片尺寸: {}x{}", width, height);
}
```

## 性能优势

### LRU 缓存

所有函数都使用 LRU 缓存，自动管理内存：

```rust
// 设置缓存大小（地图通常需要更大缓存）
resources::set_cache_size(2000, 1000);  // 2000 个 Macroquad 纹理，1000 个 egui UI 纹理

// 自动淘汰最久未使用的纹理
// 缓存命中率通常 70-90%
```

```rust
fn render_middle_layer(map: &MapReader, x: i32, y: i32) {
    let cell = map.get_cell(x, y)?;
    let (file_idx, img_idx) = cell.middle_tile()?;
    
    // ✅ 一行搞定
    if let Some(info) = get_map_texture(file_idx, img_idx) {
        if let Some(texture) = &info.image {
            let world_x = x as f32 * TILE_WIDTH;
            let world_y = y as f32 * TILE_HEIGHT;

            draw_texture_ex(texture, world_x, offset_y, WHITE, params);
        }
    }
}
```

## 完整对比示例

### 旧代码（复杂）

```rust
// ❌ 旧方式 - 需要管理生命周期和借用
fn render_old_way(file_index: i16, image_index: i32) {
    // 1. 获取库
    let lib = match get_map_library(file_index) {
        Some(l) => l,
        None => return,
    };
    
    // 2. 可变借用
    let mut lib_guard = lib.borrow_mut();
    
    // 3. 加载纹理
    let info = match lib_guard.get_or_create_texture(image_index as usize) {
        Ok(i) => i,
        Err(_) => return,
    };
    
    // 4. 获取纹理对象
    let texture = match &info.image {
        Some(t) => t,
        None => return,
    };
    
    // 5. 绘制
    draw_texture_ex(texture, x, y, WHITE, params);
}
```

### 新代码（简洁）

```rust
// ✅ 新方式 - 简单直观
fn render_new_way(file_index: i16, image_index: i32) {
    if let Some(info) = get_map_texture(file_index, image_index) {
        if let Some(texture) = &info.image {
            draw_texture_ex(texture, x, y, WHITE, params);
        }
    }
}

// 甚至可以更简洁
fn render_super_simple(file_index: i16, image_index: i32) {
    get_map_texture(file_index, image_index)
        .and_then(|info| info.image.as_ref())
        .map(|texture| draw_texture_ex(texture, x, y, WHITE, params));
}
```

## 常见问题

### Q: 新函数会影响性能吗？

A: 不会！新函数使用内联优化（`#[inline]`），编译后与直接调用相同。同时使用 LRU 缓存，命中时性能提升 50-100 倍。

### Q: 可以和旧代码混用吗？

A: 可以！新旧 API 完全兼容，可以渐进式迁移。

### Q: 缓存如何清理？

A: LRU 自动管理，不需要手动清理。如需强制清理：
```rust
resources::clear_cache();
```

### Q: 支持动画吗？

A: 支持！传入计算后的 image_index：
```rust
let base_index = cell.middle_image;
let frame_offset = calculate_animation_frame(...);
let animated_index = base_index + frame_offset;

let info = get_map_texture(file_index, animated_index)?;
```
