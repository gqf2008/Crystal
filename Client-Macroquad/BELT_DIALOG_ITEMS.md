# 血瓶对话框（BeltDialog）物品配置说明

## 概述
血瓶对话框是传奇2中的快捷栏系统，用于放置常用的药水、卷轴等消耗品。现在已经为它添加了各种血瓶和蓝瓶物品。

## 物品配置详情

### 格子分布
血瓶对话框共有 **6个格子**，支持数字键1-6快速使用：

| 格子索引 | 数字键 | 物品类型 | 图标索引 | 数量 | 说明 |
|---------|--------|----------|----------|------|------|
| 0 | 🔴 1 | 小血瓶 | Items[0] | 15个 | 基础回血药水 |
| 1 | 🔴 2 | 大血瓶 | Items[1] | 8个 | 高级回血药水 |
| 2 | 🔵 3 | 小蓝瓶 | Items[2] | 12个 | 基础回蓝药水 |
| 3 | 🔵 4 | 大蓝瓶 | Items[3] | 6个 | 高级回蓝药水 |
| 4 | 💛 5 | 金创药 | Items[5] | 3个 | 特殊治疗药品 |
| 5 | 🟢 6 | 万能药 | Items[6] | 2个 | 综合恢复药品 |

### 药水类型说明

#### 血瓶类（HP回复）
- **小血瓶 (Items[0])**
  - 基础的生命值回复药水
  - 适合低级玩家和日常补血
  - 数量较多，便于频繁使用

- **大血瓶 (Items[1])**
  - 高效的生命值回复药水
  - 适合高级玩家和紧急情况
  - 数量适中，珍贵但实用

#### 蓝瓶类（MP回复）
- **小蓝瓶 (Items[2])**
  - 基础的魔法值回复药水
  - 适合法师和道士职业
  - 数量较多，支持持续施法

- **大蓝瓶 (Items[3])**
  - 高效的魔法值回复药水
  - 适合高级法师职业
  - 数量适中，快速回蓝

#### 特殊药品
- **金创药 (Items[5])**
  - 特殊的治疗药品
  - 可能有额外的治疗效果
  - 数量较少，珍贵物品

- **万能药 (Items[6])**
  - 综合性的恢复药品
  - 可能同时回血回蓝
  - 数量最少，极其珍贵

## 视觉设计

### 布局特点
- **水平布局**：默认模式，6个格子横向排列
- **垂直布局**：可通过旋转按钮切换，6个格子纵向排列
- **数字键提示**：每个格子外显示对应数字键（1-6）

### 显示效果
- **物品图标**：从Items纹理库加载对应图标
- **数量显示**：右下角显示物品数量（白色数字）
- **数字键提示**：黄色数字显示在格子外（便于识别快捷键）
- **格子边框**：3D效果的凹陷边框，模拟原版传奇2风格

### 交互功能
- **快捷键使用**：按数字键1-6快速使用对应格子的物品
- **鼠标点击**：点击格子可查看物品详情或使用
- **布局切换**：点击旋转按钮在水平/垂直布局间切换
- **窗口拖拽**：可拖动整个血瓶对话框到屏幕任意位置

## 技术实现

### 数据结构
```rust
#[derive(Debug, Clone, Copy)]
struct CellItem {
    texture_index: u32,  // Items纹理库中的图标索引
    count: u32,          // 物品数量
}
```

### 初始化代码
```rust
// 初始化血瓶和蓝瓶物品
let mut cells = [None; 6];
cells[0] = Some(CellItem { texture_index: 0, count: 15 }); // 小血瓶
cells[1] = Some(CellItem { texture_index: 1, count: 8 });  // 大血瓶
cells[2] = Some(CellItem { texture_index: 2, count: 12 }); // 小蓝瓶
cells[3] = Some(CellItem { texture_index: 3, count: 6 });  // 大蓝瓶
cells[4] = Some(CellItem { texture_index: 5, count: 3 });  // 金创药
cells[5] = Some(CellItem { texture_index: 6, count: 2 });  // 万能药
```

### 绘制逻辑
- 使用egui的painter系统绘制物品图标
- **正确应用纹理偏移**：使用ImageInfo中的offset_x和offset_y进行精确对齐
- 使用纹理的实际尺寸而非固定格子尺寸
- 自动处理物品数量文字渲染
- 支持悬停效果和点击检测

### 纹理对齐优化
```rust
// 应用offset来正确对齐纹理
let offset_x = info.offset_x as f32;
let offset_y = info.offset_y as f32;

// 计算带偏移的绘制位置
let draw_pos = egui::pos2(
    cell_pos.x + 1.0 + offset_x, // 1像素边距 + X偏移
    cell_pos.y + 1.0 + offset_y  // 1像素边距 + Y偏移
);

// 使用纹理的实际尺寸
let texture_size = egui::vec2(info.width as f32, info.height as f32);
```

## 使用说明

### 在游戏中使用
1. **查看物品**：将鼠标悬停在格子上查看物品信息
2. **快速使用**：按数字键1-6直接使用对应格子的药水
3. **切换布局**：点击旋转按钮在水平/垂直布局间切换
4. **移动位置**：拖拽血瓶对话框到合适的屏幕位置

### 药水使用策略
- **小血瓶/小蓝瓶**：日常刷怪和练级时使用
- **大血瓶/大蓝瓶**：PK和困难战斗时使用
- **金创药**：特殊情况下的紧急治疗
- **万能药**：关键时刻的终极恢复
