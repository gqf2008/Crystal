# Crystal Map Editor - Rust Port

这是 Crystal Map Editor 从 C# + DirectX 9 移植到 Rust + ggez 的版本。

### 已实现 ✅
- [x] 基本项目结构
- [x] 地图数据结构 (CellInfo)
- [x] 地图读取器框架
- [x] 自定义地图格式 (C#) 的加载和保存
- [x] 基础渲染器
- [x] 图层渲染 (背景、中间、前景)
- [x] 网格显示
- [x] 鼠标交互
- [x] 键盘控制 (WASD 移动视口, +/- 缩放)
- [x] FPS 显示
- [x] 图层切换 (1/2/3 键)

## 构建和运行

### 前置要求
- Rust 1.70 或更高版本
- Cargo

### 编译
```bash
cd rust-map-editor
cargo build --release
```

### 运行
```bash
cargo run --release
```

## 控制说明

### 键盘
- `W/A/S/D` - 移动视口
- `+/-` - 缩放
- `1` - 切换背景层显示
- `2` - 切换中间层显示
- `3` - 切换前景层显示
- `G` - 切换网格显示
- `F` - 切换前景标记显示

### 鼠标
- 左键 - 选择/放置图块 (待实现)
- 右键 - 删除图块 (待实现)
- 滚轮 - 缩放 (待实现)

## 项目结构

```
src/
├── main.rs              # 入口和主循环
├── cell_info.rs         # 地图单元格数据结构
├── map_reader.rs        # 地图文件读取和保存
├── library.rs           # 图片库管理
├── renderer.rs          # 渲染引擎
└── editor_state.rs      # 编辑器状态管理
```

## 技术栈

- **ggez 0.10.0-rc0** - 游戏引擎和渲染
- **image** - 图像处理
- **serde/bincode** - 序列化
- **byteorder** - 二进制文件读写
- **anyhow** - 错误处理

## 与原版的差异

1. **渲染引擎**: DirectX 9 → ggez (基于 wgpu)
2. **语言**: C# → Rust
3. **UI 框架**: WinForms → 计划使用 egui
4. **内存管理**: GC → 所有权系统
