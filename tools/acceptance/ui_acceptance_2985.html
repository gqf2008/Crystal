修复清单

  1. 行会离线成员被默认滤掉：28 人只列出 1 行
    字段注释写着「默认 true」，但 #[derive(Default)] 把 bool 初始化成 false；C# 是 MembersShowOfflinesetting = true。后果不止少显示几行——成员翻页与滚动条行程全部归零，怎么滚都不动。
    判据 scroll RPC 真值：total 1 → 28
  2. 滚动条滑块从来没动过 P1
    list_thumb 返回 co.0——co 是 &ChildOf，取到的是父实体（列表自己），于是 get_mut 恒失败、continue，滑块死在初始 16×40。这正是「好多窗口滚动条好像都没实现」的真根因；同源的拖动逻辑因为两边都错得一样反而歪打正着能用。
    判据 滑块 Node 真值：高 40 → 194（=302×18/28）；滚到底 top 76 → 184
  3. 滚动条滑块跟随被光标判定挡住
    更新 Node 的那段在系统尾部，而函数开头 cursor_position() 为 None 就 return（无焦点窗口 / 共享桌面 / 自动化），整段跳过。滑块跟随与光标无关，移到判定之前。
    与上条同批复验
  4. 行会隐藏页控件串页
    Bevy 的 Visibility::Visible 会越过隐藏祖先继续渲染（官方文档原话）；六个页容器漏挂 UiRootDisplay → 切到名次/状态页后，成员行的职务下拉留在屏幕上。
    判据 像素：原下拉框位置 (12,12,20) → (3,3,3)
  5. 行会状态页表头没右对齐、也不是灰的
    C# 是 DrawFormat = Right + ForeColour = Gray，右对齐到 x=437（正好贴住值列）；本端左对齐在 x=7，中间空 60px。
    判据 像素：灰字亮区 [362..384] → [417.3..439.3]
  6. 行会翻页箭头被拉伸（16×14 vs 艺术 12×12）
    C# 那 6 处虽写了 Size = new Size(16,14)，但 MirImageControl.AutoSize 让 getter 返回艺术尺寸，绘制也不读 Size——那个 16×14 在绘制与命中两边都被顶掉。
    判据 像素：亮区 12.0×12.0
  7. 行会列表滚轮只有一小块区域生效
    C# 把滚轮同时挂在页容器、页面底图与每个行/格控件上（并集 = 整页）；本端成员列表写的是 (125,30,200,270)——「只有鼠标压在名字列上才滚得动」。
    判据：页内右下角注滚轮 offset 1→2，页外负控不变
  8. 行会公告页永远空白 P1
    公告框 spawn 时写死 Visibility::Hidden 且全仓无人再置显，正文也没有任何地方写入——服务端下发了 13 行公告，页面一片黑。C# 的 Notice 是 Visible = true + Enabled = false（平时只读展示，点「编辑」才可改）。
    修后实机渲染出「欢迎来到测试行会！/ 本行会仅用于 UI 验证。/ 公告第二段用来撑出滚动条。」+「第九行」
  9. 任务「任务：x/y」压住标题栏
    C# _takenQuestsLabel @(210,7)（标题栏右侧、关闭钮左边），本端写死 (18,20)，正好压在内边框上、文字被切。
    判据 像素：亮区起于 panel x=211
  10. 宠物立绘漏叠艺术偏移，偏右下 16/39px
    C# CreatureImage.UseOffSet = true → DisplayLocation = Location + GetOffSet(Index)，Location 只是逻辑位置。Prguse2[540] 偏移 (-16,-39) → 正确绘制点 (34,71)。偏移按种类不同，必须在换种类加载帧时重算。
    修后立绘回到框中，不再压住「可以拾取物品」那行
  11. 好友页签文字压在 FRIEND 标题上
    C# 是贴图按钮 Title[163]@(10,34) / Title[167]@(128,34)（124×24）；本端画的是「好友」「黑名单」两个文字标签 @(18,18)/(70,18)——位置不对且与美术标题重叠。
    修后 FRIEND / BLACKLIST 贴图页签就位
  12. 师徒标题被拉伸 51% 且被文字覆盖
    C# 标题就是美术 Title[51] @(18,8)，艺术尺寸 68×15；本端按 103×17 画，并额外 spawn 一行「师徒」文字叠在上面（实机 师徒MENTOR）。
    修后 MENTOR 单独、原尺寸
  13. 全局中文豆腐扫尾：24 文件 35 处 + 裸 .spawn(( 18 处
    Bevy 没有全局字体——TextFont 是每实体组件。本仓两个句柄：Arial（无 CJK）与宋体（自带）。日志显示 Han 回退已注册，但实测不生效，Arial 句柄画中文一律 .notdef。旧清扫按变量名 grep，而名字会骗人（friend.rs 里 let font = shared_cjk_font(..)）。
    改为按绑定表达式判类；补扫裸 .spawn((（公告就是这么漏的，改完立刻渲染成 □□□□）。回归：40 窗巡回 41/41
  14. 服务端C# 迁移角色的宠物静默丢光
    migrate.rs 把枚举写成数字，而 CreatureType / PickupMode 的 serde 默认表示是变体名 → 反序列化整表失败 → unwrap_or_default() 吞成空表 → 下次存档把 [] 写回去，不可恢复。
    读入端两种表示都收；实机：旧库加载出 5 只，存档自愈为变体名形式
